# JSR 354 — Java Money & Currency API
 
## JSR 354 — Java Money & Currency API

**JSR 354** (Java Specification Request 354) — это **стандартный API для работы с деньгами и валютами** в Java. Он был создан, чтобы устранить проблемы нестандартных решений (`BigDecimal`, `double` и т.д.).

---

### 📦 Что входит в JSR 354?

| Компонент            | Назначение                                      |
| -------------------- | ----------------------------------------------- |
| **`MonetaryAmount`** | Интерфейс для денежных сумм (основной тип)      |
| **`CurrencyUnit`**   | Валюта (USD, EUR, RUB)                          |
| **`Monetary`**       | Фабричный класс для создания экземпляров        |
| **Операции**         | Сложение, вычитание, умножение, сравнение       |
| **Округление**       | Встроенные правила округления (`RoundingMode`)  |
| **Форматы**          | Форматирование денежных сумм для разных локалей |
| **Конвертация**      | API для конвертации валют (по курсам)           |

---

### 🔧 Пример использования (Moneta — реализация)

```xml
<dependency>
    <groupId>org.javamoney</groupId>
    <artifactId>moneta</artifactId>
    <version>1.4.4</version>
</dependency>
```

```java
import javax.money.Monetary;
import javax.money.MonetaryAmount;
import org.javamoney.moneta.Money;

// Создание денежной суммы
MonetaryAmount amount = Money.of(100.50, "USD");
MonetaryAmount tax = amount.multiply(0.2);     // 20.10
MonetaryAmount total = amount.add(tax);         // 120.60

// Проверка валюты
System.out.println(amount.getCurrency());       // USD
System.out.println(amount.getNumber());         // 100.5

// Округление до 2 знаков
MonetaryAmount rounded = amount.with(Monetary.getDefaultRounding());

// Сравнение
boolean greater = amount.isGreaterThan(Money.of(50, "USD")); // true
```

### 📊 Сравнение: JSR 354 vs BigDecimal

| Критерий         | BigDecimal                           | JSR 354               |
| ---------------- | ------------------------------------ | --------------------- |
| Валюта           | ❌ Нет                                | ✅ Да (CurrencyUnit)   |
| Конвертация      | ❌ Нет                                | ✅ Да                  |
| Форматирование   | ❌ Нет (ручное)                       | ✅ Встроенное          |
| Типобезопасность | ⚠️ Нет (просто число)                | ✅ Да (MonetaryAmount) |
| Сравнение денег  | ⚠️ Придётся учитывать валюту вручную | ✅ Встроено            |

### 🎯 Когда использовать JSR 354?

| Сценарий                              | Рекомендация                       |
| ------------------------------------- | ---------------------------------- |
| **Мультивалютные приложения**         | ✅ Да                               |
| **Финансовые системы**                | ✅ Да                               |
| **Конвертация валют**                 | ✅ Да                               |
| **Моновалютные системы (только RUB)** | ⚠️ Можно использовать `BigDecimal` |
| **Микросервисы с разными валютами**   | ✅ Да                               |

---

### 📌 Ключевые плюсы

1. **Стандартизация** — единый API для всех Java-приложений.
2. **Работа с валютой** — не нужно хранить `Currency` отдельно.
3. **Конвертация** — встроенные механизмы получения курсов.
4. **Округление** — финансовое округление по правилам.
5. **Типобезопасность** — нельзя сложить USD и EUR без явной конвертации.

### ⚠️ Минусы

- Реализация Moneta добавляет зависимость (~0.5 MB).
- Медленнее, чем `long` в копейках (но обычно приемлемо).
- Может быть избыточно для простых моновалютных проектов.
