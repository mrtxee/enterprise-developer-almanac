**RFC 5424** — это стандарт, описывающий протокол Syslog для передачи логов (событий) от устройств и приложений на сервер сбора логов.

### Суть протокола
Это «почтовый ящик» для системных сообщений: программа генерирует лог, а Syslog упаковывает его в специальный формат и отправляет на удалённый сервер (syslog server).

### Ключевые элементы
- **Отправитель (sender)** — устройство/приложение, создающее лог.
- **Сборщик (collector)** — сервер, принимающий и хранящий логи.
- **Формат сообщения** — строгая структура с заголовком и телом.

### Формат сообщения (пример)
```
<34>1 2025-01-15T10:00:00Z myhost myapp 1234 - - Сервер запущен
```

| Часть | Что значит |
|--------|-------------|
| `<34>` | Приоритет (facility + severity) |
| `1` | Версия протокола (RFC 5424) |
| `2025-01-15T10:00:00Z` | Временная метка |
| `myhost` | Имя хоста |
| `myapp` | Имя приложения |
| `1234` | ID процесса (Procid) |
| `- -` | Message ID и Structured Data (пустые) |
| `Сервер запущен` | Само сообщение |

### Почему важен RFC 5424
- **Стандартизирует** передачу логов между разными системами.
- **Расширяет** старую версию (RFC 3164) поддержкой структурированных данных, временной зоны и UTF-8.
- **Позволяет** централизованно собирать логи со всего IT-ландшафта для анализа, мониторинга и расследования инцидентов.

### Где применяется
- SIEM-системы (Splunk, ELK).
- Сетевые устройства (роутеры, фаерволы).
- Серверы Linux/Unix (rsyslog, syslog-ng).
- Anywhere, где нужен централизованный сбор событий.
