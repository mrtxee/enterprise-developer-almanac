# RFC 3339 vs [[ISO 8601 Time format|ISO 8601]]: сравнение форматов даты и времени

## 🎯 Основное различие

| Характеристика | **ISO 8601** | **RFC 3339** |
|----------------|--------------|--------------|
| **Тип стандарта** | Международный стандарт (ISO) | Интернет-стандарт (IETF) |
| **Год создания** | 1988 (многократно обновлялся) | 2002 |
| **Область применения** | Универсальная (любые системы) | Интернет-протоколы, API, данные |
| **Сложность** | Высокая (много опций и форматов) | Низкая (строгое подмножество) |
| **Отношение** | Родительский стандарт | Профиль ISO 8601 (урезанная версия) |

## 📅 Форматы: что разрешено

### ISO 8601 (много вариантов)
```yaml
Разделители:         2025-04-12T15:30:00Z
                    20250412T153000Z
                    2025-W15-6T15:30:00Z   (неделя и день недели)
                    2025-04-12T15:30:00+03:00
                    2025-04-12             (только дата)
                    2025-04               (год-месяц)
                    2025                  (только год)
                    15:30:00              (только время)
                    P3DT2H                (длительности, интервалы)
```

### RFC 3339 (строго ограничен)
```yaml
Разрешено только:    2025-04-12T15:30:00Z
                    2025-04-12T15:30:00+03:00
                    2025-04-12T15:30Z      (минуты)
                    2025-04-12             (только дата)
Запрещено:          20250412T153000Z       (без дефисов и двоеточий)
                    Недели, порядковые дни
                    Длительности и интервалы
```

## 📊 Детальное сравнение

| Параметр | ISO 8601 | RFC 3339 |
|----------|----------|----------|
| **Разделители** | Можно без дефисов (`20250412`) | Обязательны дефисы (`2025-04-12`) |
| **Разделитель даты/времени** | `T` или пробел | Только `T` |
| **Разделитель времени** | Можно без двоеточий (`153000`) | Обязательны двоеточия (`15:30:00`) |
| **Миллисекунды** | Запятая или точка | Только точка (.) |
| **Часовой пояс** | `Z`, `+03:00`, `+0300` | Только `Z` или `+03:00` |
| **Недельная нотация** | ✅ (`2025-W15-6`) | ❌ |
| **Порядковые дни** | ✅ (`2025-102`) | ❌ |
| **Длительности** | ✅ (`P3DT2H`) | ❌ |
| **Интервалы** | ✅ (`2025-04-12/2025-04-15`) | ❌ |

## 🔍 Примеры в реальном мире

### Что использует ISO 8601
- XML Schema (`dateTime`)
- Базы данных (частично)
- Научные системы
- Промышленные стандарты

### Что использует RFC 3339
- **JSON** (спецификация рекомендует RFC 3339)
- **OpenAPI/Swagger** (формат `date-time`)
- **HTTP API** (поле `Date` — но там свой формат)
- **Логи** (Prometheus, OpenTelemetry)
- **Git** (внутреннее представление)
- **JWT** (поля `iat`, `exp` — часто Unix timestamp, но RFC 3339 тоже встречается)

## 💻 Примеры в коде

### Python
```python
from datetime import datetime, timezone

now = datetime.now(timezone.utc)

# ISO 8601 (стандартная библиотека)
iso_string = now.isoformat()  # 2025-04-12T15:30:00.123456+00:00

# RFC 3339 (упрощённо, без микросекунд)
rfc3339_string = now.strftime("%Y-%m-%dT%H:%M:%SZ")
# 2025-04-12T15:30:00Z
```

### JavaScript
```javascript
const now = new Date();

// ISO 8601 (стандартный метод)
console.log(now.toISOString()); // 2025-04-12T15:30:00.123Z (это и есть RFC 3339 + миллисекунды)

// Фактически toISOString() возвращает RFC 3339-совместимую строку
```

## ⚖️ Что выбрать?

### Выбирайте ISO 8601 если:
- Нужны **длительности, интервалы или недельная нотация**
- Система сама его генерирует (например, XML)
- Работаете в **научной среде**

### Выбирайте RFC 3339 если:
- Разрабатываете **API / REST сервис**
- Используете **JSON как формат обмена**
- Пишете **логи и метрики**
- Хотите **простоту и однозначность**
- Нужна **совместимость с веб-инструментами**

## 🏆 Итог

```
ISO 8601 — это "швейцарский нож" для дат и времени: мощный, гибкий, но сложный.
RFC 3339 — это "перочинный ножик": простой, стандартизированный для интернета.
```

**Для веб-разработки и API** — всегда используйте **RFC 3339** (`2025-04-12T15:30:00Z`). Он является подмножеством ISO 8601, поэтому любой ISO-парсер поймёт RFC 3339, но не наоборот.

**Для специальных задач** (длительности, недели) — используйте полный **ISO 8601**.
