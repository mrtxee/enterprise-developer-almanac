## Observable State

**Observable State** (наблюдаемое состояние) — это концепция в разработке программного обеспечения, особенно в реактивном программировании, которая означает, что состояние приложения или компонента может быть «наблюдаемо» — то есть другие части системы могут подписаться на его изменения и автоматически реагировать на них.

**Суть**

Это состояние, которое:

- **Изменяется со временем**.
- **Уведомляет подписчиков** об изменениях.
- **Позволяет реагировать** на изменения автоматически.

**Где используется в Frontend-фреймворках**

- **React**: MobX, Recoil, Zustand.
- **Vue**: Vuex (с плагинами), Composition API.
- **Angular**: RxJS, NgRx.

**State management библиотеки**

- **MobX** (декораторы `@observable`, `@computed`).
- **Redux** с **Redux Observable**.
- **Akita** для Angular.
- **Valtio** для React.

**Backend системы**

- Реактивные микросервисы.
- Real-time приложения (WebSockets).
- Обработка потоков данных.
