## Паттерн Sidecar

Sidecar-контейнер — это контейнер, который должен быть запущен рядом с основным [[containerization|контейнером]] внутри пода. Этот паттерн нужен для расширения и улучшения функциональности основного приложения без внесения в него изменений. Технология контейнеризации позволяет собирать все зависимости, чтобы запустить приложение где угодно.

- **Sidecar-контейнер** делает только одну вещь и делает её хорошо.

Шаблон Sidecar позволяет добавить ряд возможностей в приложение без дополнительного кода конфигурации для сторонних компонентов.
