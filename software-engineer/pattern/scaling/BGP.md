## BGP

**BGP (Border Gateway Protocol)** — это главный протокол маршрутизации в интернете, который определяет, как передавать данные между разными сетями (автономными системами).

## BGP в контексте Anycast

Когда настраивается **Anycast + BGP**, BGP используется для того, чтобы «обмануть» интернет: маршрутизаторам по всему миру объявляется «IP-адрес моего сервиса (например, `8.8.8.8`) находится у меня».

1. **Один IP на многих серверах:** запускаются десятки серверов в разных дата-центрах (в Нью-Йорке, Лондоне, Токио).
2. **Одинаковое объявление:** BGP настраивается на каждом сервере так, чтобы он объявлял миру **один и тот же IP-адрес**.
3. **Выбор ближайшего:** интернет-маршрутизаторы, получая объявления об этом IP отовсюду, автоматически выбирают **самый короткий и быстрый путь** к нему (по BGP-метрикам). Пользователь из Европы автоматически идёт на сервер в Лондоне, а пользователь из Азии — на сервер в Токио.

**Отказоустойчивость (failover)**

Если сервер в Лондоне выходит из строя, он перестает объявлять свой IP через BGP. Маршрутизаторы мгновенно «забывают» путь к нему и начинают направлять трафик европейских пользователей к следующему ближайшему живому серверу (например, в Нью-Йорке).

**Итог:** BGP — это клей, который связывает разрозненные [[anycast]]-серверы в единую глобальную, самоисцеляющуюся сеть.
