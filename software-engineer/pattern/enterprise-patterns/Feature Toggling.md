# Feature Toggling

Feature Toggling (или [[Feature Flagging|Feature Flags]]) — это подход, который позволяет включать и отключать функциональные возможности приложения без необходимости развёртывания нового кода. Это особенно полезно для управления рисками при выпуске новых функций и проведения экспериментов.

Feature Toggling — это практика, при которой функциональные возможности приложения могут быть включены или выключены во время выполнения без изменения исходного кода.
