## Feature Toggling

Feature Toggling (или [[feature-flagging|Feature Flags]]) — это подход, который позволяет включать и отключать функциональные возможности приложения без необходимости развёртывания нового кода. Это практика, при которой функциональные возможности приложения могут быть включены или выключены во время выполнения без изменения исходного кода. Особенно полезно для управления рисками при выпуске новых функций и проведения экспериментов.

Возможна настройка Feature Toggling с [[istio]].
