Настройка UFW и его графической оболочки GUFW на домашнем ноутбуке с Arch Linux — процесс простой и быстрый. Это добавит вам дополнительный уровень безопасности, особенно в публичных сетях, при этом не перегружая систему лишними сложностями.

## 📦 Установка

```bash
# Установка UFW и GUFW
sudo pacman -S ufw gufw
```

`ufw` — это сам брандмауэр (командная строка), а `gufw` — графический интерфейс к нему (опционально, но удобно для новичков).

---

## 🛠️ Базовая настройка UFW (командная строка)

Эти шаги создадут надёжную конфигурацию для ноутбука.

### 1. Установите правила по умолчанию

*Запрещаем все входящие подключения, разрешаем все исходящие.*

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
```

### 2. Разрешите SSH (если используете)

*Если вы подключаетесь к ноутбуку по SSH из локальной сети, это правило обязательно.*

```bash
sudo ufw allow ssh
```

Это разрешит подключения по SSH на стандартном порту (22).

### 3. Включите UFW
```bash
sudo ufw enable
```

Команда активирует брандмауэр. При первом запуске она может попросить подтверждения, так как это может разорвать текущие SSH-соединения.

### 4. Проверьте статус и правила
```bash
sudo ufw status verbose
```

Вы должны увидеть что-то вроде:

```
Status: active
Logging: on (low)
Default: deny (incoming), allow (outgoing), deny (routed)
New profiles: skip

To                         Action      From
--                         ------      ----
22/tcp                     ALLOW IN    Anywhere
```

## 🖥️ Настройка через GUFW (графический интерфейс)

`GUFW` делает настройку ещё проще, особенно если вы не любите работать в терминале.

1. Запустите приложение **GUFW** из меню приложений.
2. В главном окне:
	* Переключите статус на **"Включён" (Enabled)**.
	* В выпадающем списке **"Входящие" (Incoming)** выберите **"Запретить" (Deny)**.
	* В выпадающем списке **"Исходящие" (Outgoing)** выберите **"Разрешить" (Allow)**.
3. Для добавления правил (например, для SSH или торрент-клиента):
	* Нажмите **"Добавить правило" (Add Rule)**.
	* Выберите **"Simple"** или **"Advanced"**.
	* Укажите порт (например, 22 для SSH) и направление (In).
	* Нажмите **"Добавить" (Add)**.

## 🤔 Дополнительные правила для повседневного использования

Вот несколько полезных правил, которые могут пригодиться.

* **Для торрент-клиента (qBittorrent):** нужно разрешить входящие подключения на порт, который вы используете в настройках клиента (обычно это порт в диапазоне от 6881 до 6889).
```bash
sudo ufw allow 6881/tcp
sudo ufw allow 6881/udp
```
* **Для работы с Bonjour/Avahi (обнаружение сетевых устройств):**
```bash
sudo ufw allow 5353/udp
```
* **Для общего доступа к файлам (Samba):**
```bash
sudo ufw allow 139/tcp
sudo ufw allow 445/tcp
```

---

## 🧹 Управление правилами

* **Посмотреть все правила с номерами**:
```bash
sudo ufw status numbered
```
* **Удалить правило по номеру** (например, номер 3):
```bash
sudo ufw delete 3
```
* **удалить правила**
```bash
sudo ufw delete allow from 192.168.1.0/24 to any port 5353 proto udp
```
* **Полностью отключить UFW**:
```bash
sudo ufw disable
```
* **Сбросить все правила к заводским**:
```bash
sudo ufw reset
```

---

## 🔍 Включение логирования

Если вы хотите видеть, что пытается подключиться к вашему ноутбуку, включите логирование. Это поможет в диагностике.

```bash
sudo ufw logging on
```

Логи будут писаться в системный журнал (`journalctl -u ufw`).

```bash
sudo journalctl -u ufw -f
```

Это покажет, какие пакеты блокируются, и вы сможете уточнить порт.

```bash
# Разрешить mDNS (UDP 5353) для обнаружения устройств в локальной сети
sudo ufw allow from 192.168.0.0/16 to any port 5353 proto udp
# Разрешить порт передачи данных
```

```bash
# Применить Изменения:
sudo ufw reload
```

Эфемерные (динамические) порты — это порты, которые операционная система автоматически назначает клиентским приложениям на время сессии. Они используются для исходящих соединений и временных задач, в отличие от статических портов, зарезервированных для сервисов.

Давайте разложим по полочкам.

## 🧩 Категории портов

Все порты делятся на три диапазона, которые регламентированы IANA (Internet Assigned Numbers Authority):

1. **Системные (Well-Known Ports)**: 0–1023
    * **Назначение**: Зарезервированы для самых важных системных служб и протоколов.
    * **Кто использует**: Только приложения с правами суперпользователя (root).
    * **Примеры**: `22` (SSH), `80` (HTTP), `443` (HTTPS), `25` (SMTP).

2. **Зарегистрированные (Registered Ports)**: 1024–49151
    * **Назначение**: Используются для менее критичных, но широко распространённых приложений и сервисов.
    * **Кто использует**: Обычные пользовательские приложения, которые работают как серверы.
    * **Примеры**: `3306` (MySQL), `5432` (PostgreSQL), `8080` (альтернативный HTTP).

3. **Эфемерные/Динамические (Dynamic / Private Ports)**: 49152–65535
    * **Назначение**: Временные порты, которые ОС выдаёт программам на время соединения.
    * **Кто использует**: Любое клиентское приложение (браузер, мессенджер, торрент-клиент), когда оно инициирует исходящее соединение с сервером.
    * **Примеры**: `49152`, `54231` и т.д.

---

## 🤔 Что такое эфемерные порты и зачем они нужны?

Когда ваш браузер открывает веб-страницу, он не использует порт `443` (это порт сервера). Вместо этого **операционная система** (ядро) выдаёт случайный свободный порт из этого диапазона, например `52413`, и привязывает его к вашему браузеру. Этот порт остаётся занятым до закрытия соединения.

**Зачем это нужно?**

Чтобы одно приложение (например, браузер) могло поддерживать тысячи одновременных соединений с разными серверами. У каждого соединения будет свой уникальный эфемерный порт, что позволяет системе правильно направлять входящие пакеты обратно в нужное приложение.

---

## 🧠 Почему это важно для вас?

В контексте UFW и Quick Share:

* Ваш ноутбук **слушает** порт `5353` (системный, для mDNS) и открытый порт для передачи файлов (например, `43243`, который попал в категорию зарегистрированных).
* Ваш ноутбук **использует эфемерный порт** (например, `38510` из примера с `tcpdump`) как *источник*, чтобы подключиться к порту `45753` на другом устройстве. Это нормально, и такие соединения не нужно открывать в UFW.

## 📊 Сводная таблица

| Диапазон | Название | Назначение | Кто использует |
| :--- | :--- | :--- | :--- |
| **0–1023** | Системные | Критические сервисы (SSH, HTTP) | Только root |
| **1024–49151** | Зарегистрированные | Сервисы приложений (MySQL, игры) | Пользовательские серверы |
| **49152–65535** | **Эфемерные** | Временные клиентские соединения | Браузеры, клиенты |

---

## ⚠️ Важное уточнение

В Linux системные администраторы могут изменить диапазон эфемерных портов. Вы можете посмотреть текущие настройки командой:

```bash
cat /proc/sys/net/ipv4/ip_local_port_range
```

Обычно это диапазон `32768–60999`, что немного отличается от стандарта IANA, но суть остаётся той же.
