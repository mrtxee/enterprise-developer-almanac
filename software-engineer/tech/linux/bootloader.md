## Загрузчики (Bootloaders)

Bootloaders (загрузчики) — это программы, которые запускают операционную систему. Они загружают ядро и [[linux-load-phases|initramfs]] в память перед запуском системы. Рассмотрим различия между systemd-boot, GRUB, efistub, Limine и rEFInd.

## systemd-boot

Часть экосистемы [[linux-load-phases|systemd]], минималистичный загрузчик, предназначенный только для систем с [[bios-uefi|UEFI]]. Не поддерживает [[bios-uefi|BIOS]].

**Особенности:**

- Простая конфигурация: загрузочные записи разделены на несколько файлов, что упрощает управление.
- Автоматически обнаруживает ядра в каталоге `/boot` (например, `vmlinuz-linux` и `initramfs-linux.img`).
- Поддерживает зашифрованные разделы `/boot`.
- Интегрирован с systemd: для управления записями и обновлениями используется утилита `bootctl`.
- Измеряет TPM PCR во время загрузки.
- Подходит для быстрых и простых установок UEFI, а также как запасной вариант для материнских плат MSI с проблемами UEFI.

## GRUB (GRand Unified Bootloader)

Один из самых распространённых загрузчиков, поддерживает как BIOS, так и UEFI.

**Особенности:**

- Гибкий и многофункциональный: поддерживает многозадачность, RAID, LUKS1, LVM.
- Имеет встроенный генератор конфигурации `grub-mkconfig`, который автоматически обнаруживает другие операционные системы.
- Поддерживает широкий спектр файловых систем, включая ext2, ext3, ext4, btrfs, zfs, minix, iso9660, xfs, NTFS и FAT32.
- Подходит для сложных сценариев, например, для зашифрованного `/boot`, BIOS или работы с Btrfs.
- Может быть медленнее других загрузчиков, особенно на старых системах с BIOS.

## efistub (EFI boot stub)

Метод, который позволяет загружать ядро Linux напрямую через UEFI без дополнительного загрузчика.

**Особенности:**

- Ядро должно быть собрано с флагом `CONFIG_EFI_STUB=y`.
- Минимальная задержка: отсутствие промежуточного звена в цепочке загрузки ускоряет процесс.
- Пользователь сам решает, передавать ли параметры ядру.
- Требует настройки UEFI: обычно достаточно указать местоположение ядра и параметры для его запуска.

## Limine

Современный, продвинутый и переносимый многопротокольный загрузчик. Служит эталонной реализацией протокола загрузки Limine, поддерживает Linux и цепную загрузку других загрузчиков.

**Особенности:**

- Поддерживает несколько протоколов загрузки, включая Multiboot2 и протокол загрузки Linux.
- Работает как на системах UEFI, так и на BIOS.
- Имеет возможности кастомизации тем, схожие с GRUB.
- Поддерживает снимки Btrfs через `limine-snapper-sync`.
- Требует, чтобы `/boot` использовал FAT12/16/32 или ISO9660; другие файловые системы требуют дополнительной настройки.
- Не добавляет автоматически запись в [[NVRAM|NVRAM]] UEFI — это нужно делать вручную с помощью `efibootmgr` или `limine-entry-tool`.

## rEFInd (reFormatted EFI Indicator)

Графический загрузчик, ориентированный на UEFI.

**Особенности:**

- Автоматически обнаруживает все операционные системы и ядра на накопителях.
- Имеет графический интерфейс, напоминающий селектор загрузки в macOS.
- Поддерживает темы, с опциональной поддержкой сенсорного экрана.
- Может считывать образы для загрузки с файловых систем EFI (FAT12/16/32), а также EXT4 и BTRFS.
- Не поддерживает системы с BIOS.
- Не измеряет регистры PCR модуля TPM.

## Сравнение

| Загрузчик | Поддержка UEFI/BIOS | Особенности | Сценарии использования |
|---|---|---|---|
| systemd-boot | Только UEFI | Минималистичный, быстрая загрузка, интеграция с systemd | Простые установки UEFI, системы с проблемами UEFI на MSI |
| GRUB | UEFI и BIOS | Гибкий, поддержка расширенных функций (шифрование, RAID, LVM) | Сложные сценарии, зашифрованный `/boot`, многозадачность |
| efistub | Только UEFI | Прямая загрузка ядра через UEFI | Минимализм, скорость, контроль над параметрами ядра |
| Limine | UEFI и BIOS | Многопротокольный, поддержка Btrfs-снапшотов | Современные системы, dual-boot с Windows, поддержка обоих типов прошивки |
| rEFInd | Только UEFI | Графический интерфейс, автоматическое обнаружение ОС | Мультизагрузка, простота использования, акцент на внешний вид |

Выбор загрузчика зависит от конкретных требований: простоты, гибкости, поддержки определённых функций или внешнего вида интерфейса.

## Windows Boot Manager (WBM)

Windows использует собственный загрузчик — Windows Boot Manager `WBM`, сокращённо bootmgr или winload.efi, который работает по-разному в системах с [[bios-uefi|BIOS]] и UEFI.
