## Архитектура macOS

**macOS** — это операционная система от Apple, основанная на ядре **XNU** и подсистеме **Darwin**. Она объединяет Unix-инструменты, графическую оболочку Apple и поддержку процессоров Apple Silicon.

## Основные компоненты

| Компонент | Роль |
|-----------|------|
| **XNU** | Гибридное ядро (Mach + BSD-слой) |
| **Darwin** | Открытая Unix-подсистема (drivers, процессы, файловые системы) |
| **launchd** | Управляет процессами и демонами |
| **Mach-O** | Исполняемый формат macOS |
| **Apple Silicon** | ARM-процессоры Apple (M1, M2, M3) |

## XNU (ядро)

**XNU** — гибридное ядро macOS и iOS:

- **Mach-слой:** потоки, память, IPC.
- **BSD-слой:** POSIX, сеть, файловые системы.
- **I/O Kit:** драйверы устройств.

Стиль «монолитного ядра с модулями ядра (kext / DEXT)» — драйверы можно загружать в кернел-пространство.

## launchd (процессы и демоны)

`launchd` — замена классическому `init`/`sysvinit` в macOS:

- Запускает демоны и агенты по расписанию.
- Перезапускает упавшие сервисы.
- Единый механизм управления `launchctl`.

Аналог в Linux — `systemd`; в macOS роль главного процесса выполняет `launchd`.

## Исполняемый формат Mach-O

Вместо ELF (Linux) macOS использует **Mach-O**:

- Секции `__TEXT`, `__DATA` и др.
- Поддержка универсальных бинарников (x86_64 + arm64 в одном файле).
- Производится `code signing` (подпись кода).

Просмотр структуры бинарника:

```bash
file /bin/ls
otool -L /bin/ls
```

## Роль Darwin

**Darwin** — открытая Unix-подсистема Apple, из которой собирается macOS:

- POSIX-совместимость shell, утилит из BSD.
- Ядро XNU и драйверы.
- Файловые системы (APFS, HFS+) и сетевой стек.

Пользователи часто говорят «macOS — это Darwin плюс графическая оболочка и приложения Apple».

## GNU-инструменты на macOS

macOS использует **BSD-версии** утилит (`ls`, `sed`, `awk`), а не GNU-версии:

| Утилита | macOS (BSD) | Linux (GNU) |
|---------|-------------|-------------|
| `sed` | `sed -i '' s/.../` | `sed -i s/.../` |
| `find` | нет `-regextype` по умолчанию | есть |
| `du`/`df` | вывод в единицах 512-байт блоков | человекочитаемый по `-h` |

Совместимость достигается установкой GNU-утилит через Homebrew (`brew install coreutils gnu-sed`).

## История: NeXTSTEP

- macOS наследует архитектуру **NeXTSTEP** (ОС компьютеров NeXT).
- Наследство: Object-C, док, объектно-ориентированные фреймворки, Mach-ядро.
- Дальнейшим развитием стали macOS и iOS.

## Apple Silicon

- ARM-процессоры Apple (M1, M2, M3) вместо Intel x86_64.
- Поддержка запуска x86_64-приложений эмуляцией (Rosetta 2).
- Безопасность: прошивка T2 / Secure Enclave, подписанный код.

Просмотр архитектуры бинарника:

```bash
file /bin/zsh
```

## Особенности

- ✅ Гибридное ядро XNU с Unix-совместимостью.
- ✅ launchd — единая подсистема процессов.
- ✅ Универсальные бинарники Mach-O поддерживают и Intel, и ARM.
- ✅ Строгая модель безопасности (code signing, T2/Secure Enclave).
- ❌ Отличия от Linux: BSD-утилиты, Mach-O вместо ELF, закрытые части.
- ❌ Драйверы ограничены подписанными и продаваемыми через Apple.

## Итог

**macOS сочетает** Unix-ядро (XNU + Darwin) и проприетарную оболочку Apple. Понимание уровня: XNU → Darwin → launchd → ПО Apple; для кросс‑платформенной разработки важно учитывать BSD-утилиты и формат Mach-O.
