## GNOME-темы

**WhiteSur-gtk-theme**

```bash
./install.sh -o solid -c dark -a alt -N mojave -l -HD --darker
# WhiteSur-gtk-theme GDM
sudo ./tweaks.sh -g -b "/home/a/Pictures/wp/starry_sky_milky_way_night_124665_6000x3000.jpg"
```

**Fluent-gtk-theme**

```bash
./install.sh -c dark -s standard -i arch -l --tweaks solid
```

**Orchis-theme**

```bash
./install.sh -c dark -s standard -i arch --tweaks solid -f --tweaks nord --tweaks submenu
```

**Orianin-gtk-theme**

```bash
./install.sh -c dark -s standard -i arch --tweaks solid -f -l --tweaks dracula
```
