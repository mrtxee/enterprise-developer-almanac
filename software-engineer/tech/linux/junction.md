Чтобы сделать каталог `/home/a/Downloads` символической ссылкой на `/mnt/3FC00C396CD55163/h/a/n` в Arch Linux, выполните следующие шаги:

---

## 🔧 Пошаговая инструкция:

1. **Убедитесь, что исходный каталог существует:**
   ```bash
   ls /mnt/3FC00C396CD55163/h/a/n
   ```

   Если его нет — создайте:

   ```bash
   mkdir -p /mnt/3FC00C396CD55163/h/a/n
   ```

2. **Переместите старый каталог `Downloads` (если он содержит данные):**
   ```bash
   mv /home/a/Downloads /home/a/Downloads.bak
   ```
   > Это резервная копия. Удалите позже, если всё работает.

3. **Создайте символическую ссылку:**
   ```bash
   ln -s /mnt/3FC00C396CD55163/h/a/n /home/a/Downloads
   ```

4. **Проверьте, что ссылка работает:**
   ```bash
   ls -l /home/a/Downloads
   ```

   Вы должны увидеть:

   ```
   lrwxrwxrwx ... /home/a/Downloads -> /mnt/3FC00C396CD55163/h/a/n
   ```

5. **(Опционально) Удалите резервную копию, если всё в порядке:**
   ```bash
   rm -rf /home/a/Downloads.bak
   ```

---

## ⚠️ Важные замечания:

- Убедитесь, что раздел с `/mnt/3FC00C396CD55163` **монтируется автоматически при загрузке** (пропишите в `/etc/fstab`), иначе ссылка будет вести в "никуда", и могут быть ошибки.

  Пример строки в `/etc/fstab` (если это NTFS):

  ```
  UUID=3FC00C396CD55163 /mnt/3FC00C396CD55163 ntfs-3g defaults,uid=1000,gid=1000,umask=022 0 0
  ```

  Найдите UUID через:

  ```bash
  blkid
  ```

- Убедитесь, что пользователь `a` имеет **права на чтение и запись** в `/mnt/3FC00C396CD55163/h/a/n`.

---

## ✅ Готово!

Теперь `/home/a/Downloads` — это символическая ссылка, указывающая на нужный путь. Все файлы, сохраняемые в `Downloads`, будут физически находиться на указанном разделе.
