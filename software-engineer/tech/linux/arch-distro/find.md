## Команда find

**find** — утилита для поиска файлов и каталогов в файловой системе по имени, типу, размеру, правам, времени изменения и другим атрибутам. Используется в Linux, macOS и всех системах с GNU findutils.

## Основные команды

Поиск по имени в текущем каталоге:

```bash
find . -name "*.md"
```

Поиск по имени с учётом регистра:

```bash
find . -iname "*.MD"
```

Поиск по типу:

```bash
find / -type f
find / -type d
```

- `f` — файлы
- `d` — каталоги
- `l` — символьные ссылки

Поиск по размеру:

```bash
find . -size +100M
find . -size -1k
```

Поиск по времени изменения:

```bash
find . -mtime -7
find . -mmin -60
```

Поиск по правам:

```bash
find . -perm 600
find . -name "*.conf" -perm 644
```

Поиск по пользователю и группе:

```bash
find . -user root
find . -group www-data
```

Выполнение действия над найденными файлами:

```bash
find . -name "*.log" -delete
find . -name "*.tmp" -exec rm {} \;
```

Поиск с ограничением глубины:

```bash
find . -maxdepth 2 -name "*.md"
find . -mindepth 1 -name "*.txt"
```

## Синтаксис

```bash
find [начальный каталог] [опции поиска] [действия]
```

| Опция | Назначение |
|-------|-----------|
| `-name` | Точное имя без учёта регистра — `-iname` |
| `-type` | Тип объекта: `f` файл, `d` каталог, `l` ссылка |
| `-size` | Размер: `+100M`, `-1k`, `1024c` |
| `-mtime` | Модифицирован за N×24 часа: `-mtime -7` |
| `-mmin` | Модифицирован за N минут |
| `-user` / `-group` | Владелец / группа |
| `-perm` | Права доступа |
| `-maxdepth` / `-mindepth` | Глубина рекурсии |
| `-exec` / `-delete` | Действие над результатом |

## Практические примеры

Удалить все файлы `.log` старше 30 дней:

```bash
find /var/log -name "*.log" -mtime +30 -delete
```

Найти большие файлы на диске:

```bash
find / -type f -size +500M -exec ls -lh {} \;
```

Передать результаты в другую команду:

```bash
find . -name "*.cpp" | xargs wc -l
```

Найти все подкаталоги проекта:

```bash
find /project -type d
```

Объединение условий:

```bash
find . \( -name "*.md" -o -name "*.txt" \) -type f
```

Поиск с игнорированием каталогов:

```bash
find . -name "node_modules" -prune -o -name "*.js" -print
```

## Скорость в больших каталогах

- Обход в глубину с `find` быстрее, чем глоб по рекурсивным `**` в некоторых языках.
- Для больших деревьев есть утилиты-аналоги (например, `fd`) — но `find` предустановлен в любом дистрибутиве и использует нативные системные вызовы.

## Частые ошибки

| Ошибка | Решение |
|--------|---------|
| Забытые кавычки вокруг шаблона | `-name "*.md"` — кавычки обязательны, чтобы шаблон не раскрыла оболочка |
| `-exec` без `\` в конце | `-exec rm {} \;` — завершение через `;` обязательно |
| Модификация файлов при `-mtime` | Проверять: `-mtime` считает дни по времени изменения, `-mmin` — минуты |

## Итог

`find` — базовая утилита для поиска, фильтрации и выполнения действий над файлами. Главные правила: кавычить шаблоны имени, указывать тип и ограничивать глубину для больших деревьев.
