## AUR

**Суть**

AUR (Arch User Repository) — это сообщество пользователей Arch. Там лежат скрипты сборки (PKGBUILD) для программ, которых нет в официальных репозиториях (например, Яндекс.Браузер, Google Chrome, Zoom, многие драйверы и темы).

AUR работает на уровне пакетного менеджера, а не окружения рабочего стола — в GNOME нет кнопки «включить AUR».

## yay — помощник для AUR

yay (Yet Another Yogurt) — помощник, который автоматизирует установку из AUR: сам скачивает скрипт, собирает пакет, устанавливает и разрешает зависимости.

**Установка yay**

1. Установите базовые инструменты для сборки:

```bash
sudo pacman -S --needed base-devel git
```

2. Клонируйте репозиторий yay и соберите:

```bash
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si
```

Параметр `-si` означает:
- `-s` — установить зависимости
- `-i` — после сборки сразу установить

3. Проверка:

```bash
yay --version
```

**Основные команды**

| Действие | Команда |
| --- | --- |
| Поиск программы (и в AUR, и в официальных репах) | `yay -S имя_пакета` |
| Поиск только по названиям | `yay имя_пакета` |
| Установка из AUR | `yay -S название_из_aur` |
| Обновление всех пакетов (официальные + AUR) | `yay -Syu` |
| Удаление пакета | `yay -Rns название_пакета` |
| Показать информацию о пакете | `yay -Qi название_пакета` |
| Очистка кэша сборки | `yay -Scc` |

Пример установки программы из AUR (Google Chrome):

```bash
yay -S google-chrome
```

**Интеграция с GNOME**

Вариант А — графическое управление через Octopi или Pamac (оба видят AUR):

```bash
yay -S pamac-all
```

После этого в графическом менеджере пакетов видно, откуда взят пакет (официальный репозиторий или AUR). Удалять и обновлять также можно из GUI.

Вариант Б — GNOME Software не видит AUR напрямую. Обновления `yay -Syu` запускаются в терминале; можно создать скрипт:

```bash
echo '#!/bin/bash' > ~/update.sh
echo 'yay -Syu' >> ~/update.sh
chmod +x ~/update.sh
```

**Безопасность**

Пакеты из AUR не проверяются официально. Устанавливайте только те, у которых много голосов (votes) и давно не было жалоб. По возможности проверяйте PKGBUILD перед установкой.

**Обновление системы**

В отличие от `pacman -Syu`, yay также обновит пакеты из AUR:

```bash
yay -Syu
```

## paru — альтернативный AUR-хелпер

paru — AUR-хелпер для Arch Linux, написанный на Rust.

**Сравнение yay и paru**

| Критерий | yay | paru |
| --- | --- | --- |
| Язык | Go | Rust |
| Разработчик | Jguer | Morganamilo |
| Вес | Тяжелее (~20 MB) | Легче (~5 MB) |
| Скорость | Чуть медленнее | Чуть быстрее |
| Зависимости | Только Go | Только Rust |
| Настройка | Минимальная | Гибкая (конфиг) |
| Поведение по умолчанию | Спрашивает подтверждение | `--sudoloop` по умолчанию |
| Поддержка pkgbuild | Полная | Полная |
| Установка | `sudo pacman -S yay` | `sudo pacman -S paru` |
| Актуальность | Стабильный, редко обновляется | Активно развивается |
| Команды | `yay -Syu`, `yay -S` | `paru -Syu`, `paru -S` |

**Установка paru**

1. Установите `base-devel` и `git`:

```bash
sudo pacman -S --needed base-devel git
```

2. Склонируйте и соберите:

```bash
git clone https://aur.archlinux.org/paru.git
cd paru
makepkg -si
```

`makepkg -si` сгенерирует пакет и установит его (`-i`) вместе со всеми необходимыми зависимостями (`-s`).

**Конфигурация paru**

Расположение конфигурационного файла:

1. Системный файл (глобальный): `/etc/paru.conf`
2. Пользовательский файл (рекомендуемый): `~/.config/paru/paru.conf`

Для создания пользовательского файла можно скопировать системный:

```bash
mkdir -p ~/.config/paru && cp /etc/paru/paru.conf ~/.config/paru/paru.conf
```

Для редактирования используется любой текстовый редактор:

```bash
nano ~/.config/paru/paru.conf
```

**Настройки по умолчанию: `[options]`**

Все настройки, касающиеся самого paru, находятся в блоке `[options]`. Чтобы включить опцию, обычно достаточно раскомментировать соответствующую строку (убрать символ `#` в начале):

```conf
[options]
# Цветной вывод. Важно: чтобы эта опция работала, цвет должен быть также включен в файле /etc/pacman.conf (строкой "Color").
Color

# Показывать статистику по пакетам из AUR при обновлении (например, голоса за пакет).
#NewsOnUpgrade

# Изменить порядок выдачи результатов поиска.
# По умолчанию наиболее релевантный пакет показывается сверху. Эта опция переворачивает список,
# и самый релевантный пакет оказывается внизу.
#BottomUp

# Автоматически удалять зависимости, которые не нужны другим пакетам, после установки.
#RemoveMake

# После обновления задавать вопрос об удалении пакетов-зависимостей, которые больше не нужны.
RemoveMake=ask

# Работать только с репозиториями AUR, игнорируя официальные репозитории pacman.
#AurOnly

# Совмещать обновление пакетов из репозиториев и AUR в одном процессе.
#CombinedUpgrade

# Показывать меню выбора пакетов при обновлении.
#UpgradeMenu

# Запрашивать пароль sudo интерактивно, без необходимости вводить его через sudo -v.
#SudoLoop

# Автоматически очищать кэш собранных пакетов после установки.
#CleanAfter
```

**Полезные советы**

- **Порядок выдачи результатов поиска (`BottomUp`).** Это одна из самых популярных настроек. Если привычен порядок, при котором подходящий пакет показывается внизу (как в yay), включите эту опцию.
- **Синтаксис подсветки PKGBUILD.** Чтобы при просмотре файла `PKGBUILD` перед установкой видеть подсветку синтаксиса, установите пакет `bat` — paru использует его автоматически.
- **Управление пакетами `-git`.** Для пакетов из AUR, которые обновляются прямо из Git-репозиториев (имена заканчиваются на `-git`), выполните команду `paru --gendb`, чтобы paru «видел» уже установленные такие пакеты.

После установки любые программы из сообщества, включая те, которых нет в официальных репозиториях, устанавливаются через `paru -S <имя_пакета>`: например, `paru -S google-chrome` или `paru -S visual-studio-code-bin`.
