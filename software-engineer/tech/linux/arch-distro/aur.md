Короткий ответ: **AUR** — это репозиторий, а **yay** — это программа-помощник для установки оттуда. Их нужно не «включать» в GNOME, а **установить и настроить**.

Ниже — четкая инструкция для Arch Linux + GNOME.

---

## AUR


### 1️⃣ Что такое AUR и зачем нужен yay?

**AUR (Arch User Repository)** — это сообщество пользователей Arch. Там лежат скрипты сборки (`PKGBUILD`) для программ, которых нет в официальных репозиториях (например, Яндекс.Браузер, Google Chrome, Zoom, многие драйверы и темы).

**yay** (Yet Another Yogurt) — это помощник, который автоматизирует установку из AUR: сам скачивает скрипт, собирает пакет, устанавливает и разрешает зависимости.

**Важно:** В GNOME нет «кнопки включить AUR». AUR работает через терминал.

---

## yay

### 2️⃣ Установка yay в Arch

#### Шаг 1. Убедитесь, что установлены базовые инструменты для сборки

```bash
sudo pacman -S --needed base-devel git
```

#### Шаг 2. Клонируем репозиторий yay и собираем

```bash
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si
```

Параметр `-si` означает:

- `-s` — установить зависимости
- `-i` — после сборки сразу установить

После этого yay готов к работе.

#### Шаг 3. Проверка

```bash
yay --version
```

Если видите версию — всё ок.

---

### 3️⃣ Как пользоваться yay (базовые команды)

| Действие | Команда |
| :--- | :--- |
| **Поиск программы** (и в AUR, и в официальных репах) | `yay -S имя_пакета` |
| **Поиск только по названиям** | `yay имя_пакета` |
| **Установка из AUR** | `yay -S название_из_aur` |
| **Обновление всех пакетов (официальные + AUR)** | `yay -Syu` |
| **Удаление пакета** | `yay -Rns название_пакета` |
| **Показать информацию о пакете** | `yay -Qi название_пакета` |
| **Очистка кэша сборки** | `yay -Scc` |

**Пример установки программы из AUR (Google Chrome):**

```bash
yay -S google-chrome
```

---

### 4️⃣ Интеграция с GNOME (чтобы не лазить в терминал если не хочется)

#### Вариант А. Узнать, установлена ли программа через AUR, из GUI

Установите **Octopi** или **Pamac** (оба видят AUR):

```bash
# Или Pamac (GTK, выглядит родным для GNOME)
yay -S pamac-all
```

После этого в графическом менеджере пакетов будет видно, откуда взят пакет (официальный репозиторий или AUR). Удалять и обновлять тоже можно из GUI.

#### Вариант Б. Использовать GNOME Software для уведомлений об обновлениях AUR

К сожалению, GNOME Software **не видит AUR** напрямую. Но обновления `yay -Syu` всё равно нужно запускать в терминале. Можно создать простой скрипт:

```bash
echo '#!/bin/bash' > ~/update.sh
echo 'yay -Syu' >> ~/update.sh
chmod +x ~/update.sh
```

И запускать его двойным кликом (но терминал всё равно откроется).

### 5️⃣ Частые вопросы

#### ❓ Нужно ли что-то отдельно включать в GNOME, чтобы работал AUR?

**Нет.** AUR работает на уровне пакетного менеджера, а не окружения рабочего стола.

#### ❓ Безопасно ли использовать AUR?

**Средне.** Пакеты из AUR не проверяются официально. Ставьте только те, у которых много голосов (votes) и давно не было жалоб. По возможности проверяйте `PKGBUILD` перед установкой.

#### ❓ Как обновлять всё разом (официальные + AUR)?
```bash
yay -Syu
```

В отличие от `pacman -Syu`, yay также обновит пакеты из AUR.

---

### 📋 Итог (краткая памятка)

1. Устанавливаем `base-devel` и `git`
2. Клонируем yay из AUR и собираем через `makepkg -si`
3. Пользуемся `yay -S название_пакета` для установки из AUR
4. Для обновления системы с учётом AUR → `yay -Syu`
5. При желании ставим Pamac или Octopi для графического управления

Теперь на Arch + GNOME вы можете устанавливать любые программы из сообщества, включая те, которых нет в официальных репозиториях.

## paru

### Yay vs Paru: краткое сравнение

Оба являются AUR-хелперами для Arch Linux, но отличаются подходом и реализацией.

| Критерий | **Yay** | **Paru** |
| :--- | :--- | :--- |
| **Язык** | Go | Rust |
| **Разработчик** | Jguer | Morganamilo |
| **Вес** | Тяжелее (~20 MB) | Легче (~5 MB) |
| **Скорость** | Чуть медленнее | Чуть быстрее |
| **Зависимости** | Только Go | Только Rust |
| **Настройка** | Минимальная | Гибкая (конфиг) |
| **Поведение по умолчанию** | Спрашивает подтверждение | `--sudoloop` по умолчанию |
| **Поддержка pkgbuild** | Полная | Полная |
| **Установка** | `sudo pacman -S yay` | `sudo pacman -S paru` |
| **Актуальность** | Стабильный, редко обновляется | Активно развивается |
| **Команды** | `yay -Syu`, `yay -S` | `paru -Syu`, `paru -S` |

#### 💡 Что выбрать?

- **Yay** — если вы привыкли к нему, он проверен годами и стабилен.
- **Paru** — если вы хотите что-то более современное, быстрое и гибкое, написанное на Rust.

Оба отлично справляются с задачами, оба поддерживают AUR и официальные репозитории. Разница в основном в идеологии и мелочах.

**Лично я рекомендую Paru** — он быстрее, легче и имеет больше возможностей для настройки. Но если у вас уже стоит Yay и всё устраивает — не меняйте.

Установка `paru` в Arch Linux — это простой двухэтапный процесс. Сначала вы устанавливаете инструменты для сборки, а затем собираете сам `paru` из Arch User Repository (AUR) .

### 📦 установка paru

1. **Установите `base-devel` и `git`.** Это необходимые инструменты для компиляции программ из исходного кода .
    ```bash
    sudo pacman -S --needed base-devel git
    ```

2. **Склонируйте и соберите `paru`.** Следующие команды загрузят исходный код и установят AUR-хелпер .
    ```bash
    git clone https://aur.archlinux.org/paru.git
    cd paru
    makepkg -si
    ```
    - **`makepkg -si`**: сгенерирует пакет и установит его (`-i`) вместе со всеми необходимыми зависимостями (`-s`) .

#### ⚙️ Настройка и использование

После установки вы можете настроить `paru` под свои нужды.

- **Файлы конфигурации**: Основной файл — `/etc/paru.conf`, но вы можете создать пользовательский файл `~/.config/paru/paru.conf`, чтобы ваши настройки не перезаписывались при обновлениях системы . Документацию по всем опциям можно посмотреть в man-странице: `man paru.conf` .
- **Основные команды**:
    - **Обновить систему**: `paru` или `paru -Syu` .
    - **Установить пакет**: `paru -S <имя_пакета>` .
    - **Поиск и установка**: `paru <имя_пакета>` .
- **Советы по настройке**:
    - Чтобы включить цветной вывод, убедитесь, что опция `Color` включена в `/etc/pacman.conf` .
    - Для просмотра PKGBUILD'ов с подсветкой синтаксиса установите `bat` (`paru -S bat`) .
    - Если вы используете `paru` для отслеживания `-git` пакетов, создайте базу данных: `paru --gendb` .

Теперь вы можете легко устанавливать пакеты из AUR , например: `paru -S google-chrome` или `paru -S visual-studio-code-bin`. Если в процессе возникнут вопросы, можете смело их задавать.

Типовая настройка `paru` обычно сводится к управлению конфигурационным файлом, чтобы изменить поведение поиска и обновлений по умолчанию. Основные опции касаются порядка выдачи результатов и автоматического контроля пакетов.

#### 📁 Где находится и как редактировать конфигурацию

Конфигурационный файл `paru` может находиться в двух местах. Для постоянных пользовательских настроек принято редактировать личную копию, чтобы ваши изменения не затерлись при обновлении системы.

1. **Системный файл (глобальный):** `/etc/paru.conf`
2. **Пользовательский файл (рекомендуемый):** `~/.config/paru/paru.conf`

Если вы хотите создать пользовательский файл, скопируйте системный и отредактируйте его:

```bash
mkdir -p ~/.config/paru && cp /etc/paru/paru.conf ~/.config/paru/paru.conf
```

Для редактирования используйте любой текстовый редактор, например `nano`:

```bash
nano ~/.config/paru/paru.conf
```

#### ⚙️ Настройки по умолчанию: `[options]`

В конфигурационном файле все настройки, касающиеся самого `paru`, находятся в блоке `[options]`. Чтобы включить ту или иную опцию, обычно нужно просто раскомментировать соответствующую строку (убрать символ `#` в начале). Вот ключевые параметры, которые стоит знать:

```conf
[options]
# Цветной вывод. Важно: чтобы эта опция работала, цвет должен быть также включен в файле /etc/pacman.conf (строкой "Color").
Color

# Показывать статистику по пакетам из AUR при обновлении (например, голоса за пакет).
#NewsOnUpgrade

# Изменить порядок выдачи результатов поиска.
# По умолчанию наиболее релевантный пакет показывается сверху. Эта опция переворачивает список, и самый релевантный пакет оказывается внизу.
#BottomUp

# Автоматически удалять зависимости, которые не нужны другим пакетам, после установки.
#RemoveMake

# После обновления задавать вопрос об удалении пакетов-зависимостей, которые больше не нужны.
RemoveMake=ask

# Работать только с репозиториями AUR, игнорируя официальные репозитории pacman.
#AurOnly

# Совмещать обновление пакетов из репозиториев и AUR в одном процессе.
#CombinedUpgrade

# Показывать меню выбора пакетов при обновлении.
#UpgradeMenu

# Запрашивать пароль sudo интерактивно, без необходимости вводить его через sudo -v.
#SudoLoop

# Автоматически очищать кэш собранных пакетов после установки.
#CleanAfter
```

#### 💡 Полезные советы для работы с `paru`

- **Порядок выдачи результатов поиска (`BottomUp`):** Это одна из самых популярных настроек. Если вы привыкли, что самый подходящий пакет показывается внизу (как в `yay`), включите эту опцию.
- **Синтаксис подсветки PKGBUILD:** Чтобы при просмотре файла `PKGBUILD` перед установкой видеть синтаксис с подсветкой, установите пакет `bat`. `paru` использует его автоматически.
- **Управление пакетами `-git`:** Если вы используете пакеты из AUR, которые обновляются прямо из Git-репозиториев (имена заканчиваются на `-git`), `paru` может отслеживать их обновления. Чтобы он начал "видеть" уже установленные такие пакеты, выполните команду `paru --gendb`.

Основная суть настройки `paru` — это редактирование его конфигурационного файла для комфортной вам работы, а также знание того, что для расширенных возможностей вроде гибкой работы с PKGBUILD могут понадобиться дополнительные утилиты типа `bat` или `vifm`.
