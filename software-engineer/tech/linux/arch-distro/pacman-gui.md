В Arch Linux с GNOME можно пользоваться полноценными графическими менеджерами пакетов, которые полностью заменяют работу с терминалом.

В отличие от [[linux-distros|Ubuntu]], где графический магазин («Ubuntu Software») установлен по умолчанию и часто работает медленно, в сообществе Arch популярны лёгковесные и мощные GUI-клиенты для `pacman` и AUR.

---

## Лучший выбор для GNOME — Octopi

**Octopi** — это, пожалуй, самый популярный GUI-менеджер пакетов в мире Arch. Он написан на Qt, но отлично выглядит и работает в GNOME.

**Почему это хороший выбор:**

- **Интерфейс очень похож на Synaptic** (классический менеджер пакетов из Ubuntu) — быстрое освоение.
- **Показывает настоящий вывод терминала** во время установки (без фальшивых прогресс-баров).
- **Удобный поиск и фильтрация** пакетов: можно сортировать по статусу (установленные, только из AUR, сироты).
- **Есть иконка в трее**, которая уведомляет о новых обновлениях и становится красной, когда они доступны.
- **Полная поддержка AUR** — устанавливает программы из пользовательского репозитория без `yay`.

**Как установить:**

```bash
# Из официальных репозиториев (или AUR, если в официальных нет)
sudo pacman -S octopi

# Если нужна поддержка AUR, доустановите helper
sudo pacman -S octopi-notifier
```

После установки Octopi находится в меню приложений GNOME.

## Современная альтернатива — GuiMan

**GuiMan** — новинка 2025 года, написанная на Rust/Vue. Позиционируется как «графический интерфейс для `pacman`, который действительно работает»: разработчик создал его, потому что устал постоянно вводить команды вручную.

**Особенности:**

- **Очень быстрый и современный интерфейс** (вкладки: панель управления, установленные, обновления, сироты, группы пакетов, файлы).
- **Визуальные графы зависимостей** — наглядно видно, от чего зависит каждый пакет.
- **Интеграция с Polkit** — не нужно постоянно вводить пароль (настраивается один раз).
- **Умная очистка кэша и работа с зеркалами** ([[pacman-reflector|Reflector]] из коробки).

**Как установить:**

```bash
# Из AUR
yay -S guiman
```

Запуск: команда `guiman` в терминале или значок в меню.

## Универсальный инструмент — Bauh

Если используются не только обычные пакеты Arch, но и **[[pacman-yay-faltpak|Flatpak]]**, Snap или AppImage, то **bauh** — подходящий выбор. Это графическая программа, которая управляет сразу всеми форматами приложений в одной панели.

**Особенности:**

- Единый интерфейс для `pacman`/AUR, Flatpak, Snap, AppImage.
- Работает в трее и показывает уведомления об обновлениях для всех типов пакетов.
- Интеграция с Timeshift для создания бэкапов перед обновлениями.

**Как установить:**

```bash
# Из AUR
yay -S bauh
```

---

## Какой инструмент выбрать

| Задача | Инструмент |
| :--------------------------------------------------------------------- | :-------------- |
| Классический интерфейс «как в Ubuntu» и полную поддержку AUR | **Octopi** |
| Современный дизайн, скорость и визуальные графы зависимостей | **GuiMan** |
| Управление всеми типами пакетов (Flatpak, Snap, AppImage) в одном окне | **Bauh** |

**Рекомендация:** для GNOME лучше начать с **Octopi** — он стабильный и проверенный. Если нужно что-то более современное и визуальное, подойдёт **GuiMan**. В любом случае эти программы позволяют устанавливать и удалять приложения мышкой, как в привычных ОС.
