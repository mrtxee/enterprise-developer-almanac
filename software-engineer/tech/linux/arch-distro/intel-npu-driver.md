## Драйвер Intel NPU в Arch Linux

После чистой установки Arch Linux, чтобы задействовать NPU процессора Meteor Lake, необходимо установить несколько дополнительных компонентов. Сам по себе драйвер ядра и прошивка для NPU уже включены в стандартные пакеты ядра и `linux-firmware`, поэтому базовая поддержка может уже быть. Однако для того, чтобы приложения могли его обнаружить и использовать, потребуется **пользовательский драйвер и библиотеки** из пакета `intel-npu-driver`, а также настройка прав доступа.

Для работы NPU потребуется выполнить три основных шага: установка драйвера, настройка прав доступа и проверка.

**Установка драйвера**

Пакет `intel-npu-driver` из AUR содержит необходимый пользовательский драйвер и компоненты для взаимодействия с NPU. Проще всего установить его с помощью [[aur|AUR-хелпера]] (например, `yay` или `paru`):

```bash
yay -S intel-npu-driver
```

**Настройка прав доступа**

Устройство NPU доступно как `/dev/accel/accel0`. По умолчанию доступ к нему может быть только у `root`. Чтобы приложения могли с ним работать, необходимо добавить пользователя в группу `render`:

```bash
sudo usermod -aG render $USER
```

После этого нужно выйти из системы и зайти снова (или перезагрузиться), чтобы изменения вступили в силу.

**Проверка**

Команды ниже проверяют, что NPU обнаружен и готов к работе.

Проверка устройства:

```bash
ls -lah /dev/accel/accel0
```

Ожидаемый вывод: `crw-rw---- 1 root render 261, 0 ...`. Это подтвердит, что устройство существует и принадлежит группе `render`.

Проверка драйвера ядра:

```bash
lsmod | grep intel_vpu
```

## Запуск LLM на NPU

После установки драйвера сам по себе NPU не ускорит любую LLM. Нужно использовать специальное программное обеспечение, которое умеет с ним работать.

- **Библиотека IPEX-LLM**: официальный инструмент от Intel для ускорения LLM на их процессорах, включая NPU. Он интегрируется с популярными фреймворками, такими как `llama.cpp`, `Ollama` и Hugging Face.
- **Бэкенд OpenVINO для Ollama**: можно настроить `Ollama` для работы через бэкенд `openvino`, который имеет поддержку NPU. Это более простой способ запустить некоторые модели.

Для экспериментов можно начать с установки `ollama` и `openvino`, но поддержка NPU в экосистеме все еще активно развивается.
