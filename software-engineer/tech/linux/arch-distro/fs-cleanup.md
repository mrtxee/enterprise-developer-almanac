## Очистка файловой системы в Arch Linux

Как почистить место в корневом разделе (`/`) и домашней директории в Arch Linux с GNOME, а также настроить автоматическую очистку. Перед любыми действиями нужно **сделать бэкап важных данных**.

### Очистка корневого раздела

#### Анализ занятого места

Сначала выясняется, какие папки занимают больше всего места.

**Через `ncdu`** (интерактивный инструмент):

```bash
sudo pacman -S ncdu
sudo ncdu /
```

Используйте стрелки для навигации, `d` — удалить файл/папку, `q` — выход.

**Через стандартную команду `du`**:

```bash
sudo du -sh /* 2>/dev/null | sort -h
```

Команда покажет размер всех папок в корне, отсортированный по возрастанию.

#### Очистка кэша пакетов

**Pacman** (основной менеджер пакетов):

- Очистить кэш устаревших пакетов (оставит последние версии):
  ```bash
  sudo pacman -Sc
  ```
- Полностью очистить кэш (включая последние версии — использовать осторожно):
  ```bash
  sudo pacman -Scc
  ```

**AUR-хелперы** (если используются `yay`, `paru` и т.д.):

```bash
yay -Scc    # для yay
paru -Scc   # для paru
```

#### Удаление неиспользуемых пакетов

1. Найдите «сироты» (orphaned packages — зависимости, оставшиеся после удаления программ):
   ```bash
   pacman -Qdt
   ```
2. Если вывод не пуст, удалите их:
   ```bash
   sudo pacman -Rns $(pacman -Qdtq)
   ```

**Внимание:** перед массовым удалением проверьте каждый пакет через `pacman -Qi <имя_пакета>`, чтобы случайно не удалить что-то нужное.

#### Очистка временных файлов

- Удалите содержимое `/tmp` (временные файлы, обычно удаляются при перезагрузке):
  ```bash
  sudo rm -rf /tmp/*
  ```
- Проверьте `/var/tmp` (долгоживущие временные файлы):
  ```bash
  sudo du -sh /var/tmp
  sudo rm -rf /var/tmp/*  # если много места занято
  ```

#### Очистка логов

Большие логи могут занимать много места.

- Посмотрите, какие логи самые объёмные:
  ```bash
  sudo du -sh /var/log/* | sort -h
  ```
- Очистите старые логи (осторожно, не удаляйте активные):
  ```bash
  sudo journalctl --vacuum-size=100M  # оставить только последние 100 МБ логов
  sudo find /var/log -name "*.log" -type f -delete  # удалить все .log (не рекомендуется без проверки)
  ```

#### Проверка больших файлов

Найдите файлы больше 100 МБ в корне:

```bash
sudo find / -xdev -type f -size +100M -exec ls -lh {} \; 2>/dev/null
```

Просмотрите результат и удалите ненужные (например, старые ISO-образы, дампы).

#### Дополнительные инструменты

- **BleachBit** — графический «уборщик»:
  ```bash
  sudo pacman -S bleachbit
  bleachbit
  ```
  Позволяет безопасно очистить кэш браузеров, временные файлы и т.д.

- **fdupes** — поиск дубликатов файлов:
  ```bash
  sudo pacman -S fdupes
  fdupes -r /home /etc ...  # укажите нужные папки
  ```

#### Важные предупреждения

- **Не удаляйте вручную файлы в `/usr`, `/bin`, `/lib`, `/etc` без понимания их назначения** — это может сломать систему.
- Перед `pacman -Scc` убедитесь, что есть доступ к интернету — восстановить удалённые пакеты без сети сложно.
- Если используется `BleachBit`, не выбирайте опции, затрагивающие системные разделы или важные конфигурации.
- После очистки кэша пакетов (`pacman -Sc`) проверьте, что система загружается и все программы работают.

#### Профилактика

Чтобы проблема не повторялась:

- Раз в 1–2 месяца запускайте `pacman -Sc`.
- Периодически проверяйте `/tmp` и `/var/tmp`.
- Используйте `ncdu` для мониторинга перед установкой крупных программ.

### Очистка домашней директории

Чтобы найти и удалить большие и ненужные файлы в домашней директории, используется как интерактивный способ с программой `ncdu`, так и быстрый анализ в терминале стандартными командами `du` и `find`.

#### Быстрый анализ через терминал

- **Топ-15 самых «тяжёлых» директорий:**
  ```bash
  du -h ~/ --max-depth=1 | sort -hr | head -n 15
  ```
  Здесь `du -h` выводит размер в удобном для человека формате, `--max-depth=1` ограничивает глубину, а `sort -hr` и `head` сортируют и показывают результат.

- **Топ-20 самых больших файлов:**
  ```bash
  find ~/ -type f -exec du -Sh {} + | sort -rh | head -n 20
  ```
  `find` перебирает файлы, `du -Sh` выводит их размер в удобном формате, а `sort -rh | head` сортирует и выбирает топ результатов.

Этих двух команд обычно достаточно, чтобы быстро определить «виновника» переполненного диска.

#### Интерактивная очистка с `ncdu`

`ncdu` (NCurses Disk Usage) — мощная консольная утилита для интерактивного исследования и удаления файлов. Можно перемещаться по папкам и удалять ненужное, не запоминая сложные команды.

1. **Установка:** если `ncdu` ещё не установлена:
   ```bash
   sudo pacman -S ncdu
   ```
2. **Запуск и работа:**
   ```bash
   ncdu ~/
   ```
   При большом количестве файлов процесс может занять время. Чтобы не сканировать временные файлы, можно добавить параметр `--exclude .cache`.
3. **Навигация и удаление:** после завершения сканирования виден список всех папок и файлов, отсортированных по размеру. Клавиши для управления:
   - **Стрелки (`↑`/`↓`)** — перемещение по списку.
   - **`Enter`** — войти в выбранную папку.
   - **`]`** (закрывающая квадратная скобка) — выйти на уровень выше.
   - **`d`** — удалить выбранный файл или папку (программа запросит подтверждение).
   - **`q`** — выйти из программы.

#### Стратегии очистки домашней папки

- **Очистка кэша** (`~/.cache/`): многие приложения хранят здесь временные данные. Обычно удаление содержимого безопасно, но делать это лучше выборочно. Просмотрите содержимое с помощью `du -sh ~/.cache/*`. Удалить старые и неиспользуемые файлы кэша:
  ```bash
  find ~/.cache -depth -type f -atime +100 -delete
  ```
  Команда удалит файлы, к которым не было обращений более 100 дней.

- **Очистка корзины:** периодически очищайте корзину рабочего стола (обычно папка `~/.local/share/Trash`).
- **Удаление дубликатов:** утилита `rmlint`. Установите её (`sudo pacman -S rmlint`) и запустите в домашней папке. Программа найдёт все возможные дубликаты и предложит, что с ними сделать.
- **Управление пакетами (Cache и Orphans):**
  - Очистить кэш `pacman`: `sudo paccache -r` (оставляет 3 последние версии пакетов).
  - Удалить «осиротевшие» пакеты: `sudo pacman -Rns $(pacman -Qtdq)`.
- **Другие папки для проверки:** большие объёмы данных могут храниться и в других скрытых папках, например `~/.local/` (особенно при использовании `flatpak`), `~/.config/` (конфиги) или `~/.mozilla/` / `~/.cache/chromium/` (кэш и профили браузеров).

### Автоматическая очистка

Автоматическая очистка системы в Arch Linux — это комбинация инструментов, каждый из которых отвечает за свою область.

#### Очистка кэша пакетов

Кэш пакетов в `/var/cache/pacman/pkg/` имеет свойство быстро разрастаться. Для его автоматической очистки используется утилита `paccache` из пакета `pacman-contrib`.

- **Установка:** `sudo pacman -S pacman-contrib`.
- **Настройка:** по умолчанию `paccache` хранит **3 последние версии** каждого пакета. Это число можно изменить, отредактировав файл `/etc/conf.d/pacman-contrib`. Например, чтобы хранить только **1** последнюю версию, добавьте туда строку `PACCACHE_ARGS='-k1'`.
- **Автоматический запуск:** включите системный таймер для еженедельной очистки:
  ```bash
  sudo systemctl enable --now paccache.timer
  ```

#### Очистка кэша сразу после обновления (Pacman Hook)

Метод дополняет предыдущий, запуская очистку сразу после каждой операции с пакетами.

Создайте хук в `/etc/pacman.d/hooks/`, например файл `/etc/pacman.d/hooks/paccache-clean.hook`:

```ini
[Trigger]
Operation = Install
Operation = Upgrade
Type = Package
Target = *

[Action]
Description = Очистка кэша pacman...
When = PostTransaction
Exec = /usr/bin/paccache -rvk2
```

Хук после каждого обновления оставит только 2 последние версии пакетов (`-k2`).

#### Удаление «осиротевших» пакетов

Пакеты, которые были установлены как зависимости, но больше не нужны ни одной программе, называются «orphans».

Их можно найти и удалить:

```bash
sudo pacman -Rns $(pacman -Qtdq) 2>/dev/null
```

Команду можно добавить в пользовательский скрипт или запускать вручную. Существуют готовые скрипты, которые автоматизируют этот процесс.

#### Очистка временных и кэш-файлов пользователя

- **Системные временные файлы:** за это отвечает служба `systemd-tmpfiles`. Она автоматически очищает каталоги вроде `/tmp` и `/var/tmp` согласно настройкам в `/usr/lib/tmpfiles.d/` и `/etc/tmpfiles.d/`. Включите таймер, если он ещё не активен: `sudo systemctl enable --now systemd-tmpfiles-clean.timer`.
- **Кэш пользователя (`~/.cache/`):** для безопасной очистки можно использовать скрипты, которые удаляют файлы, к которым не было доступа более 30 дней:
  ```bash
  find ~/.cache -type f -atime +30 -delete
  ```
  Эту команду также можно добавить в пользовательский скрипт автоматической очистки.

#### Очистка кэша AUR-помощников (yay, paru и др.)

AUR-помощники тоже имеют свой кэш.

- **Для yay:** `yay -Scc` или `yay -Sccc` для более агрессивной очистки.
- **Для paru:** `paru -Scc`.

Эти команды можно добавить в скрипт обслуживания.

#### Комплексный подход

Можно объединить все команды в один скрипт и запускать его по расписанию. В сообществе Arch Linux есть много готовых примеров. Скрипт может включать:

1. Обновление системы (`pacman -Syu`).
2. Очистку кэша (`paccache -r`).
3. Удаление осиротевших пакетов (`pacman -Rns $(pacman -Qtdq)`).
4. Очистку кэша AUR-помощника.
5. Очистку пользовательского кэша (`find ~/.cache -type f -atime +30 -delete`).

#### Краткий итог

Для типичной настройки автоматической очистки в Arch Linux достаточно:

1. Установить `pacman-contrib` и включить `paccache.timer`.
2. (Опционально) Создать Pacman Hook для очистки после каждого обновления.
3. Добавить в скрипт обслуживания команду для удаления осиротевших пакетов.

Для более глубокой автоматизации, например очистки кэша пользователя, можно изучить готовые скрипты или создать свой собственный, следуя приведённым выше принципам.
