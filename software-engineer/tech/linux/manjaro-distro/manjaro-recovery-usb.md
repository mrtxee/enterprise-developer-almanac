## Восстановление Manjaro через USB

**Manjaro** — это дистрибутив с плавающими обновлениями (rolling release): обновления пакетов и ядра приходят постоянно. Из-за этого в системе иногда случаются серьёзные сбои — например, система перестаёт загружаться после обновления ядра. Для восстановления используется **загрузочная USB-флешка** с образом Manjaro.

## Что такое восстановление

- Процесс создания загрузочной флешки с исправным образом Manjaro.
- Используется, когда основная система не загружается.
- Позволяет попасть в рабочее окружение и восстановить загрузчик или файлы.

**Что понадобится**

- Флешка (от 8 ГБ, лучше быстрее).
- ISO-образ Manjaro с официального сайта.
- Программа для записи: `dd`, `balenaEtcher`, `Ventoy`, `GNOME Disks`.
- Знание модели ноутбука (для выбора режима встроенной клавиатуры прокрутки не требуется, но фирменная раскладка ускоряет работу).

**Что может пойти не так**

- После обновления ядра система не загружается — нужен chroot с загрузочной флешки.
- Испорчен загрузчик GRUB — нужно переустановить или включить восстановление через BIOS-настройки.
- Случайно выбранная файловая система в установщике — повторная установка с нуля.

## Метод 1: запись через dd

Самый надёжный и быстрый способ — записать образ напрямую в устройство:

```bash
dd if=manjaro.iso of=/dev/sdX bs=4M status=progress
sync
```

- `if=` — файл образа.
- `of=` — устройство флешки (без цифры в конце!).
- `bs=4M` — размер блока (ускорение).
- `status=progress` — показывать прогресс.
- `sync` — принудительная запись кэша.

## Метод 2: запись через balenaEtcher

`balenaEtcher` — графическая программа с простым интерфейсом:

1. Скачать `balenaEtcher` с официального сайта (есть версия для Linux).
2. Выбрать ISO-образ и флешку.
3. Нажать **Flash** и дождаться завершения.
4. После записи флешка готова.

**Примечание:** после записи может появиться желание «отформатировать диск» — это нормально для Etcher; не нужно, образ записан.

## Метод 3: запись через Ventoy

`Ventoy` — мультизагрузчик: образы просто копируются на флешку, без перезаписи.

1. Установить Ventoy на флешку один раз.
2. Скопировать ISO-файлы в корень флешки.
3. При загрузке выбрать нужный ISO из меню Ventoy.

```text
/my-usb/
├── manjaro.iso
├── ubuntu.iso
└── arch.iso
```

## Метод 4: запись через GNOME Disks

`GNOME Disks` есть почти во всех GNOME-дистрибутивах:

1. Открыть *GNOME Disks* (утилита «Диски»).
2. Выбрать флешку в списке слева.
3. Нажать на «гамбургер» (меню) в верхнем правом углу и выбрать *Restore Disk Image…*.
4. Выбрать ISO-образ и подтвердить восстановление.

## Восстановление системы с загрузочной флешки

Для восстановления загрузчика GRUB после обновления ядра:

1. Загрузиться с флешки (выбрать в Boot Menu — обычно `F12`, `F11` или `Esc`).
2. Открыть терминал и найти корневой раздел:

```bash
lsblk
```

1. Смонтировать корень и остальные разделы:

```bash
mount /dev/sda2 /mnt
mount /dev/sda1 /mnt/boot
mount --bind /dev /mnt/dev
mount --bind /proc /mnt/proc
mount --bind /sys /mnt/sys
```

1. Войти в окружение восстановления (chroot):

```bash
chroot /mnt /bin/bash
```

1. Переустановить загрузчик:

```bash
grub-install /dev/sda
grub-mkconfig -o /boot/grub/grub.cfg
```

1. Обновить ядро внутри chroot, если причина сбоя — обновление ядра:

```bash
pacman -Syu linux linux-headers
```

1. Выйти из chroot и перезагрузиться:

```bash
exit
umount -R /mnt
reboot
```

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| Флешка не загружается | Проверить Boot Order; для старых плат отключить Secure Boot |
| Ошибка `dd: permission denied` | Выполнять `dd` через `sudo` или от root |
| Путаница с именем устройства | Перед записью проверить `lsblk`, не перепутать флешку и системный диск |
| Система грузится в ACPI от старого ядра | После загрузки обновить пакеты и ядро в `pacman -Syu` |

## Итог

- Загрузка с флешки — штатный способ восстановления Manjaro после сбоя обновления.
- Для записи подходят `dd`, `balenaEtcher`, `Ventoy` и `GNOME Disks`.
- Восстановление сводится к `chroot` и переустановке загрузчика через `grub-install`.
- Дополнительно, если обновилось ядро, выполняется `pacman -Syu` внутри chroot.
