Чтобы создать **загрузочную USB-флешку из образа `manjaro-gnome-26.0.4-260327-linux618.iso` в Arch Linux**, выполните следующие шаги.

> 💡 Цель: записать ISO-образ так, чтобы флешка стала **загрузочной** и могла использоваться для установки Manjaro GNOME.

---

## ✅ Способ 1: Использование `dd` (просто и надёжно)

### 🔧 Шаг 1: Подключите USB-фешку

Вставьте флешку в USB-порт.

### 🔧 Шаг 2: Определите устройство

Выполните:

```bash
lsblk
```

Найдите свою флешку. Обычно это:

- `/dev/sdX` — для USB-флешек на SATA/USB (например, `/dev/sdb`)
- `/dev/nvme0n1` — это **не флешка**, это SSD
- Ищите по размеру (например, 8 ГБ, 16 ГБ и т.д.)

> ⚠️ **Очень важно не перепутать устройство** Запись по `dd` **удалит все данные** на указанном диске.

Пример: флешка — `/dev/sdb` (не `/dev/sdb1`!)

### 🔧 Шаг 3: Запишите образ с помощью `dd`

```bash
sudo dd if=manjaro-gnome-26.0.4-260327-linux618.iso of=/dev/sdX bs=4M status=progress oflag=sync
```

> 🔁 Замените `/dev/sdX` на ваше устройство (например, `/dev/sdb`)

### 🔍 Пояснение параметров:
- `if=` — input file (входной ISO-файл)
- `of=` — output file (устройство флешки)
- `bs=4M` — блоки по 4 МБ — ускоряет запись
- `status=progress` — показывает прогресс
- `oflag=sync` — синхронная запись, безопаснее

### 🔧 Шаг 4: Дождитесь завершения

Когда команда завершится (может занять 2–5 минут), отключите флешку:

```bash
sudo eject /dev/sdX
```

## ✅ Способ 2: Использование `balena-etcher` (графический, удобный)

Если хотите **графический интерфейс**:

### 1. Установите **balenaEtcher**:

```bash
yay -S balena-etcher
```

> Или скачайте с [https://www.balena.io/etcher/](https://www.balena.io/etcher/)

### 2. Запустите:
```bash
etcher
```

### 3. Выберите:
- ISO-файл: `manjaro-gnome-26.0.4-260327-linux618.iso`
- Устройство: ваша флешка
- Нажмите **Flash**

Etcher сам проверит и запишет образ безопасно.

## ✅ Способ 3: `ventoy` (если хотите мультизагрузочную флешку)

Хотите **хранить несколько ISO** на одной флешке? Используйте **Ventoy**:

1. Скачайте Ventoy с [https://www.ventoy.net](https://www.ventoy.net)
2. Установите на флешку:
   ```bash
   sudo sh Ventoy2Disk.sh -i /dev/sdX
   ```
3. Скопируйте ISO-файл в корень флешки:
   ```bash
   cp manjaro-gnome-26.0.4-260327-linux618.iso /run/media/$USER/VENTOY/
   ```
4. Перезагрузитесь — Ventoy покажет меню выбора ISO.

---

## ⚠️ Важно: не используйте `mkfs` перед `dd`

- **Не форматируйте флешку** перед записью ISO.
- ISO-образ содержит свою собственную разметку и загрузчик.
- `dd` перезапишет всё — форматирование не нужно.

---

## ✅ Проверка: загрузится ли?

1. Вставьте флешку в целевой компьютер.
2. Перезагрузитесь.
3. Зайдите в **Boot Menu** (обычно F12, F10, Esc при включении).
4. Выберите флешку.
5. Должен запуститься **загрузчик Manjaro** с выбором: Live, Install и т.д.

## ✅ Поддержка ISO-образов в GNOME Disks 46.1

Начиная с версии **40+**, `gnome-disk-utility` (также известный как **Disks**) получил **встроенную функцию записи ISO-образов на USB-устройства** — без необходимости использовать сторонние инструменты вроде `dd` или `balenaEtcher`.

Версия **46.1** — **полностью поддерживает** эту функцию и отлично работает с **Manjaro, Ubuntu, Fedora** и другими дистрибутивами.

---

## 🔧 Как создать загрузочную флешку в GNOME Disks 46.1

### 1. Откройте **GNOME Disks**
- Найдите в меню: «Диски» (Disks) или запустите:
  ```bash
  gnome-disks
  ```

### 2. Вставьте USB-флешку
- Убедитесь, что она определилась (например, как `/dev/sdb` или `/dev/mmcblk0`).

### 3. Выберите USB-устройство в левом меню
- Нажмите на него (не на разделы, а на сам диск).

### 4. Нажмите на значок меню (три точки) → **«Восстановить образ диска»**

   (в оригинале: *Restore Disk Image*)

### 5. Выберите ISO-файл
- Укажите путь к `manjaro-gnome-26.0.4-260327-linux618.iso`
- Убедитесь, что выбран **именно файл `.iso`**, а не архив.

### 6. Подтвердите запись
- Система предупредит, что **весь диск будет перезаписан**.
- Нажмите «Начать восстановление» → подтвердите.

### 7. Дождитесь завершения
- Прогресс-бар покажет ход записи.
- После завершения — можно извлекать флешку.

## ✅ Почему это работает с Manjaro?

- Образ `manjaro-gnome-...iso` — это **стандартный гибридный ISO**, совместимый с:
  - Записью через `dd`
  - Загрузкой по UEFI и Legacy BIOS
  - Автоматическим распознаванием в GNOME Disks
- GNOME Disks 46.1 корректно обрабатывает такие образы и **сохраняет загрузочную способность**.

## ✅ Альтернатива (если Disks не видит ISO)

Если по какой-то причине Disks **не открывает ISO**, проверьте:

- Файл не повреждён: `sha256sum manjaro-gnome-...iso`
- У вас есть права на чтение файла
- Попробуйте открыть через **«Открыть» → «Образ диска»** в меню Disks

Если не помогает — используйте `dd` (в терминале):

```bash
sudo dd if=manjaro-gnome-26.0.4-260327-linux618.iso of=/dev/sdX bs=4M status=progress oflag=sync
```

(где `/dev/sdX` — ваша флешка, например `/dev/sdb` — **не `/dev/sdb1`**)
