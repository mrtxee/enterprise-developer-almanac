## Что такое EFI

**EFI (Extensible Firmware Interface)** — это интерфейс прошивки, разработанный компанией Intel в 1990‑х годах для замены устаревшего BIOS. Изначально создавался для серверов на архитектуре Itanium, где требовалась более гибкая и масштабируемая система инициализации оборудования.

## Основные функции EFI

- инициализация аппаратного обеспечения при включении компьютера;
- тестирование компонентов системы (аналог POST в BIOS);
- загрузка операционной системы;
- предоставление сервисов для ОС (работа с файловыми системами, сетью и т. д.);
- поддержка EFI‑приложений — программ, которые могут запускаться до загрузки ОС (диагностические утилиты, установщики и пр.).

## Ключевые особенности EFI

- **32‑ или 64‑битный режим работы** (в отличие от 16‑битного режима BIOS), что даёт больше возможностей и производительности.
- **Модульная архитектура** — прошивка состоит из набора драйверов и сервисов, загружаемых по мере необходимости. Например, если нет USB‑мыши, соответствующий драйвер не загружается, экономя ресурсы.
- **Поддержка [[mbr-gpt|GPT]]** (GUID Partition Table) вместо [[mbr-gpt|MBR]], что позволяет работать с дисками объёмом более 2,2 ТБ.
- **Раздел [[partitions|ESP]]** (EFI System Partition) — специальный раздел на диске (обычно FAT32), где хранятся загрузчики, драйверы и другие EFI‑приложения.
- **Сетевые возможности**, включая поддержку PXE для удалённой загрузки.
- **API для взаимодействия ОС с прошивкой** — операционная система может использовать сервисы EFI даже после загрузки.
- **Оболочка EFI** (UEFI Shell) — командная среда, позволяющая выполнять команды, запускать приложения, работать с файлами и сетью до загрузки ОС.

## EFI vs UEFI: в чём разница

Хотя термины часто используют как синонимы, между ними есть различия.

| Параметр | EFI | UEFI |
|---|---|---|
| Происхождение | Разработан Intel для Itanium | Открытый стандарт, развиваемый UEFI Forum (Intel, AMD, Microsoft, Apple и др.) |
| Стандартизация | Недостаточно стандартизирован, приводил к несовместимости между производителями | Регулярно обновляется (версии 2.0, 2.3, 2.7 и т. д.), имеет чёткую документацию |
| Масштабируемость | Привязан к архитектуре Itanium | Поддерживает x86, x86_64, ARM и другие платформы |
| Экосистема | Ограниченная поддержка сторонних приложений | Развитая система сертификации, инструменты разработки, сторонние утилиты |
| Дополнительные функции | Базовые возможности | Secure Boot, поддержка HTTPS, TPM, Measured Boot и др. |

**Важно:** в современной практике термин **UEFI (Unified Extensible Firmware Interface)** практически полностью заменил EFI. Когда говорят о «EFI» в контексте современных ПК, обычно имеют в виду UEFI.

## Как работает загрузка через UEFI/EFI

1. При включении питания прошивка инициализирует оборудование.
2. Проверяется состояние [[bios-uefi|Secure Boot]] (если включён) — проверяются цифровые подписи загрузчиков.
3. Прошивка ищет **ESP** (EFI System Partition) на диске.
4. Запускается загрузчик из ESP (например, `bootmgfw.efi` для Windows или `grubx64.efi` для Linux).
5. Загрузчик передаёт управление операционной системе.

## Важные компоненты UEFI/EFI

- **ESP (EFI System Partition)** — раздел FAT32 на диске с GUID `C12A7328-F81F-11D2-BA4B-00A0C93EC93B` (в GPT) или типом `0xEF` (в MBR). Содержит файлы загрузчиков и приложений.
- **[[NVRAM|NVRAM]]** — энергонезависимая память, где хранятся настройки загрузки (порядок устройств, параметры Secure Boot и т. д.).
- **Secure Boot** — технология проверки цифровых подписей загрузчиков и драйверов. Предотвращает запуск вредоносного кода на этапе загрузки.
- **UEFI Shell** — командная оболочка, позволяющая выполнять операции до загрузки ОС: диагностику, настройку, обновление прошивки, копирование файлов и т. п.

## Итог

- **EFI** — оригинальная разработка Intel для серверов Itanium, заложившая основы современной прошивки.
- **UEFI** — эволюция EFI: стандартизированный, масштабируемый и безопасный интерфейс, используемый сегодня в большинстве компьютеров, ноутбуков, серверов и даже мобильных устройств.
- [[bios-uefi|UEFI]] решает ключевые проблемы [[bios-uefi|BIOS]]: ограничения по размеру дисков, медленную загрузку, отсутствие защиты и сложности с расширением функциональности.
