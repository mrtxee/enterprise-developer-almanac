**XF86-клавиши** (или мультимедийные клавиши) — это специальные клавиши на современных клавиатурах и ноутбуках, которые управляют не вводом текста, а системными функциями: громкостью, яркостью экрана, воспроизведением музыки, калькулятором и т.д.

## Почему они так странно называются?

Название **XF86** — это историческое наследие. Оно расшифровывается как **XFree86** (предшественник современной графической системы X.Org). Когда в 90-х годах на клавиатурах начали появляться новые мультимедийные кнопки, стандартные коды клавиш (ASCII/PC) не имели для них обозначений. Разработчики XFree86 создали новый набор кодов с префиксом `XF86`, и это название закрепилось в ядре Linux и графических серверах, даже несмотря на переход к Wayland.

## Самые распространенные XF86-клавиши

Вот как они называются в системе (именно эти имена нужно использовать в конфигурационных файлах):

**Аудио:**

* `XF86AudioRaiseVolume` (Громкость +)
* `XF86AudioLowerVolume` (Громкость -)
* `XF86AudioMute` (Выключить звук)
* `XF86AudioPlay` / `XF86AudioPause` (Воспроизведение/Пауза)
* `XF86AudioNext` / `XF86AudioPrev` (Следующий/Предыдущий трек)

**Экран и питание:**

* `XF86MonBrightnessUp` (Яркость +)
* `XF86MonBrightnessDown` (Яркость -)
* `XF86Sleep` (Спящий режим)
* `XF86PowerOff` (Кнопка питания)

**Прочие:**

* `XF86Calculator` (Кнопка калькулятора)
* `XF86Mail` (Кнопка почты)
* `XF86HomePage` (Кнопка "Домой" в браузере)
* `XF86TouchpadToggle` (Отключение тачпада на некоторых ноутбуках)

## Как использовать XF86-клавиши в Niri (Wayland)

В Niri вы можете назначить эти клавиши на выполнение команд. Поскольку в Niri нет встроенного управления громкостью или яркостью, вам понадобятся сторонние утилиты.

**1. Установите необходимые утилиты:**

```bash
# Для управления звуком (PipeWire, стандарт в Arch)
sudo pacman -S wireplumber

# Для управления яркостью
sudo pacman -S brightnessctl
```

**2. Добавьте привязки в `~/.config/niri/config.kdl`:**

```kdl
binds {
    // --- Громкость (используем wpctl для PipeWire) ---
    "XF86AudioRaiseVolume" { spawn "wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+"; }
    "XF86AudioLowerVolume" { spawn "wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-"; }
    "XF86AudioMute"        { spawn "wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle"; }

    // --- Яркость экрана ---
    "XF86MonBrightnessUp"   { spawn "brightnessctl set +5%"; }
    "XF86MonBrightnessDown" { spawn "brightnessctl set 5%-"; }

    // --- Управление медиа (работает в Spotify, Firefox, VLC и т.д.) ---
    "XF86AudioPlay"  { spawn "playerctl play-pause"; }
    "XF86AudioNext"  { spawn "playerctl next"; }
    "XF86AudioPrev"  { spawn "playerctl previous"; }
}
```

*(Для `playerctl` потребуется установить пакет `playerctl` через pacman).*

**3. Перезагрузите конфиг:** `Super + Shift + R`.

## Как узнать точное имя клавиши, если она не работает?

Иногда производители ноутбуков используют нестандартные коды. Чтобы узнать, как система видит нажатие конкретной клавиши:

**Способ 1: В графическом интерфейсе (Wayland)**

Установите утилиту `wev` (Wayland Event Viewer):

```bash
sudo pacman -S wev
wev
```

Откроется окно. Нажмите нужную клавишу (например, кнопку яркости). В терминале вы увидите событие, например: `sym: XF86MonBrightnessUp, code: 224`.

**Способ 2: В чистой консоли (TTY)**

Если клавиша не работает даже в терминале, переключитесь в TTY (`Ctrl + Alt + F3`), войдите в систему и введите:

```bash
sudo showkey -k
```

Нажмите клавишу. Вы увидите её scancode и keycode. Если `showkey` ничего не выдает, значит, клавиша аппаратно заблокирована или требует специальной обработки ядром (часто бывает с кнопками режимов работы ноутбука, например, Fn+Fx).

## Резюме

XF86 — это просто стандартные имена для мультимедийных кнопок. В тайловых композиторах (Niri, Sway, Hyprland) они **не работают по умолчанию**. Вы должны явно прописать их в конфиге, связав с командами вроде `wpctl` или `brightnessctl`.
