## SSH

- **Полное название:** Secure Shell.
- **Зачем нужен:** для **удаленного управления** сервером или компьютером через командную строку (терминал).
- **Суть:** это фундамент. Он создает защищенный зашифрованный канал связи, через который можно выполнять команды на удаленной машине так, будто сидишь за её клавиатурой.

## SCP

- **Полное название:** Secure Copy Protocol.
- **Зачем нужен:** для **простого и быстрого копирования** файлов между компьютерами.
- **Суть:** работает поверх SSH. Это аналог команды `cp` (copy), но для сети: «возьми файл А отсюда и положи в место Б».
- **Ограничение:** не интерактивен. Нельзя посмотреть список файлов на сервере, удалить или переименовать файл через SCP. Только копирование.

## SFTP

- **Полное название:** SSH File Transfer Protocol (часто называют *Secure File Transfer Protocol*).
- **Зачем нужен:** для **полноценного интерактивного управления файлами** на удаленном сервере.
- **Суть:** работает поверх SSH. Это современная, зашифрованная замена старому протоколу FTP. Позволяет не только скачивать/загружать файлы, но и просматривать директории (`ls`), удалять, переименовывать файлы, создавать папки и **возобновлять** прерванную передачу.

---

**Сравнительная таблица**

| Протокол | Полное название | Главная цель | Интерактивность |
| :--- | :--- | :--- | :--- |
| SSH | Secure Shell | Удаленное выполнение команд (администрирование) | Да (полный доступ к терминалу) |
| SCP | Secure Copy Protocol | Одностороннее копирование файлов | Нет (только команда «скопировать») |
| SFTP | SSH File Transfer Protocol | Управление файлами (как в файловом менеджере) | Да (просмотр, удаление, переименование, докачка) |

---

**Когда что использовать**

| Задача | Протокол |
| :--- | :--- |
| Зайти на сервер и настроить его | SSH — `ssh user@host` |
| Быстро перекинуть файл или папку одной командой в скрипте | SCP — `scp file.txt user@host:/path` |
| Удобно работать с файлами через графический клиент (FileZilla, WinSCP) или оболочку с навигацией | SFTP — `sftp user@host` |
