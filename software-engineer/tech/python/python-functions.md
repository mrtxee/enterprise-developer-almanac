## Функциональное программирование

**Функциональное программирование** — парадигма программирования, в которой процесс вычисления трактуется как вычисление значений функций. Это способ организации вычислений без состояния. Строго говоря, состояние у такой программы конечно есть — это совокупность контекстов всех её функций.

- В Python такой стиль реализуют как пользовательские функции, так и встроенные: `lambda`, `map()`, `filter()`.

---

## Определение и вызов функций

Выделяют понятия **pure function** и **impure function**. Чистая функция — такая, которая оперирует исключительно с данными, переданными в аргументах функции. Если она берёт некие общие данные, константы и т. п., то функция уже не чистая. Применение чистых функций упрощает задачу **мемоизации** (**memoization**), то есть хранения обработанных данных вне функции, что сокращает число повторных вызовов функции.

### Аргументы функции

При описании функции можно задавать значение по умолчанию для аргументов. При вызове функции можно нарушать последовательность определения аргументов — тогда в вызове функции необходимо указывать имя аргумента.

Пример вызова функции:

```python
  def function(x, y, food="spam"):
      print(food)
  function(1, 2)
  function(3, 4, "egg")
  function(y=3, food="orange", x=4)
```

#### Переменное число аргументов

Через имена аргументов `*args`, `**kwargs`:

|  | `*args` | `**kwargs` |
| --- | --- | --- |
| Переменная | `args` | `kwargs` |
| Форма данных | [[python-data-structures|кортеж]] | словарь |

Пример переменного числа аргументов:

```python
  # дополнительные аргументы в качестве кортежа
  def adder(sum1, *args):
      for n in list(args):
          sum1 += n
      print(sum1)
  adder(2, 3)  # 5
  adder(1, 2, 3, 4, 5)  # 15
  # дополнительные аргументы в качестве словаря
  def my_func(x, y=7, *args, **kwargs):
      print(kwargs)
  my_func(2, 3, 4, 5, 6, a=7, b=8)
  # ещё один пример
  def concatenate(*args):
      return '-'.join(list(args))
  print(concatenate("I", "love", "Python", "!"))
```

#### Аннотация типов

Аннотация типов носит рекомендательный характер и не добавляет проверку при выполнении кода. Может использоваться как справочная информация для программиста, читающего код. Для того чтобы исправить этот недостаток, можно применить `mypy` — опциональный статический анализатор типов для Python, который сочетает преимущества динамической и статической типизации.

Пример аннотации типов:

```python
  def my_sqr(value: int) -> int:
      ...
  def dict_to_json(dict: dict) -> json:
      return json.dumps(dict)
```

### Рекурсия

**Рекурсия** — событие, когда метод вызывает сам себя. **Перекрёстная рекурсия** случается, когда несколько методов вызывают друг друга взаимно. Опасность рекурсии в том, что она может привести к зацикливанию программы. Чтобы этого избежать, необходимо разделить рекурсию на 2 части:

1. База рекурсии — условие выхода из рекурсии.
2. Рекурсивный вызов.

### Модули

Модули бывают встроенные в среду и пользовательские. Набор функций можно объединить в пользовательский модуль: для этого необходимо в одном файле описать все методы модуля. Имя файла до точки становится именем модуля. Для обращения к методу модуля используется форма `имя_модуля.имя_метода()`.

Для удобства можно изменить имя модуля в одном контексте кода. Для повышения производительности можно импортировать несколько методов модуля, а не весь модуль полностью.

Пример с json и http-request:

```python
  import requests
  import json
  def explore_obj(o):
      data = {
          "type": str(type(o)),
          "id": str(id(o)),
          "struct": json.loads(str(dir(o)).replace("'", '"'))
      }
      print(json.dumps(data, indent=4))
  url = 'https://wttr.in/spb'
  weather_parameters = {
      '0': '',
      'T': ''
  }
  request_headers = {
      'Accept-Language': 'ru'
  }
  response = requests.get(url, params=weather_parameters, headers=request_headers)
  explore_obj(response)
  print(response.url)
  print(response.text)
```

Пример с json и datetime:

```python
  import datetime as dt
  # библиотека datetime подключена под именем dt
  start_moment = dt.datetime(2022, 10, 10, 11, 5)
  current_moment = dt.datetime(2022, 10, 11, 12, 7)
  total_time = current_moment - start_moment
  print(total_time)
```

#### Подключение модулей с main

У главного исполняемого модуля переменная `__name__` всегда равна `"__main__"`, поэтому операции, скрытые внутри блока `if __name__ == "__main__":`, будут выполнены только если модуль запускается как главный, и не будут выполнены при импорте модуля.

Пример главного модуля:

```python
  def function():
      print("This is a module function")
  if __name__ == "__main__":
      print("This is a script")
```

Это важно, если есть потребность создавать модули, имеющие двойственную природу, то есть которые могут быть подключены либо запущены отдельно.

### Функции высшего порядка

Функция, которая принимает в качестве аргумента либо возвращает другую функцию — **Higher-order functions**. К таковым относятся `λ-функции`, `декораторы`, `map()`, `filter()`.

|  | `map()` | `filter()` |
| --- | --- | --- |
| Сигнатура | `map(function, iterable[, iterable1, iterable2, ..., iterableN])` | `filter(function, iterable)` |
| Действие | применяет функцию к каждому элементу коллекции | создаёт итератор из элементов iterable, для которых function возвращает true |

Пример функции высшего порядка:

```python
  # простой декоратор
  def decor_it(func, s='ss2'):
      def wrap():
          print("============")
          func(s)
          print("============")
      return wrap
  def any_f(s='11'):
      print("Hello world!" + s)
  # декорируем существующий метод
  decorated_f = decor_it(any_f)
  decorated_f()
```

#### Декораторы

Декоратор — функция высшего порядка, которая изменяет работу другой функции. Можно вызвать декорированный метод без обращения к декоратору напрямую. Реализуется через добавление объявления `@имя_функции-декоратора` перед объявлением декорируемой функции.

Пример декоратора:

```python
  # декоратор меняет вывод главной функции display_text()
  text = 'bla-blah'
  def uppercase_decorator(func):
      def wrapper(text):
          return func(text).upper()
      return wrapper
  @uppercase_decorator
  def display_text(text):
      return text
  print(display_text(text))
```

#### Генераторы данных

Генератор — это функция, которая может осуществлять много `return`-ов в цикле, не вызывая `break`. Объявление генератора происходит при помощи оператора `yield`. При этом оператор `yield` заменяет ~~`return`~~.

> [!important] Использование генераторов повышает производительность
> так как является результатом ленивых вычислений. Генерация значений происходит по требованию, что приводит к снижению использования памяти. Кроме того, не нужно ждать, пока все элементы будут накоплены, прежде чем начать их использовать.

Пример генератора:

```python
  # генерация чисел Фибоначчи с yield
  num = 5
  def fib(n):
      a, b = 0, 1
      for _ in range(n):
          yield a
          a, b = b, a + b
  print(list(fib(num)))
  # получение набора данных из сторонней функции в цикле при помощи yield
  def isPrime(x):  # проверка, является ли число простым
      if x < 2:
          return False
      elif x == 2:
          return True
      for n in range(2, x):
          if x % n == 0:
              return False
      return True
  def primeGenerator(a, b):
      for i in range(a, b):
          if isPrime(i):
              yield i
  f = 1
  t = 100
  generated_list = list(primeGenerator(f, t))
  print(generated_list)
```

#### Лямбда-функции

Лямбда-функции служат для имплементации **модели λ-исчисления**.

> **Лямбда-исчисление** — формальная система в математической логике для выражения вычислений, основанных на абстракции функций и применении с использованием привязки и подстановки переменных. **λ-исчисление** по мощности эквивалентно **машине Тьюринга** и определяет этот же класс функций. Любую программу, которую можно запрограммировать на вычислительном устройстве, можно воспроизвести и на машине Тьюринга. Создателем лямбда-исчисления является **Алонзо Черч #👨**. Основные понятия λ-исчисления: _переменные_, _абстракция_ (декларация функции, включающая тело и аргументы функции), _аппликация_ (применение функции к аргументу).

В Python λ-функции также называют **анонимными функциями**, потому что их главная особенность в том, что они позволяют получить результат работы функции без описания самой функции. Для вызова анонимной функции используется оператор `lambda` с конструкцией `(lambda тело_функции) (аргументы)`.

Применение λ-функций является неотъемлемой частью парадигмы функционального программирования.

Примеры λ-функций:

```python
  # λ-функции — анонимные функции
  # получаем результат при помощи λ-вычислений
  def polynomial(x):
      return x**2 + 5*x + 4
  print(polynomial(19))
  # переводим тот же код в лямбда-выражение:
  print((lambda x: x**2 + 5*x + 4)(19))
  # фильтруем коллекцию в одну строку при помощи lambda, filter()
  nums = [1, 2, 8, 3, 7]
  res = list(filter(lambda x: x % 2 == 0, nums))
  print(res)
  # меняем данные в коллекции в одну строку при помощи lambda, map()
  salaries = [2000, 1800, 3100, 4400, 1500]
  bonus = 30
  salaries = list(map(lambda num: num + bonus, salaries))
  print(salaries)
```

### Модуль itertools

Один из типов функций этого модуля — бесконечные итераторы.

- `count()` — считает вверх бесконечно, начиная с заданного значения.
- `cycle()` — бесконечно повторяет элементы итерируемого объекта (например, списка или строки).
- `repeat()` — повторяет объект бесконечно или заданное число раз.
- `takewhile()` — берёт элементы итерируемого объекта, пока предикатная функция возвращает true.
- `chain()` — объединяет несколько итерируемых объектов в один длинный.
- `accumulate()` — возвращает нарастающую сумму значений итерируемого объекта.
- `product()` и `permutations()` — применяются, когда нужно выполнить задачу со всеми возможными комбинациями элементов.

Пример работы функций itertools:

```python
  from itertools import count
  for i in count(3):
      print(i)
      if i >= 11:
          break
  # аналог filter и map
  from itertools import accumulate, takewhile
  nums = list(accumulate(range(8)))
  print(nums)
  print(list(takewhile(lambda x: x <= 6, nums)))
  # product и permutations
  from itertools import product, permutations
  letters = ("A", "B")
  print(list(product(letters, range(2))))
  # список кортежей со всеми возможными наборами элементов
  print(list(permutations(letters)))
```

## Перегрузка методов

В Python перегрузка методов (**OOP Overloading**) работает не так, как в Java: второе определение функции перекрывает первое.

Пример перегрузки методов:

```python
  class Demo:
      def multiply(x, y): print(x * y)
      def multiply(x, y, z): print(x * y * z)

  d = Demo()
  d.multiply(10, 3, 2)
```
