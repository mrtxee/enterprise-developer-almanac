## Selenium

**Selenium** — это популярный набор инструментов с открытым исходным кодом (open-source) для **автоматизации веб-браузеров**.

Простыми словами: это программа, которая позволяет управлять браузером (Chrome, Firefox, Safari, Edge и др.) с помощью кода. Она делает это так, как если бы за компьютером сидел живой человек: переходит по ссылкам, кликает на кнопки, вводит текст, скроллит страницы.

**Назначение**

1. **Автоматизированное тестирование (основная цель)** — разработчики и QA-инженеры пишут сценарии (скрипты), которые проверяют, работает ли сайт правильно. Например: «Открыть страницу логина → ввести логин и пароль → нажать „Войти" → проверить, что появилась надпись „Добро пожаловать"». Это позволяет быстро проверять сайт после каждого обновления вместо ручного тестирования.
2. **Веб-скрапинг (парсинг)** — сбор данных с сайтов, которые динамически подгружают контент (где простой HTTP-запрос не сработает). Например, сбор цен с интернет-магазинов или вакансий.
3. **Автоматизация рутинных задач** — заполнение форм, скачивание отчетов, массовые действия в веб-интерфейсах.

## Компоненты Selenium

Selenium — это не одна программа, а целый пакет:

**Selenium WebDriver (самый важный компонент)**

Библиотека, которая позволяет писать код на языках программирования (**Java, Python, C#, JavaScript, Ruby, PHP**). WebDriver отправляет команды браузеру (например, «нажми на элемент») и получает ответы.

**Пример на Java**

```java
WebDriver driver = new ChromeDriver();
driver.get("https://google.com");
driver.findElement(By.name("q")).sendKeys("Selenium" + Keys.ENTER);
driver.quit();
```

**Selenium IDE (Integrated Development Environment)**

Плагин для браузера (Chrome и Firefox). Он позволяет записывать действия пользователя («Record and Playback») и генерировать код, не написав ни строчки вручную. Подходит для новичков и простых проверок.

**Selenium Grid**

Позволяет запускать тесты параллельно на разных машинах, с разными браузерами и операционными системами одновременно. Это значительно ускоряет процесс тестирования.

**Краткий итог**

Selenium — это **стандарт индустрии** для автоматизации действий в браузере. Если слышишь фразу «пишем автотесты на Java для веба», с вероятностью 99% речь идет о Selenium WebDriver.
