## Дерево файлов (tree)

Получить полное дерево файлов из текущей директории:

batch
```shell
cd ~\Documents\GitHub\enterprise-developer-almanac
tree /F /A > tree.txt
```

bash
```bash
cd ~/Documents/GitHub/enterprise-developer-almanac
sudo pacman tree
tree > tree.txt
```
