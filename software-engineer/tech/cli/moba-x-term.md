## MobaXterm

**MobaXterm** — это расширенный терминал и сетевой инструмент для Windows, предназначенный для системных администраторов, разработчиков и [[dev-ops|DevOps]]-инженеров. Он объединяет в одном приложении множество функций, обычно доступных только в Linux/macOS:

1. SSH-клиент (для подключения к Linux-серверам).
2. X11-сервер (запуск графических приложений Linux на Windows).
3. SFTP-браузер (удобная передача файлов).
4. Поддержку RDP, VNC, [[telnet|Telnet]], FTP, Serial.
5. Встроенные Unix-утилиты (bash, grep, rsync и др.).

Идеален для разработчиков и админов, работающих с удалёнными серверами. Доступен в бесплатной (Home) и платной (Professional) версиях.

**Итог:** MobaXterm — это «всё-в-одном» решение для работы с удалёнными системами на Windows, сочетающее терминал, файловый менеджер и графическую поддержку.
