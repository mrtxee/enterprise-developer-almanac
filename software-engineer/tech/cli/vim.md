## Редактор vim

### Основные команды

**Запуск**

- `vi example.txt` — запуск vim
- `Esc` — перейти в командный режим

**Режимы**

- `i` — режим вставки
- `I` — вставка текста в начало текущей строки
- `a` — вставка текста после курсора
- `A` — вставка текста в конец текущей строки
- `Esc` — командный режим

**Навигация**

- `h` — курсор влево
- `j` — курсор вниз
- `k` — курсор вверх
- `l` — курсор вправо
- `b` — к началу текущего слова
- `e` — к концу текущего слова
- `$` — конец строки
- `0` — начало строки
- `gg` — переход на первую строку файла
- `G` — переход на последнюю строку файла
- `9G` — переход на 9-ю строку файла

**Выделение**

- `v` — выделить текст
- `V` — выделить строку

**Копирование и вставка**

- `y` — скопировать («yank») выделение
- `yy` — скопировать всю строку
- `p` — вставить

**Удаление**

- `x` — удалить символ
- `dw` — удалить слово
- `d$` — удалить от текущей позиции до конца строки
- `d0` — удалить от текущей позиции до начала строки
- `dG` — удалить до последней строки файла

**Отмена**

- `u` — отменить действие

**Сохранение**

- `:w` — сохранить
- `:wq` — сохранить и выйти
- `:ZZ` — сохранить и выйти
- `:q!` — выйти без сохранения

## vim vs vi

Разница между **vi** и **vim** — это разница между древним инструментом и его современным, мощным потомком**. Vim — это почти полностью переписанный, расширенный и улучшенный vi, ставший де-факто стандартом в Linux/Unix-мире.

**Краткий ответ**

| Критерий | vi | vim |
| --- | --- | --- |
| Полное название | Visual Editor | Vi IMproved (Vi Improved) |
| Год создания | 1976 (Bill Joy) | 1991 (Bram Moolenaar) |
| Разработчик | Университет Беркли | Bram Moolenaar |
| Совместимость | Сам по себе | 100% совместим с vi — может работать как `vi` |
| Функционал | Минималистичный, базовый | Огромный набор функций: подсветка синтаксиса, автодополнение, плагины |
| Поддержка | Устарел, почти не используется | Активно развивается и поддерживается |
| По умолчанию в Linux | Нет (в новых дистрибутивах) | Да — стандартный редактор |
| Типичное имя в командной строке | `vi` | `vim` (или `vi` как симлинк на `vim`) |

> В современных системах (Ubuntu, CentOS, Fedora, macOS) `vi` — это просто симлинк на `vim`. Когда в командной строке вводится `vi file.txt`, запускается Vim, а не старый vi.

### Что умеет vim, а vi — нет

| Функция | vi | vim | Почему важно |
| --- | --- | --- | --- |
| Подсветка синтаксиса | ❌ | ✅ (HTML, Python, Java, JSON и др.) | Ускоряет чтение кода, снижает ошибки |
| Подсветка скобок | ❌ | ✅ | Помогает находить парные скобки `{}`, `[]`, `()` |
| Автодополнение | ❌ | ✅ (`Ctrl+X Ctrl+O` — для кода, `Ctrl+X Ctrl+N` — по словам) | Экономит время при наборе |
| Множественные окна / разделы | ❌ | ✅ (`:split`, `:vsplit`) | Редактирование двух файлов одновременно |
| Работа с файлами по FTP/SFTP | ❌ | ✅ (`:e ftp://host/file`) | Редактирование файлов на удалённом сервере |
| Поддержка Unicode / UTF-8 | Ограниченная | Полная | Корректная работа с кириллицей, эмодзи, азиатскими языками |
| Плагины | ❌ | ✅ (через `.vimrc`, Vundle, vim-plug, Neovim) | Git-интеграция, линтеры, темы, код-форматтеры |
| История команд | Ограниченная | Полная (прокрутка `↑`/`↓`) | Удобное повторение команд |
| Поиск и замена с регулярками | Базовый | Расширенный (`\v`, `\m`, `\V`) | Более точный и мощный поиск |
| Отмена действий | Только одна отмена | История отмен (100+ действий) | Возможность отката на много шагов назад |
| Цветовая схема | ❌ | ✅ (`:colorscheme desert`, `:colorscheme gruvbox`) | Удобнее для глаз при долгой работе |
| Работа с буферами и табами | ❌ | ✅ (`:buffers`, `:tabnew`, `:bnext`) | Удобная работа с несколькими файлами |
| Горячие клавиши для навигации | Только базовые | Много (`Ctrl+O` / `Ctrl+I`, `gd` — к определению) | Эффективность выше в 2–3 раза |
| Интеграция с Git | ❌ | ✅ (через плагин vim-fugitive) | Просмотр diff, коммиты, статус — прямо в редакторе |
| Поддержка языков программирования | ❌ | ✅ (автодополнение для Python, JS, Go, Rust и др.) | Помощь при коде, как в IDE |

### Пример: как выглядит редактирование в vi и vim

В **vi** (1976):

```bash
vi myfile.py
```

- Только базовый режим.
- Нет подсветки.
- Нет автодополнения.
- `u` отменит только последнее действие.
- Нет понимания, что это Python-файл.

В **vim** (2024):

```bash
vim myfile.py
```

- Подсветка синтаксиса Python.
- Автодополнение: `for` → `Ctrl+X Ctrl+O` → предлагает `for i in range()`.
- Скобки подсвечиваются: `print("Hello")` — скобки мигают при установке курсора.
- Отмена до 100 действий: `u` — `u` — `u`...
- Открытие второго файла: `:split other.py`.
- Переход к определению функции: `gd`.
- Просмотр Git-статуса: `:Gstatus`.

## Как проверить, какой редактор установлен

```bash
vi --version
```

Если вывод содержит `VIM - Vi IMproved 9.0` — установлен Vim.

Если вывод `vi: command not found` — `vi` является симлинком на vim. Проверить:

```bash
which vi
# → /usr/bin/vi

ls -la /usr/bin/vi
# → lrwxrwxrwx 1 root root 20 Apr 1 2023 /usr/bin/vi -> /usr/bin/vim.tiny
```

> В Ubuntu 22.04+, Fedora, macOS `vi` — это Vim в мини-версии (vim-tiny). В Arch Linux, CentOS `vim` — полноценный.

## Почему vim стал стандартом

| Причина | Объяснение |
| --- | --- |
| Обратная совместимость | Vim может работать как `vi` — старые скрипты не сломались |
| Открытый исходный код | Бесплатный, развивается сообществом |
| Кроссплатформенность | Работает на Linux, macOS, Windows (через WSL, Cygwin) |
| Лёгкость и скорость | Запускается за миллисекунды — даже на слабых серверах |
| Мощность | Почти как IDE, но без тяжёлого GUI |
| Универсальность | Работает через SSH — редактирование файлов на любом сервере |

## Когда использовать vi, а когда vim

| Ситуация | Рекомендация |
| --- | --- |
| Старый сервер (embedded-система, роутер, старый Unix) | `vi` — он всегда есть, даже если vim не установлен |
| Современная система Linux/macOS | `vim` — он и есть `vi` в системе |
| Написание кода, скриптов, конфигов | Всегда `vim` |
| Обучение Linux / DevOps / SysAdmin | Учиться `vim` — неотъемлемая часть профессии |
| Работа в SSH-сессии | `vim` — не нужен GUI и интернет, работает в терминале |

## Настройка vim как IDE

Создайте файл `~/.vimrc`:

```vim
" Подсветка синтаксиса
syntax on
filetype plugin indent on

" Цветовая схема
colorscheme desert

" Номера строк
set number

" Отступы
set tabstop=4
set shiftwidth=4
set expandtab

" Автодополнение
set completeopt=menuone,noinsert,noselect

" Поиск без учёта регистра
set ignorecase
set smartcase

" История команд
set history=1000

" Отмена до 100 действий
set undolevels=1000
```

После перезапуска `vim` получается почти полноценная IDE.

## Финальный вывод

| vi | vim |
| --- | --- |
| Архаичный, исторический инструмент | Современный, мощный, живой редактор |
| Использовать только в экстренных случаях (старые серверы) | Использовать всегда — это стандарт |
| Не рекомендуется в современных системах | Идеален для повседневной работы |

> «vi — это как карета. vim — это автомобиль. Можно ездить на карете, но зачем, если есть автомобиль?»

## Запомните

> `vi` — это legacy. `vim` — это стандарт. На 99% систем, где предстоит работать, `vi` = `vim`. Учиться `vim` — и не пожалеть.
