## 🌐 Glob vs Regex — Краткое сравнение

### 📌 Главное отличие

| | **Glob** | **Regex** |
|--|----------|-----------|
| **Что это** | Простой шаблон для **имён файлов** | Мощный язык для **поиска в тексте** |
| **Сложность** | 🟢 Очень простой | 🔴 Сложный |
| **Где используется** | Файловые пути, shell | Текст, валидация, парсинг |

---

## 🔑 Основные символы

| Задача | **Glob** | **Regex** |
|--------|----------|-----------|
| Любой один символ | `?` | `.` |
| Любое количество символов | `*` | `.*` |
| Набор символов | `[abc]` | `[abc]` |
| Диапазон | `[a-z]` | `[a-z]` |
| Исключение из набора | `[!abc]` | `[^abc]` |
| Экранирование | `\` | `\` |

---

## 🧪 Примеры

| Задача | **Glob** | **Regex** |
|--------|----------|-----------|
| Все `.txt` файлы | `*.txt` | `.*\.txt$` |
| Файл `file1.txt`, `file2.txt` | `file?.txt` | `file\d\.txt` |
| Только `a`, `b`, `c` в имени | `[abc]*.txt` | `[abc].*\.txt` |
| Любое расширение из списка | `*.{jpg,png}` | `.*\.(jpg\|png)$` |

---

## 📊 Сравнение возможностей

| Возможность | **Glob** | **Regex** |
|-------------|----------|-----------|
| Поиск по файлам | ✅ Идеально | ⚠️ Избыточно |
| Валидация email | ❌ Нет | ✅ Да |
| Группировка `()` | ❌ Нет | ✅ Да |
| Квантификаторы `{n,m}` | ❌ Нет | ✅ Да |
| Якоря `^` `$` | ❌ Нет | ✅ Да |
| Lookahead/Lookbehind | ❌ Нет | ✅ Да |
| Скорость | 🟢 Быстрая | 🟡 Средняя |
| Кривая обучения | 🟢 5 минут | 🔴 Часы/дни |

---

## 🎯 Когда что использовать

| Сценарий | Выбор |
|----------|-------|
| Поиск файлов в директории | ✅ **Glob** |
| `.gitignore`, shell скрипты | ✅ **Glob** |
| Валидация email, телефона | ✅ **Regex** |
| Парсинг текста, извлечение данных | ✅ **Regex** |
| Конфиги Spring `@ComponentScan` | ✅ **Glob** |
| Поиск/замена в редакторах | ✅ **Regex** |

---

## 📌 Памятка

```
┌─────────────────────────────────────────────────────────────┐
│  Glob = простой шаблон для файлов                           │
│  • * → любой текст                                          │
│  • ? → один символ                                          │
│  • [abc] → набор                                            │
│                                                             │
│  Regex = мощный язык для текста                             │
│  • .* → любой текст                                         │
│  • . → один символ                                          │
│  • \d, \w, ^, $, +, {n,m} → продвинутое                    │
│                                                             │
│  🎯 Файлы → Glob | Текст → Regex                            │
└─────────────────────────────────────────────────────────────┘
```

> 💡 **Правило:** Если работаете с **файлами** — используйте Glob. Если с **текстом** — Regex.
