## DDD Context Map vs 4C Context Map

**[[c4-diagram|4C]] Context Map** и **[[domain-driven-design|DDD]] Context Map** — это две разные диаграммы, хотя обе используются для визуализации бизнес-контекстов.

## Что такое DDD Context Map

**DDD Context Map (Domain-Driven Design)** — это диаграмма, созданная Эриком Эвансом #👨 для визуализации бизнес-контекстов (bounded contexts) и их взаимодействий.

**Основные элементы:**

- **Bounded Contexts** — границы ответственности.
- **Типы взаимодействий:** Customer-Supplier, Conformist, ACL, Open Host Service и др.
- **Фокус:** на архитектуре, границах, коммуникации между командами.

Пример связи: `Order Processing` ↔ `User Management`.

## Что такое 4C Context Map

**4C Context Map** — это диаграмма из книги «The Art of Business Analysis» Майкла Брауна #👨 #📘, которая показывает четыре типа контекста:

| C | Значение | Объяснение |
|---|----------|------------|
| **Core** | Ядро | Критически важные процессы (например, продажи) |
| **Context** | Контекст | Внешние системы, с которыми взаимодействует бизнес |
| **Collaboration** | Сотрудничество | Другие подразделения внутри компании |
| **Competition** | Конкуренция | Конкуренты, рынки, угрозы |

**Пример:**

- **Core:** обработка заказов.
- **Context:** платёжные шлюзы (Stripe, PayPal).
- **Collaboration:** отдел маркетинга.
- **Competition:** Amazon, Wildberries.

## Сравнение: DDD Context Map vs 4C Context Map

| Критерий | **DDD Context Map** | **4C Context Map** |
|----------|---------------------|--------------------|
| **Автор** | Eric Evans | Michael Brown |
| **Цель** | Архитектура, границы, интеграция систем | Анализ бизнеса, стратегия, конкурентоспособность |
| **Фокус** | Технические/бизнес-контексты, API, зависимости | Бизнес-процессы, внешняя среда, конкуренция |
| **Используется в** | Разработке, DDD, микросервисы | Бизнес-аналитика, стратегия, управление |
| **Пример элемента** | `Order Processing`, `Payment Gateway` | `Core: Sales`, `Context: Stripe`, `Competition: Amazon` |
| **Связи** | Типы взаимодействий (Customer-Supplier, ACL) | Нет специальных типов связей |
| **Уровень абстракции** | Технический (системы, API) | Бизнес-стратегический |

## Когда использовать?

| Сценарий | Рекомендация |
|----------|--------------|
| Проектирование архитектуры микросервисов | **DDD Context Map** |
| Анализ бизнес-процессов, стратегии | **4C Context Map** |
| Команде нужно понять, кто за что отвечает | **DDD Context Map** |
| Менеджменту нужно понять внешнюю среду | **4C Context Map** |

## Вывод

**DDD Context Map** — это техническая диаграмма для разработчиков. **4C Context Map** — это стратегическая диаграмма для бизнес-аналитиков.**

DDD показывает, как строить программное обеспечение; 4C показывает, какой бизнес строить.
