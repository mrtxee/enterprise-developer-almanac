Фильтр Блума — вероятностная структура данных, сконструированная Бёртоном Блумом в 1970 году, позволяющая проверять принадлежность элемента к множеству. При этом существует возможность получить ложноположительное срабатывание (элемента в множестве нет, но структура данных сообщает, что он есть), но не ложноотрицательное.

Фильтр Блума может использовать любой объём памяти, заранее заданный пользователем, причём чем он больше, тем меньше вероятность ложного срабатывания. Поддерживается операция добавления новых элементов в множество, но не удаления существующих (если только не используется модификация со счётчиками — фильтр Блума с подсчётом. 

### Как работает фильтр Блума в Postgres

1. **Хеширование**:
    - Каждое значение столбца пропускается через несколько хеш-функций.
    - Результаты хеширования определяют, какие биты установить в битовой карте.

2. **Битовая карта**:
    - Индекс хранит **битовый массив**, где каждый бит соответствует возможному хеш-значению.
    - Если все биты для значения установлены — оно **возможно** есть в таблице (но могут быть ложные срабатывания).

3. **Проверка запроса**:
    - Для условия `WHERE col1 = 'A' AND col2 = 'B'`:
        - Bloom-индекс проверяет биты для `'A'` и `'B'`.
        - Если хотя бы один бит не совпадает — строка точно не подходит.
        - Если все биты совпадают — строка **возможно** подходит (нужна дополнительная проверка).
