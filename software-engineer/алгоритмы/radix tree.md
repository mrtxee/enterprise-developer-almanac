# Radix Tree – Дерево цифрового ключа

Radix Tree (также называемое **Compact Prefix Tree** или **Patricia Tree**) — это оптимизированная версия префиксного дерева [[trie]], которая используется для **быстрого поиска строк, чисел или битовых последовательностей** (например, IP-адресов) по их префиксам.

Это древовидная структура данных, где:
- **Каждый узел** хранит **общий префикс** для всех своих дочерних узлов.
- **"Сжатые" ветви** объединяют узлы с одним потомком, экономя память.
- **Ключи** (строки, числа, IP-адреса) разбиваются на части (обычно по битам или символам).

**Пример Radix Tree для слов "test", "team", "toast"**
Где `[es]` — общий префикс для "test" и "team"
```text
        [t]
       /   \
     [es]  [o]
     /  \    \
   [t] [am] [ast]
```


**Применение**
1. **Сетевые технологии (IP-маршрутизация)**
	- **Быстрый поиск подсетей** в роутерах (например, для `192.168.1.0/24`)
	- Используется в Linux-ядре (`struct radix_tree_root`).
2. **Анализ текста**
	- Автодополнение (Google, поисковые системы).
	- Поиск по словарю (проверка орфографии).
3. **Ключ-значение хранилища**
	- Redis использует Radix Tree для **хранения строковых ключей** в памяти.
	- **Индексация строк** (например, в PostgreSQL SP-GiST для `text_pattern_ops`).
	- **Хранение IP-адресов** (оптимизация запросов вида `LIKE '192.168.%'`).
4. **Анализ текста**
	- Автодополнение (Google, поисковые системы).
	- Поиск по словарю (проверка орфографии).
5. **Ключ-значение хранилища**
	- Redis использует Radix Tree для **хранения строковых ключей** в памяти.

## Отличие от обычного Trie (префиксного дерева)

| **Trie**                                    | **Radix Tree**                         |
| ------------------------------------------- | -------------------------------------- |
| Каждый символ/бит — отдельный узел          | Узлы объединяют общие префиксы         |
| Много узлов с одним потомком (неэффективно) | Нет "лишних" узлов — память экономится |
| Медленнее из-за большего числа узлов        | Быстрее за счет сжатия                 |
