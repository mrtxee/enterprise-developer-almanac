R-дерево — это **сбалансированное дерево**, которое организует данные в виде **вложенных прямоугольников** `bounding boxes`. Каждый узел хранит минимальный ограничивающий прямоугольник **MBR**, покрывающий все дочерние элементы.

**Как работает?**
- **Листья**: Содержат ссылки на объекты (например, полигоны на карте) и их MBR.
- **Внутренние узлы**: Хранят MBR для дочерних узлов.
- **Поиск**: Начинается с корня, отбрасывая узлы, чьи MBR не пересекаются с запросом.

**Пример в PostgreSQL (GiST для геоданных)**
```sql
-- Создание R-дерева (через GiST)
CREATE INDEX idx_geom_gist ON polygons USING GiST(geom);

-- Запрос: поиск полигонов, пересекающихся с заданной областью
SELECT * FROM polygons 
WHERE geom && ST_MakeEnvelope(10, 10, 20, 20);
```

**Плюсы и минусы**

| **Плюсы**                          | **Минусы**                            |
| ---------------------------------- | ------------------------------------- |
| Эффективен для геоданных.          | Может быть несбалансированным.        |
| Поддержка сложных форм (полигоны). | Высокий оверхед при вставке/удалении. |
