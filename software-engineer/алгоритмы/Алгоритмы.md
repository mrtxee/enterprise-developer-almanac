# Хэширование

Хэширование — это процесс преобразования объекта в целочисленную форму.
**[[Хеш-функция]]** берет на вход любые данные и возвращает значение — **хэш** данных. Нет обратной функции для восстановления данных по хэшу
* $h = H(m)$
# Структуры данных
[https://habr.com/ru/post/422259/](https://habr.com/ru/post/422259/)
Структура данных — это контейнер, который хранит данные в определенном макете. Этот «макет» позволяет структуре данных быть эффективной в некоторых операциях и неэффективной в других.
- **Линейные**, элементы образуют последовательность или линейный список, обход узлов линеен. Примеры: Массивы. Связанный список, стеки и очереди.
- **Нелинейные**, если обход узлов нелинейный, а данные не последовательны. Пример: граф и деревья.

Linked list
Связанный список – колеекция элементов, в которой каждый эелемент включает в себя как минимум 2 поля – данные и ссылки на следующий узел.
Принципиальным преимуществом перед массивом является возможность фрагментации стрктуры в физической памяти
**Однонаправленный список:** каждый узел хранит адрес или ссылку на следующий узел в списке и последний узел имеет следующий адрес или ссылку как NULL. **1->2->3->4->NULL**
**Двунаправленный список:** две ссылки, связанные с каждым узлом, одним из опорных пунктов на следующий узел и один к предыдущему узлу. **NULL<-1<->2<->3->NULL**
**Круговой список:** все узлы соединяются, образуя круг. В конце нет NULL.  
Циклический связанный список может быть одно-или двукратным циклическим  
связанным списком. **1->2->3->1**
- InsertAtEnd — Вставка заданного элемента в конец списка
- InsertAtHead — Вставка элемента в начало списка
- Delete — удаляет заданный элемент из списка
- DeleteAtHead — удаляет первый элемент списка
- Search — возвращает заданный элемент из списка
- isEmpty — возвращает True, если связанный список пуст
## Нелинейные структуры
### Граф
Граф-это набор узлов (вершин, VERTEX), которые соединены друг с другом в виде сети ребрами (дугами, EDGE).
```mermaid
---
title: Graph (Граф)
---
flowchart LR
    A("A") --> B("B") & C("C")
    B --> D("D<br><sup>vertex / вершина</sup>") & C
    C --> D
    D --> E("E")
    E -- "<sup>edge / ребро</sup>" --> A

     A:::vertex
     B:::vertex
     C:::vertex
     D:::vertex
     E:::vertex
```

* **Ориентированный граф**, ребра являются направленными, т.е. существует только одно доступное направление между двумя связными вершинами.
* **Неориентированный граф**, к каждому из ребер можно осуществлять переход в обоих направлениях.
* **Смешанный граф**

Дерево-это иерархическая структура данных, состоящая из узлов (вершин) и ребер (дуг). Деревья по сути связанные графы без циклов.
- Бинарное дерево  
    Двоичное дерево - такое у каждого узла которого не более 2 потомков  
    - Бинарное дерево поиска BST
        - Ключи всех левых потомков <= ключи всех правых потомков.  
            Сложность поиска от O(log n) до O(N). O(N) - если дерево не сбалласнисрованное.  
            
    - рандомизированные деревья поиска
    - Сбалансированное дерево  
        Такие деревья, у которых длина от конря до любого из потомков отличается не более чем на 1. Это гарантируем нам сложность поиска до O(log n), но усложняет методы добавляения, удаление элементов  
        - Красно-черное дерево, RBTree
            1. Каждый узел промаркирован красным или чёрным цветом
                1. Корень и конечные узлы (листья, NULL, `nil-node`) дерева — чёрные
                2. У красного узла родительский узел — чёрный
                3. Все простые пути из любого узла x до листьев содержат одинаковое количество чёрных узлов `black height`
                4. Чёрный узел может иметь чёрного родителя
        - AVL - дерево  
            АВЛ - по первым буквам фамилий авторов алгоритма  
            Довольно накладная реализация подхода. В каждом узле надо хранить высоту текущего узла, при манипуляциях с данными надо првоверять  
            `balance factor` и выполнять баллансировку, которая делится на 4 операция: плавый / левый, малый / большой пововрот дерева.
- Декартово дерево
- Б-дерево
- [[trie]] ( префиксное деревое )
    - пример - хранение данных для Т9

Хэширование — это процесс, используемый для уникальной идентификации объектов и хранения каждого объекта в заранее рассчитанном уникальном индексе (ключе).
Объект хранится в виде пары «ключ-значение», а коллекция таких элементов называется «словарем». Каждый объект можно найти с помощью этого ключа.
По сути это массив, в котором ключ представлен в виде хеш-функции.

### Алгоритмы поиска

| Алгоритм                                                    | Структура данных                           | **Временная сложность в среднем**    | **Временная сложность в худшем**         | Сложность по памяти в худшем |
| ----------------------------------------------------------- | ------------------------------------------ | ------------------------------------ | ---------------------------------------- | ---------------------------- |
| Поиск в глубину (DFS)                                       | Граф с $\|V\|$ вершинами и $\|E\|$ ребрами | $-$                                  | $O(\|E\| + \|V\|)$<br>🟢<br>             | 🟩<br>$O(\|V\|)$<br>         |
| Поиск в ширину (BFS)                                        | Граф с $\|V\|$ вершинами и $\|E\|$ ребрами | $-$                                  | $O(\|E\| + \|V\|)$<br>🟢<br>             | $O(\|V\|)$<br>               |
| Бинарный поиск                                              | Отсортированный массив из $n$ элементов    | 🟩<br>$O(log(n))$<br>                | 🟩<br>$O(log(n))$                        | 🟩<br>$O(1)$<br>             |
| Линейный поиск                                              | Массив                                     | 🟥<br>$O(n)$<br>                     | 🟥<br>$O(n)$                             | 🟩<br>$O(1)$<br>             |
| Кратчайшее расстояние по алгоритму Дейкстры (двоичная куча) | Граф с $\|V\|$ вершинами и $\|E\|$ ребрами | 🟨<br>$O((\|V\| + \|E\|)*log \|V\|)$ | 🟨<br>$O((\|V\| + \|E\|) log \|V\|)$<br> | 🟨<br>$O(\|V\|)$<br>         |
| Кратчайшее расстояние по алгоритму Дейкстры (массив)        | Граф с $\|V\|$ вершинами и $\|E\|$ ребрами | 🟨<br>$O(\|V\|^2)$                   | 🟨<br>$O(\|V\|^2)$                       | 🟨<br>$O(\|V\|)$             |

## Нотация асимптотического роста

| Обозначение              | Граница                                   | Рост             |
| ------------------------ | ----------------------------------------- | ---------------- |
| $\Theta$ — тэта          | Нижняя и верхняя границы, точная оценка   | Равно            |

| $\Omega$ — большое омега | Нижняя граница, точная оценка неизвестна  | Больше или равно |
| $\omega$ — малое омега   | Нижняя граница, не точная оценка          | Больше           |
