**Метрика триграмм** — это способ оценки схожести двух строк на основе количества общих триграмм (подстрок из трёх последовательных символов). Чем больше общих триграмм у строк, тем они «ближе» друг к другу.

**Формула метрики**
Расстояние между строками `A` и `B` определяется как:
$$
distance=1−\frac{количество\:общих\:триграмм}{количество\:уникальных\:триграмм\:в\:A\:и\:B}

$$
- **Результат**: от `0` (полное совпадение) до `1` (совсем не похожи).

**Примеры**
* Для строк `"кот"` и `"кит"`:
	1. Триграммы `"кот"`: `" ко"`, `"кот"`, `"от "`.
	2. Триграммы `"кит"`: `" ки"`, `"кит"`, `"ит "`.
	3. Общих триграмм: `0`.
	4. Расстояние: `1 - 0 / 6 = 1`.
* Для `"hello"` и `"hell"`:
	1. Триграммы `"hello"`: `" he"`, `"hel"`, `"ell"`, `"llo"`, `"lo "`.
	2. Триграммы `"hell"`: `" he"`, `"hel"`, `"ell"`, `"ll "`.
	3. Общие триграммы: `" he"`, `"hel"`, `"ell"` → `3`.
	4. Расстояние: `1 - 3 / (5 + 4 - 3) ≈ 0.5`.

**Другие метрики**

| **Метрика**         | **Описание**                             | **Пример использования**                           |
| ------------------- | ---------------------------------------- | -------------------------------------------------- |
| **Триграммы**       | Учитывает подстроки из 3 символов.       | Исправление опечаток (`"програма" → "программа"`). |
| **Левенштейн**      | Минимальное число правок для совпадения. | Точное исправление опечаток (медленнее).           |
| **Косинусная мера** | Учитывает частоту терминов (для NLP).    | Поиск похожих документов.                          |
