KD-дерево — это **бинарное дерево**, которое рекурсивно разбивает пространство по **[[Геометрия#Гиперплоскость|гиперплоскостям]]** (например, вертикальным и горизонтальным линиям для 2D).

**Как работает?**
- **Разбиение**: На каждом уровне дерева выбирается ось (X, Y, Z...) и медианное значение для разделения данных.
- **Поиск**: Быстрый спуск по дереву с отсечением ненужных ветвей.  

**Пример в PostgreSQL (SP-GiST)**
```sql
-- Создание KD-дерева (через SP-GiST)
CREATE INDEX idx_points_spgist ON points USING SPGiST(geom);
-- Запрос: поиск ближайших соседей (KNN)
SELECT * FROM points 
ORDER BY geom <-> ST_Point(10, 20) 
LIMIT 5;
```

**Плюсы и минусы**

| **Плюсы**                        | **Минусы**                                  |
| -------------------------------- | ------------------------------------------- |
| Быстрый поиск ближайших соседей. | Неэффективен для динамических данных.       |
| Оптимален для точечных данных.   | Требует перестройки при частых обновлениях. |
