## Levenshtein distance

Английское название: **Levenshtein distance** (также часто используется более широкий термин **Edit distance**).

### Суть

Расстояние Левенштейна #👨 — это метрика, измеряющая разность между двумя строковыми последовательностями. Оно определяется как **минимальное количество операций** (вставки, удаления или замены одного символа), необходимых для того, чтобы преобразовать одну строку в другую.

Вычисляется с помощью метода динамического программирования.

---

$$
d_{i,j} = \min \begin{cases}
d_{i-1, j} + 1, & \text{удаление} \\
d_{i, j-1} + 1, & \text{вставка} \\
d_{i-1, j-1} + \begin{cases} 0, & \text{если } a_i = b_j \\ 1, & \text{если } a_i \neq b_j \end{cases} & \text{замена}
\end{cases}
$$

$$
\text{Базовые случаи:} \quad
\begin{cases}
d_{i, 0} = i \\
d_{0, j} = j
\end{cases}
$$

Пояснение к формуле:

- $d_{i,j}$ — расстояние между первыми $i$ символами строки $a$ и первыми $j$ символами строки $b$.
- $i$ — длина префикса первой строки.
- $j$ — длина префикса второй строки.
- $a_i$ и $b_j$ — соответствующие символы в строках.
- Индикаторная функция равна 0, если символы совпадают (замена не требуется), и 1, если отличаются.

## Edit distance

**Расстояние Левенштейна** (редакционное расстояние) — это минимальное число операций, которые нужно выполнить, чтобы превратить одну строку в другую.

### Какие операции считаются

Разрешены три типа операций, каждая стоит 1 шаг:

- **Вставка** символа.
- **Удаление** символа.
- **Замена** одного символа на другой.

---

### Простой пример

Превратим `кот` → `код`:

1. Заменяем `т` на `д` → `код`.

Расстояние = 1.

Ещё пример: `салат` → `стол`:

1. `салат` → `стат` (удалить `л`)
2. `стат` → `стот` (заменить `а` на `о`)
3. `стот` → `стол` (заменить `т` на `л`)

Расстояние = 3.

---

### Где это пригодится в твоих Java‑задачах

Учитывая твои прошлые вопросы (детектирование лицензий, сравнение текстов), расстояние Левенштейна полезно, когда:

- Нужно найти «похожую» лицензию, если текст немного отличается от эталона (например, есть копирайт или дата).
- Реализовать нечёткий поиск (как «Возможно, вы имели в виду…»).
- Оценить схожесть строк, когда простого совпадения недостаточно.

---

### Как считают (коротко)

Обычно используют **динамическое программирование**: строят матрицу размера `(длина строки 1 + 1) × (длина строки 2 + 1)` и заполняют её по правилу: если символы совпадают, стоимость не растёт, иначе берут минимум из трёх соседних ячеек и прибавляют 1. Итоговая ячейка — искомое расстояние.

Сложность: `O(m × n)` по времени и памяти (где `m`, `n` — длины строк).

---

### Пример на Java (без сторонних библиотек)

```java
public static int levenshtein(String s1, String s2) {
    int m = s1.length();
    int n = s2.length();

    int[][] dp = new int[m + 1][n + 1];

    // Базовые случаи: превращение в пустую строку
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1]; // без операции
            } else {
                int insert = dp[i][j - 1] + 1;
                int delete = dp[i - 1][j] + 1;
                int replace = dp[i - 1][j - 1] + 1;
                dp[i][j] = Math.min(insert, Math.min(delete, replace));
            }
        }
    }
    return dp[m][n];
}
```
