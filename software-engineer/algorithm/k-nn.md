## KNN-поиск — K-Nearest Neighbors

**KNN-поиск** (от англ. _K-Nearest Neighbors_ — «K ближайших соседей») — это алгоритм поиска объектов, ближайших к заданной точке в многомерном пространстве, где:

- **K** — количество соседей, которые нужно найти,
- **Близость** определяется метрикой расстояния (евклидово, манхэттенское и др.).

## Основные понятия

- **Целевая точка** (query point): Точка, для которой ищутся соседи.
- **Метрика расстояния**:
  - **Евклидово расстояние**: $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ (обычное расстояние в пространстве).
  - **Манхэттенское расстояние**: $|x_2 - x_1| + |y_2 - y_1|$ (сумма разностей по координатам).
- **Пространство данных**: Может быть 2D (геокоординаты), 3D (3D-модели), N-D (векторные embeddings).

## Как работает KNN?

1. **Задача:** Для точки **P** найти **K** ближайших точек в наборе данных.
2. **Алгоритм:**
  - Вычислить расстояния от **P** до всех точек.
  - Отсортировать точки по возрастанию расстояния.
  - Выбрать **K** точек с наименьшими расстояниями.

### Пример

Поиск 2 ближайших точек к запросу (4, 5):

```python
## Данные: [(x, y), ...]
points = [(1, 2), (3, 4), (5, 6), (7, 8)]
query = (4, 5)
k = 2

## Находим 2 ближайшие точки к (4, 5)
neighbors = sorted(points, key=lambda p: (p[0]-query[0])**2 + (p[1]-query[1])**2)[:k]
print(neighbors) # [(3, 4), (5, 6)]
```

## Оптимизации для больших данных

Прямой перебор всех точек неэффективен для больших наборов данных. Используются:

- **KD-деревья:** Рекурсивно разбивают пространство для быстрого отсечения дальних точек.
- **LSH (Locality-Sensitive Hashing):** Группирует похожие точки в «корзины».
- **Графовые методы** (например, HNSW): Строят графы для приближённого поиска.

## KNN в базах данных (PostgreSQL)

В PostgreSQL KNN-поиск ускоряется с помощью **GiST** или **SP-GiST**-индексов.

Создание индекса и поиск ближайших точек:

```sql
-- Создание индекса для точек
CREATE INDEX idx_points_gist ON points USING GiST(coord);

-- Поиск 5 ближайших точек к (10, 20)
SELECT * FROM points
ORDER BY coord <-> point '(10,20)'
LIMIT 5;
```

- **Оператор `<->`** — вычисляет расстояние (евклидово для `point`).
- **Индекс** позволяет избежать полного перебора.

## Применение

- **Рекомендательные системы:** «Похожие товары».
- **Геопоиск:** «Ближайшие кафе».
- **Компьютерное зрение:** Поиск похожих изображений.
- **Классификация:** Алгоритм k-NN для предсказания (например, определение типа растения по признакам).

## Ограничения

- **Вычислительная сложность:** O(N) для наивного подхода, O(log N) с индексами.
- **Чувствительность к шуму:** Выбросы могут искажать результат.
- **Выбор K:** Малое K → чувствительность к шуму, большое K → сглаживание границ.

## Примеры метрик расстояния

| Метрика           | Формула (2D)                            | Применение                      |
| ----------------- | --------------------------------------- | ------------------------------- |
| **Евклидово**     | $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ | Общий случай (геопоиск).        |
| **Манхэттенское** | $|x_2 - x_1| + |y_2 - y_1|$             | Городские маршруты (такси).     |
| **Косинусное**    | $1 - \frac{A \cdot B}{|A| |B|}$         | Текст/векторные данные (NLP).   |

## Вывод

KNN — это универсальный метод поиска ближайших объектов, критически важный для задач, где важно **расстояние** или **похожесть**. В базах данных его ускоряют специализированные индексы (GiST, SP-GiST), а в машинном обучении — оптимизированные алгоритмы (KD-деревья, HNSW).
