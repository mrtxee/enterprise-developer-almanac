## IETF (Internet Engineering Task Force)

**IETF (Internet Engineering Task Force)** — это **открытая международная организация**, которая разрабатывает и продвигает **технические стандарты для интернета**. Она отвечает за создание большинства протоколов, на которых работает современный интернет.

## Общая информация

| Характеристика | Описание |
|---|---|
| **Дата основания** | 16 января 1986 года |
| **Статус** | независимая организация, дочерняя по отношению к Обществу Интернета (ISOC) |
| **Миссия** | улучшение работы Интернета через создание качественных технических документов, влияющих на разработку, использование и управление сетью |
| **Тип организации** | открытая, добровольная, некоммерческая |
| **Язык работы** | английский |
| **Участие** | открыто для всех — инженеров, исследователей, компаний |
| **Формат работы** | рабочие группы (Working Groups), электронные рассылки, встречи 3 раза в год |

## Ключевые принципы работы

1. **Открытое взаимодействие** (*open process*):
   - любой заинтересованный человек может участвовать в разработке;
   - все документы, списки рассылок, протоколы собраний публикуются в открытом доступе.
2. **Техническая компетентность** (*technical competence*):
   - IETF обладает необходимой экспертизой для обсуждения профильных вопросов;
   - организация прислушивается к компетентным мнениям из любых источников.

## Структура и организация работы

- **Рабочие группы** — основные единицы, занимающиеся конкретными тематиками (маршрутизация, транспорт данных, безопасность и др.). Группы формируются внутри тематических областей (прикладная, Интернет-область, безопасность и т. д.).
- **Собрания** проводятся 3 раза в год, но основная работа ведётся через почтовые рассылки.
- **Принятие решений** основано на «примерном согласии» (*rough consensus*), без формального голосования.

## Результаты деятельности

- **Internet Drafts** — рабочие проекты, разрабатываемые группами.
- **RFC (Requests for Comments)** — официальные документы, описывающие стандарты, протоколы и исследовательские работы. Именно RFC становятся итоговыми стандартами Интернета.

## Основные задачи (согласно RFC 4677)

1. выявление проблем и предложение решений в технических аспектах Интернета;
2. разработка спецификаций, стандартов и соглашений по архитектурным принципам протоколов;
3. вынесение рекомендаций по стандартизации на рассмотрение IESG (*Internet Engineering Steering Group*);
4. содействие распространению технологий и стандартов, разрабатываемых IRTF (*Internet Research Task Force*);
5. организация дискуссий между участниками интернет-сообщества.

## Важные вспомогательные организации

| Организация | Роль |
|---|---|
| **IESG** (*Internet Engineering Steering Group*) | Курирует процессы разработки, создаёт и распускает рабочие группы |
| **IANA** (*Internet Assigned Numbers Authority*) | Регистрирует активность IETF, ведёт учёт протоколов (DNS, порты TCP) |
| **RFC Editor** | Редактирует, форматирует и публикует RFC-документы |
| **IETF Secretariat** | Обеспечивает материально-техническую поддержку (координация собраний, рассылок, веб-сайта) |
| **IETF Trust** | С 2005 года отвечает за соблюдение прав интеллектуальной собственности |

## Что создаёт IETF?

IETF публикует **RFC (Request for Comments)** — документы, которые описывают протоколы, процедуры и стандарты Интернета.

### Примеры известных RFC от IETF

| Протокол / Технология | RFC |
|---|---|
| **HTTP/1.1** | RFC 2616 → RFC 7230–7235 |
| **TCP** | RFC 793 |
| **IP (IPv4)** | RFC 791 |
| **DNS** | RFC 1034, RFC 1035 |
| **TLS 1.3** | RFC 8446 |
| **OAuth 2.0** | RFC 6749 |
| **LDAP** | RFC 4511 |
| **SMTP (почта)** | RFC 5321 |

> Если технология используется в интернете — скорее всего, её стандартизировал IETF.

## Как устроена работа IETF?

1. **Идея** → предлагается в рабочей группе
2. **Черновик** → публикуется как Internet-Draft
3. **Обсуждение** → сообщество даёт отзывы
4. **Утверждение** → становится **RFC**
5. **Стандарт** → если принят как **Internet Standard**

> Не все RFC — стандарты. Некоторые — экспериментальные или информационные.

## IETF vs другие организации

| Организация | Роль |
|---|---|
| **IETF** | Инженерные стандарты: TCP, IP, HTTP, TLS, DNS |
| **W3C** | Веб-стандарты: HTML, CSS, XML |
| **IEEE** | Аппаратные и сетевые стандарты: Wi-Fi (802.11), Ethernet (802.3) |
| **ITU** | Глобальная телекоммуникационная стандартизация (государственная) |

## Цитата

> «We reject kings, presidents and voting. We believe in rough consensus and running code.»
> — Девиз IETF

## Итог

**IETF = двигатель интернета.** Без неё не было бы ни веба, ни почты, ни безопасного соединения — ничего из того, чем мы пользуемся ежедневно.
