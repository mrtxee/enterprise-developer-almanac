Команды `grep`, `sed` и `awk` — это три мощных утилиты обработки текста в Unix/Linux-системах. Они часто используются вместе, но решают разные задачи:

---

## 🔍 1. **`grep`** — поиск строк по шаблону

### 🎯 Назначение:
Фильтрация строк в файле или потоке данных, **соответствующих заданному регулярному выражению**.

### ✅ Примеры:
```bash
# Найти строки, содержащие "error" в лог-файле
grep "error" /var/log/syslog

# Регистронезависимый поиск
grep -i "warning" app.log

# Показать номера строк
grep -n "TODO" *.java

# Инвертировать — показать всё, кроме совпадений
grep -v "^#" config.conf  # исключить комментарии

# Подсчитать количество совпадений
grep -c "404" access.log
```

### 💡 Когда использовать:
> Когда нужно **найти** или **отфильтровать** строки по содержимому.

---

## ✂️ 2. **`sed`** — потоковый редактор (stream editor)

### 🎯 Назначение:
**Модификация текста**: замена, удаление, вставка строк **на лету**, без изменения исходного файла (если не указано иное).

### ✅ Примеры:
```bash
# Заменить первое вхождение "foo" на "bar" в каждой строке
sed 's/foo/bar/' file.txt

# Заменить все вхождения
sed 's/foo/bar/g' file.txt

# Удалить пустые строки
sed '/^$/d' file.txt

# Удалить комментарии (строки, начинающиеся с #)
sed '/^#/d' config.ini

# Сохранить изменения в файл (in-place)
sed -i 's/old/new/g' file.txt

# Извлечь только вторую строку
sed -n '2p' file.txt
```

### 💡 Когда использовать:
> Когда нужно **изменить** текст: заменить, удалить, преобразовать — особенно в скриптах.

---

## 🧮 3. **`awk`** — язык обработки структурированных данных

### 🎯 Назначение:
Анализ и обработка **столбцов** (полей) в тексте, особенно когда данные разделены пробелами, табуляцией, запятыми и т.п.

`awk` работает по принципу:  
**`условие { действие }`**

### ✅ Примеры:
```bash
# Вывести первый столбец (по умолчанию поля разделены пробелами/табами)
awk '{print $1}' data.txt

# Вывести строки, где второй столбец > 100
awk '$2 > 100' sales.csv

# Использовать запятую как разделитель
awk -F',' '{print $1, $3}' users.csv

# Суммировать значения в первом столбце
awk '{sum += $1} END {print sum}' numbers.txt

# Форматированный вывод
awk '{printf "User: %s, ID: %s\n", $1, $2}' passwd

# Подсчитать количество строк
awk 'END {print NR}' file.txt
```

### 💡 Когда использовать:
> Когда данные **структурированы** (как таблица), и нужно работать с **полями**, агрегировать, фильтровать по числовым условиям.

## 🆚 Сравнение

| Характеристика       | `grep`                     | `sed`                          | `awk`                              |
|----------------------|----------------------------|----------------------------------|------------------------------------|
| **Основная цель**    | Поиск                      | Редактирование текста           | Обработка полей / вычисления      |
| **Работает с**       | Строками                   | Строками                        | Полями внутри строк               |
| **Поддержка regex**  | Да                         | Да                              | Да                                |
| **Арифметика**       | ❌ Нет                     | ❌ Нет                          | ✅ Да                             |
| **Условия/логика**   | Ограничено (`-v`, `-E`)    | Ограничено                      | ✅ Полноценный язык программирования |
| **Типичное применение** | Фильтрация логов        | Замена конфигов, очистка текста | Анализ CSV, логов, отчётов        |

## 🔄 Пример совместного использования

Допустим, есть лог:
```
192.168.1.10 - - [10/May/2026] "GET /api/users HTTP/1.1" 200 1024
192.168.1.11 - - [10/May/2026] "POST /api/login HTTP/1.1" 401 256
```

Задача: найти все **успешные POST-запросы** и извлечь IP и путь.

```bash
grep "POST" access.log | grep ' 200 ' | awk '{print $1, $7}'
```

Или через `awk` один:
```bash
awk '/POST/ && / 200 / {print $1, $7}' access.log
```

## 💎 Вывод

- **`grep`** → «Что есть в тексте?»
- **`sed`** → «Как изменить текст?»
- **`awk`** → «Что можно вычислить из структуры текста?»

Все три инструмента дополняют друг друга и составляют основу эффективной работы с текстом в терминале.
