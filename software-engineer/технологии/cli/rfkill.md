**rfkill** — утилита командной строки в Linux для управления беспроводными радиоустройствами: Wi‑Fi, Bluetooth, NFC, 3G/4G и т. д. Позволяет блокировать (отключать) и разблокировать (включать) их.


## Основные команды


1. **`rfkill list`**
   Показывает список всех беспроводных устройств и их статус:
   * индекс устройства (число);
   * тип (Wi‑Fi, Bluetooth и т. д.);
   * текущее состояние (`blocked` / `unblocked`).

2. **`rfkill block [идентификатор]`**
   Блокирует устройство:
   * `rfkill block 0` — блокирует устройство с индексом 0;
   * `rfkill block wifi` — блокирует все Wi‑Fi‑адаптеры;
   * `rfkill block bluetooth` — блокирует Bluetooth;
   * `rfkill block all` — блокирует **все** беспроводные устройства.


3. **`rfkill unblock [идентификатор]`**
   Разблокирует устройство (обратная операция):
   * `rfkill unblock 0` — разблокирует устройство с индексом 0;
   * `rfkill unblock wifi` — разблокирует Wi‑Fi;
   * `rfkill unblock bluetooth` — разблокирует Bluetooth;
   * `rfkill unblock all` — разблокирует **все** беспроводные устройства.

4. **`rfkill help`**
   Выводит справку по использованию команды.

---

## Когда пригодится


* **Проблема с подключением Wi‑Fi или Bluetooth.** Если адаптер не определяется, возможно, он заблокирован — проверьте статус через `rfkill list`.
* **Экономия заряда батареи.** Временное отключение беспроводных модулей на ноутбуке.
* **Безопасность.** Быстрое отключение радиомодулей (например, в самолёте).
* **Диагностика.** Проверка, не является ли блокировка причиной проблем с сетью.

## Как работает


Утилита взаимодействует с подсистемой ядра Linux **RFKill**, которая:
* отслеживает состояние устройств (через `/dev/rfkill` и `sysfs`);
* позволяет временно отключать радиопередатчики без физического изъятия оборудования;
* генерирует события при изменении состояния (полезно для скриптов и GUI‑утилит).

---

## Краткий пример использования


```bash
# Посмотреть статус всех устройств
rfkill list

# Если Wi‑Fi заблокирован (статус blocked), разблокировать его
rfkill unblock wifi


# Полностью отключить Bluetooth
rfkill block bluetooth
```

**Важно:** на ноутбуках аппаратные переключатели или комбинации клавиш (например, `Fn`+`F2`) могут устанавливать блокировку — `rfkill` отражает и такие состояния.
