**fdisk** — утилита командной строки в Linux для управления разделами жёстких дисков и других накопителей. Позволяет создавать, удалять, изменять и просматривать разделы на блочных устройствах (жёстких дисках, SSD, флешках и т. д.).

## Основные возможности

* просмотр таблицы разделов диска;
* создание первичных (primary) и расширенных (extended) разделов;
* удаление разделов;
* изменение типа раздела (например, установка флага «загрузочный»);
* запись изменений на диск.

## Как запустить

Синтаксис:
```bash
fdisk [опции] <устройство>
```

Примеры:
* `fdisk -l` — вывести список всех дисков и их разделов;
* `fdisk /dev/sda` — запустить интерактивное управление диском `/dev/sda`.

## Ключевые команды в интерактивном режиме

После запуска `fdisk <устройство>` вы попадаете в интерактивный режим. Основные команды (вводятся с клавиатуры):

* **`p`** — напечатать (print) текущую таблицу разделов (посмотреть, что есть на диске);
* **`n`** — создать новый раздел:
    * система спросит тип раздела (primary/extended), номер, начальный и конечный сектор (или размер);
* **`d`** — удалить (delete) раздел (спросит номер раздела);
* **`t`** — изменить тип раздела (например, установить Linux LVM, Linux swap и т. д.);
* **`a`** — включить/выключить флаг «загрузочный» (bootable) для раздела;
* **`w`** — записать (write) изменения на диск (применить все сделанные действия);
* **`q`** — выйти (quit) без сохранения изменений;
* **`m`** — показать справку (меню всех команд).

## Типовой сценарий работы

1. Посмотреть диски и разделы:
   ```bash
   fdisk -l
   ```
2. Запустить `fdisk` для нужного диска:
   ```bash
   fdisk /dev/sdb
   ```
3. Внутри `fdisk`:
   * `p` — посмотреть текущую разметку;
   * `n` → создать новый раздел;
   * `t` → при необходимости изменить тип;
   * `p` → проверить, всё ли верно;
   * `w` → записать изменения на диск.
4. Выйти из `fdisk`.

## Важные замечания и предупреждения

* **Требуются права суперпользователя.** Обычно нужно запускать с `sudo`: `sudo fdisk ...`.
* **Осторожность при работе.** Команды `fdisk` могут безвозвратно удалить данные. Перед изменениями:
    * сделайте резервную копию важных данных;
    * убедитесь, что работаете с правильным диском (`fdisk -l` поможет).
* **Изменения не применяются сразу.** Пока вы не ввели команду `w`, все действия существуют только в памяти утилиты. Команда `q` отменяет все изменения.
* **Не для файловых систем.** `fdisk` работает только с разделами. Чтобы создать файловую систему (ext4, ntfs и т. д.), используйте другие утилиты: `mkfs.ext4`, `mkfs.ntfs` и т. п.
* **Ограничения MBR.** В схеме разделов MBR можно создать не более 4 первичных разделов либо 3 первичных + 1 расширенный (внутри которого — логические разделы). Для большего числа разделов или дисков >2 ТБ используйте `parted` или `gdisk` (GPT).

---

**Итог:** `fdisk` — классический и мощный инструмент для разметки дисков в текстовом режиме. Подходит для базовых операций с разделами в MBR‑таблицах. Для GPT‑дисков и более сложных сценариев часто предпочитают `parted` или `gdisk`.
