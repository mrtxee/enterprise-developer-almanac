### Основные команды winget (Windows Package Manager)


Ниже — список самых востребованных команд с краткими пояснениями и примерами.


1. **Поиск пакетов**  
   ```cmd
   winget search <поисковая_строка>
   ```
   * Ищет пакеты по имени, ID или описанию.  
   * Пример: `winget search firefox`.


2. **Установка пакета**  
   ```cmd
   winget install <имя_или_ID_пакета>
   ```
   * Устанавливает указанный пакет.  
   * Пример: `winget install Mozilla.Firefox`.


3. **Удаление пакета**  
   ```cmd
   winget uninstall <имя_или_ID_пакета>
   ```
   * Удаляет установленный пакет.  
   * Пример: `winget uninstall Mozilla.Firefox`.


4. **Вывод списка установленных пакетов**  
   ```cmd
   winget list
   ```
   * Показывает все установленные через winget (и не только) программы.  
   * Можно фильтровать: `winget list --name "chrome"`.

5. **Информация о пакете**  
   ```cmd
   winget show <имя_или_ID_пакета>
   ```
   * Выводит детали о пакете: описание, версию, источник, URL.  
   * Пример: `winget show Mozilla.Firefox`.

6. **Обновление пакета**  
   ```cmd
   winget upgrade <имя_или_ID_пакета>
   ```
   * Обновляет конкретный пакет до последней версии.  
   * Пример: `winget upgrade Mozilla.Firefox`.


7. **Обновление всех пакетов**  
   ```cmd
   winget upgrade --all
   ```
   * Автоматически обновляет все установленные пакеты, для которых есть новые версии.


8. **Экспорт списка установленных пакетов**  
   ```cmd
   winget export -o <путь_к_файлу>.json
   ```
   * Сохраняет список установленных программ в JSON‑файл (полезно для переноса на другой ПК).  
   * Пример: `winget export -o C:\backup\installed.json`.


9. **Импорт пакетов из файла**  
   ```cmd
   winget import -i <путь_к_файлу>.json
   ```
   * Устанавливает пакеты, перечисленные в JSON‑файле.  
   * Пример: `winget import -i C:\backup\installed.json`.


10. **Управление источниками (репозиториями)**  
    ```cmd
    winget source list
    ```
    * Показывает список доступных репозиториев (например, `winget`, `msstore`).  
    * Другие команды:  
      * `winget source add` — добавить новый источник.  
      * `winget source remove` — удалить источник.  
      * `winget source update` — обновить список источников.


11. **Получение хэша установщика**  
    ```cmd
    winget hash <путь_к_установщику>
    ```
    * Вычисляет хэш файла установщика (например, для проверки целостности).

12. **Проверка манифеста пакета**  
    ```cmd
    winget validate <путь_к_манифесту>.yaml
    ```
    * Проверяет корректность YAML‑манифеста пакета (для разработчиков).


13. **Просмотр версии winget**  
    ```cmd
    winget --version
    ```
    * Показывает текущую версию утилиты.

14. **Справка по командам**  
    ```cmd
    winget --help
    ```
    * Выводит список всех команд и опций.  
    * Для справки по конкретной команде: `winget <команда> --help` (например, `winget install --help`).


### Полезные опции (используются с основными командами)
- `--exact` — точное совпадение имени (например, `winget search --exact "vscode"`).  
- `--versions` — показать все версии пакета (например, `winget show Mozilla.Firefox --versions`).  
- `--source <имя>` — ограничить поиск конкретным репозиторием (например, `--source msstore`).  
- `--silent` — тихая установка (без диалоговых окон).  
- `--accept-package-agreements` — автоматически принять лицензионные соглашения.  
- `--location <путь>` — указать каталог установки (например, `--location "D:\Programs"`).


### Примечания
- Команды выполняются в **PowerShell** или **Windows Terminal** (с правами администратора, если требуется).  
- По умолчанию winget использует репозитории `winget` (официальный) и `msstore` (Microsoft Store).  
- Для сложных сценариев (например, массового развёртывания) удобно комбинировать `export` и `import`.
