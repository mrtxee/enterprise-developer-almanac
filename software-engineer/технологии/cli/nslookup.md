`nslookup` (name server lookup) — утилита командной строки для **запросов к DNS‑серверам** с целью получения информации о доменных именах, IP‑адресах и других DNS‑записях.

### Назначение

Позволяет:
* преобразовывать доменные имена в IP‑адреса (и наоборот);
* проверять корректность DNS‑настроек;
* диагностировать проблемы с разрешением имён;
* просматривать различные типы DNS‑записей (A, MX, NS, CNAME и др.).

### Как работает

1. Пользователь вводит команду с доменом или IP.
2. Утилита отправляет запрос к **DNS‑серверу** (по умолчанию — к серверу, указанному в настройках сети).
3. DNS‑сервер ищет запись в своей базе или рекурсивно запрашивает другие серверы.
4. Результат возвращается в консоль.

### Основные режимы работы

1. **Интерактивный режим**  
   Запускается без параметров. Позволяет выполнять несколько запросов подряд.  
   Пример:  
   ```
   nslookup
   > google.com
   > mail.ru
   > exit
   ```

2. **Неинтерактивный режим**  
   Запрос указывается в одной строке.  
   Пример:  
   ```
   nslookup example.com
   ```

### Примеры использования

1. **Получить IP‑адрес домена**  
   ```
   nslookup google.com
   ```  
   Вывод:  
   ```
   Server:     8.8.8.8
   Address:    8.8.8.8#53

   Non-authoritative answer:
   Name:   google.com
   Address: 142.250.190.46
   ```

2. **Обратный DNS‑запрос (IP → домен)**  
   ```
   nslookup 8.8.8.8
   ```  
   Вывод:  
   ```
   Server:     8.8.8.8
   Address:    8.8.8.8#53

   Non-authoritative answer:
   8.8.8.8.in-addr.arpa   name = dns.google.
   ```

3. **Запросить конкретный DNS‑сервер**  
   ```
   nslookup google.com 1.1.1.1
   ```  
   Здесь `1.1.1.1` — адрес DNS‑сервера Cloudflare.

4. **Проверить MX‑записи (почтовые серверы)**  
   ```
   nslookup -type=mx example.com
   ```  
   Вывод:  
   ```
   example.com   mail exchanger = 10 mail.example.com.
   ```

5. **Просмотреть NS‑записи (серверы имён домена)**  
   ```
   nslookup -type=ns wikipedia.org
   ```

6. **Получить все записи домена**  
   ```
   nslookup -type=any example.com
   ```

### Полезные опции

* `-type=X` — указать [[DNS]] (`A`, `MX`, `NS`, `CNAME`, `TXT` и др.);
* `server X.X.X.X` — сменить DNS‑сервер в интерактивном режиме;
* `set debug` — включить подробный вывод (показ всех этапов запроса);
* `set vc` — использовать TCP вместо UDP (для больших ответов);
* `exit` или `quit` — завершить интерактивный режим.

### Важные замечания

1. **Non‑authoritative answer**  
   Означает, что ответ пришёл не от авторитетного сервера для домена, а от кэширующего DNS‑сервера.

2. **Утилита устарела**  
   `nslookup` считается устаревшей в пользу `dig` (в Linux/macOS) и `Resolve-DnsName` (в PowerShell). Однако она по‑прежнему доступна в Windows и многих дистрибутивах Linux.

3. **Ограничения**  
   * Не поддерживает DNSSEC‑проверку.
   * Менее информативна, чем `dig`.
   * В некоторых ОС может отсутствовать по умолчанию.

### Где используется

* **Администрирование сетей** — проверка DNS‑настроек.
* **Разработка** — отладка приложений, зависящих от DNS.
* **Кибербезопасность** — анализ подозрительных доменов.
* **Техническая поддержка** — диагностика проблем с доступом к сайтам.
