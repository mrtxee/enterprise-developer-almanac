Разберу пошагово, как подключиться к Wi‑Fi при установке Arch Linux с помощью `iwctl` — инструмента для работы с беспроводными сетями в составе пакета `iwd` (iNet wireless daemon).

## Предварительные условия

Убедитесь, что:
* используете официальный установочный образ Arch Linux (в нём по умолчанию есть `iwd`);
* беспроводной адаптер распознаётся системой.

## Пошаговая инструкция


1. **Запустите `iwctl`**

   В терминале установочного окружения выполните:
   ```bash
   iwctl
   ```
   Вы попадёте в интерактивную оболочку `iwctl` (приглашение `>`).

2. **Выведите список беспроводных устройств**

   Внутри `iwctl` выполните:
   ```plaintext
   device list
   ```
   Найдите имя вашего Wi‑Fi‑адаптера (обычно `wlan0`, `wlp2s0` и т. д.). Запомните его — оно понадобится в следующих командах.

3. **Включите устройство**

   Если адаптер выключен, включите его:
   ```plaintext
   station [device_name] power on
   ```
   Замените `[device_name]` на имя вашего адаптера (например, `station wlan0 power on`).

4. **Просканируйте сети**

   Запустите сканирование доступных Wi‑Fi‑сетей:
   ```plaintext
   station [device_name] scan
   ```
   Дождитесь завершения сканирования.

5. **Выведите список доступных сетей**

   Чтобы увидеть найденные сети, выполните:
   ```plaintext
   station [device_name] get-networks
   ```
   В списке будут SSID (имена сетей), уровень сигнала, тип шифрования и т. д.

6. **Подключитесь к сети**

   Используйте команду:
   ```plaintext
   station [device_name] connect [network_name]
   ```
   * `[device_name]` — имя вашего Wi‑Fi‑устройства;
   * `[network_name]` — SSID нужной сети (если в имени есть пробелы, заключите его в кавычки).

   Пример:
   ```plaintext
   station wlan0 connect MyHomeWiFi
   ```

   Если сеть защищена (WPA/WPA2), `iwctl` запросит пароль — введите его и нажмите Enter.

7. **Проверьте статус подключения**

   Убедитесь, что подключение установлено:
   ```plaintext
   station [device_name] show
   ```
   В выводе должна быть строка `Connected network: [network_name]`.

8. **Проверьте интернет‑соединение**

   Выйдите из `iwctl` командой `exit`, затем проверьте связь:
   ```bash
   ping -c 3 archlinux.org
   ```
   Если пакеты приходят (есть ответы от сервера), интернет работает.

9. **Завершите работу с `iwctl`**

   После успешного подключения просто выйдите из оболочки:
   ```plaintext
   exit
   ```

## Возможные проблемы и решения

* **Устройство не найдено (`device list` пуст)**
    * Проверьте, загружен ли драйвер для Wi‑Fi‑адаптера.
    * Убедитесь, что адаптер не заблокирован (например, аппаратным переключателем или `rfkill`). Проверьте статус: `rfkill list`. Если заблокировано, разблокируйте: `rfkill unblock wifi`.

* **Нет IP‑адреса (подключение есть, но интернет не работает)**
    * Установите и запустите DHCP‑клиент:
      ```bash
      dhcpcd [device_name]
      ```
      Пример: `dhcpcd wlan0`.

* **Проблемы с DNS (пинг по IP работает, по домену — нет)**
    * Настройте DNS вручную. Отредактируйте `/etc/resolv.conf`:
      ```bash
      echo "nameserver 8.8.8.8" > /etc/resolv.conf
      echo "nameserver 1.1.1.1" >> /etc/resolv.conf
      ```

* **Сеть не видна в `get-networks`**
    * Повторите сканирование: `station [device_name] scan`, подождите несколько секунд и снова выполните `get-networks`.

## Важные замечания

* `iwd` и `iwctl` предустановлены в официальном ISO Arch Linux. Если их нет (например, в кастомном образе), установите: `pacman -S iwd`.
* После установки системы рекомендуется настроить постоянное управление сетью (например, через `NetworkManager` или `systemd-networkd`).
* Для получения IP‑адреса после подключения может потребоваться запуск DHCP‑клиента (`dhcpcd` или `dhclient`).
