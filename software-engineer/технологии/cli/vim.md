# vim editor

* *start vim*
	* `$ vi example.txt`
	* To enter command mode, press `Esc`
* *commands*
	* **Modes**
		* i — for insert mode
		* I — insert text at beginning of current line
		* a — append text after cursor
		* A — append text at end of current line
		* Esc — command mode
	* **Navigation**
		* h — cursor left
		* j — cursor down (j looks trivially like a down arrow)
		* k — cursor up
		* l — cursor right
		* b — cursor to beginning of current word
		* e — cursor to end of current word
		* $ — go to end of line
		* 0 — go to beginning of line
		* gg — go to first line of file
		* G — go to last line of file
		* 9G — go to line 9 of file
	* **Select**
		* v — select text
		* V — select line
		* Copy and paste
		* y — copy ("yank") selection
		* yy — copy ("yank") the entire line
		* p — paste
	* **Delete**
		* x — delete character
		* dw — delete word
		* d$ — delete from current position to end of line
		* d0 — delete from current position to beginning of line
		* dG — delete to last line of file
	* **Undo**
		* u — undo
	* **Save**
		* :w — save
		* :wq — save and quit
		* :ZZ — save and quit
		* :q! — force quit without saving

# vim vs vi
Отличия между **vi** и **vim** — это **разница между древним инструментом и его современным, мощным потомком**.  
Многие думают, что это просто «разные версии одного редактора» — но на самом деле **Vim — это почти полностью переписанный, расширенный и улучшенный vi**, который стал **де-факто стандартом** в Linux/Unix-мире.

---

✅ Краткий ответ:  

| Критерий | **vi** | **vim** |
|----------|--------|---------|
| **Полное название** | Visual Editor | **Vi IMproved** (Vi Improved) |
| **Год создания** | 1976 (Bill Joy) | 1991 (Bram Moolenaar) |
| **Разработчик** | Университет Беркли | Bram Moolenaar |
| **Совместимость** | Сам по себе | **100% совместим с vi** — может работать как `vi` |
| **Функционал** | Минималистичный, базовый | **Огромный набор фич** — подсветка синтаксиса, автодополнение, плагины и т.д. |
| **Поддержка** | Устарел, почти не используется | **Активно развивается**, поддерживается до сих пор |
| **По умолчанию в Linux** | ❌ Нет (в новых дистрибутивах) | ✅ Да — `vim` — стандартный редактор |
| **Типичное имя в командной строке** | `vi` | `vim` (или `vi` как симлинк на `vim`) |

> 💡 **В современных системах (Ubuntu, CentOS, Fedora, macOS) `vi` — это просто симлинк на `vim`.**  
> То есть, когда вы пишете `vi file.txt` — на самом деле запускается **Vim**, а не старый `vi`.

---

**✅ Подробное сравнение: Что умеет vim, а vi — нет?**

| Функция | **vi** | **vim** | Почему важно |
|--------|--------|---------|--------------|
| **Подсветка синтаксиса** | ❌ Нет | ✅ Да (HTML, Python, Java, JSON и др.) | Ускоряет чтение кода, снижает ошибки |
| **Подсветка скобок** | ❌ Нет | ✅ Да | Помогает находить парные скобки `{}`, `[]`, `()` |
| **Автодополнение** | ❌ Нет | ✅ Да (Ctrl+X Ctrl+O — для кода, Ctrl+X Ctrl+N — по словам) | Экономит время при наборе |
| **Множественные окна / разделы** | ❌ Нет | ✅ Да (`:split`, `:vsplit`) | Можно редактировать 2 файла одновременно |
| **Работа с файлами по FTP/SFTP** | ❌ Нет | ✅ Да (`:e ftp://host/file`) | Можно редактировать файлы на удалённом сервере без скачивания |
| **Поддержка Unicode / UTF-8** | ❌ Ограниченная | ✅ Полная | Работает с кириллицей, эмодзи, азиатскими языками |
| **Плагины** | ❌ Нет | ✅ Да (через `.vimrc`, Vundle, vim-plug, Neovim) | Можно добавить: git-интеграцию, linters, темы, код-форматтеры |
| **История команд** | ❌ Ограниченная | ✅ Полная (можно прокручивать `↑`/`↓`) | Легко повторять команды |
| **Поиск и замена с регулярками** | ❌ Базовый | ✅ Расширенный (поддержка `\v`, `\m`, `\V`) | Более точный и мощный поиск |
| **Отмена действий (undo)** | ❌ Только одна отмена | ✅ История отмен (до 100+ действий) | Не боясь ошибиться — можно откатиться на 50 шагов назад |
| **Цветовая схема (theme)** | ❌ Нет | ✅ Да (`:colorscheme desert`, `:colorscheme gruvbox`) | Удобнее для глаз, особенно при долгой работе |
| **Работа с буферами и табами** | ❌ Нет | ✅ Да (`:buffers`, `:tabnew`, `:bnext`) | Удобно работать с несколькими файлами |
| **Горячие клавиши для навигации** | ❌ Только базовые | ✅ Много (Ctrl+O / Ctrl+I — навигация по истории, `gd` — перейти к определению) | Эффективность выше в 2–3 раза |
| **Интеграция с Git** | ❌ Нет | ✅ Через плагины (vim-fugitive) | Просмотр diff, коммиты, статус — прямо в редакторе |
| **Поддержка языков программирования** | ❌ Нет | ✅ Да (автодополнение для Python, JS, Go, Rust и др.) | Пишете код — vim помогает вам, как IDE |

✅ Пример: Как выглядит редактирование в vim vs vi

🔹 В **vi** (1976):
```bash
vi myfile.py
```
→ Только базовый режим.  
→ Нет подсветки.  
→ Нет автодополнения.  
→ Если ошиблись — `u` отменит только **последнее** действие.  
→ Нет понимания, что это Python-файл.

🔹 В **vim** (2024):
```bash
vim myfile.py
```
→ **Подсветка синтаксиса Python**  
→ Автодополнение: `for` → нажимаете `Ctrl+X Ctrl+O` → предлагает `for i in range()`  
→ Скобки подсвечиваются: `print("Hello")` — скобки мигают при курсоре на них  
→ Можно отменить 100 действий: `u` — `u` — `u` — ...  
→ Можно открыть два файла: `:split other.py`  
→ Можно перейти к определению функции: `gd`  
→ Можно открыть Git-статус: `:Gstatus`

✅ Как проверить, какой редактор у вас?

```bash
vi --version
```

Если вывод содержит:
```
VIM - Vi IMproved 9.0
...
```
→ Вы используете **Vim**.

Если вывод:
```
vi: command not found
```
→ У вас `vi` — это **симлинк на vim**. Проверьте:

```bash
which vi
# → /usr/bin/vi

ls -la /usr/bin/vi
# → lrwxrwxrwx 1 root root 20 Apr 1 2023 /usr/bin/vi -> /usr/bin/vim.tiny
```

> ✅ В **Ubuntu 22.04+**, **Fedora**, **macOS** — `vi` — это **Vim в мини-версии** (vim-tiny).  
> В **Arch Linux**, **CentOS** — `vim` — полноценный.

✅ Почему vim стал стандартом?

| Причина | Объяснение |
|--------|------------|
| ✅ **Обратная совместимость** | Vim может работать как `vi` — поэтому старые скрипты не сломались |
| ✅ **Открытый исходный код** | Бесплатный, развивается сообществом |
| ✅ **Кроссплатформенный** | Работает на Linux, macOS, Windows (через WSL, Cygwin) |
| ✅ **Лёгкий и быстрый** | Запускается за миллисекунды — даже на слабых серверах |
| ✅ **Мощный** | Почти как IDE, но без тяжёлого GUI |
| ✅ **Универсальный** | Работает через SSH — вы можете редактировать файлы на любом сервере |

---

✅ Когда использовать vi? Когда — vim?

| Ситуация | Рекомендация |
|----------|--------------|
| ✅ **Вы находитесь на старом сервере** (например, в embedded-системе, роутере, старом Unix) | → `vi` — он **всегда есть**, даже если vim не установлен |
| ✅ **Вы работаете на современном Linux/macOS** | → Используйте **`vim`** — он и есть `vi` в вашей системе |
| ✅ **Вы пишете код, скрипты, конфиги** | → Всегда **vim** — он делает вашу жизнь проще |
| ✅ **Вы учитесь Linux / DevOps / SysAdmin** | → Учитесь **vim** — это **неотъемлемая часть профессии** |
| ✅ **Вы работаете в SSH-сессии** | → **vim** — ваш лучший друг. Не нужен GUI, не нужен интернет — работает в терминале |

✅ Бонус: Как настроить vim как IDE?

Создайте файл `~/.vimrc`:

```vim
" Подсветка синтаксиса
syntax on
filetype plugin indent on

" Цветовая схема
colorscheme desert

" Номера строк
set number

" Отступы
set tabstop=4
set shiftwidth=4
set expandtab

" Автодополнение
set completeopt=menuone,noinsert,noselect

" Поиск без учёта регистра
set ignorecase
set smartcase

" История команд
set history=1000

" Отмена до 100 действий
set undolevels=1000
```

→ После перезапуска `vim` — вы получите **почти IDE**.
