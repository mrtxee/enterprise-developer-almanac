В Linux есть несколько способов сохранить вывод команды в файл — это полезно, например, для логирования, анализа или автоматизации задач. Вот основные методы, как это сделать в Bash:

---

### 1. **Перенаправление вывода в файл с перезаписью (`>`)**  
Если файл уже существует — его содержимое будет **удалено**, и запишется новый результат.

```bash
команда > файл.txt
```

**Пример:**
```bash
ls -la > список_файлов.txt
```
Сохранит вывод команды `ls -la` в файл `список_файлов.txt`. Если файла не было — он создастся.

---

### 2. **Дозапись в файл (`>>`)**  
Добавляет результат в **конец файла**, не удаляя старое содержимое.

```bash
команда >> файл.txt
```

**Пример:**
```bash
date >> лог.txt
```
Каждый раз будет добавлять текущую дату и время в конец файла `лог.txt`.

---

### 3. **Сохранение ошибок (`2>`)**  
Иногда команда завершается с ошибкой — её можно отдельно сохранить.

```bash
команда 2> ошибки.txt
```

**Пример:**
```bash
ls /не_существующая_папка 2> ошибка.txt
```
Сообщение об ошибке запишется в `ошибка.txt`, а основной вывод (если есть) — на экран.

---

### 4. **Сохранение и вывода, и ошибок в один файл**

#### Вариант A: Классический способ (работает везде)
```bash
команда > вывод_и_ошибки.txt 2>&1
```
- `>` — перенаправляет стандартный вывод (`stdout`) в файл.  
- `2>&1` — говорит: «а ошибки (`stderr`, поток 2) отправь туда же, куда идёт поток 1».

#### Вариант B: Короткая запись (только в Bash)
```bash
команда &> вывод_и_ошибки.txt
```
Это то же самое, что и выше, но короче. Однако **не работает в `sh` или `dash`**, так что для скриптов, которые должны быть универсальными, лучше использовать первый способ.

---

### 5. **Дозапись и вывода, и ошибок**
```bash
команда &>> файл.txt
```
или
```bash
команда >> файл.txt 2>&1
```
Оба варианта допишут и успешный вывод, и ошибки в конец файла.

---

### 6. **Использование `tee` — вывод на экран и в файл одновременно**
Иногда хочется **увидеть результат в терминале и сохранить его в файл**.

```bash
команда | tee файл.txt
```

Если нужно **дописывать**, а не перезаписывать:
```bash
команда | tee -a файл.txt
```

**Пример:**
```bash
df -h | tee использование_диска.txt
```
Покажет информацию о диске на экране и запишет в файл.

---

### Полезные советы:
- Чтобы **подавить весь вывод** (ничего не показывать и не сохранять), используйте:
  ```bash
  команда > /dev/null 2>&1
  ```
  `/dev/null` — это «чёрная дыра»: всё, что туда отправляется, исчезает.

- Проверить, успешно ли выполнилась команда, можно через код возврата:
  ```bash
  echo $?
  ```
  Если `0` — всё хорошо, если другое число — была ошибка.

---

Если ты, например, хочешь автоматически сохранять логи запуска скрипта — вот пример:

```bash
#!/bin/bash
exec &>> /home/пользователь/лог_запуска.txt
echo "Запуск скрипта в $(date)"
# тут твои команды
echo "Готово!"
```
`exec &>>` перенаправит **весь последующий вывод скрипта** в файл — удобно для логирования.
