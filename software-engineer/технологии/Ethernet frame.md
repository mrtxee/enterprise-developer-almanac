### Ethernet frame – кадр Ethernet

**Ethernet frame** (кадр Ethernet) — это блок данных канального уровня (L2 модели [[OSI]]), который передаётся по сети Ethernet. Это базовая единица передачи данных в Ethernet‑сетях: всё, что отправляется по Ethernet (пакеты IP, ARP‑запросы и т. д.), упаковывается в кадры.

## Структура кадра Ethernet (стандарт IEEE 802.3)


Типичный кадр Ethernet состоит из следующих полей:

| Поле | Размер (байт) | Назначение |
|------|--------------|----------|
| **Preamble** (преамбула) | 7 | Последовательность бит (`10101010`) для синхронизации приёмника с передатчиком. Не считается частью кадра при обработке, нужна только для синхронизации. |
| **SOF** (Start of Frame, иногда SFD — Start Frame Delimiter) | 1 | Маркер начала кадра (`10101011`). Сигнализирует, что следующие байты — это заголовки кадра. |
| **Destination MAC** (MAC‑адрес получателя) | 6 | Физический адрес устройства‑получателя (например, сетевой карты). |
| **Source MAC** (MAC‑адрес отправителя) | 6 | Физический адрес устройства‑отправителя. |
| **Type/Length** (тип или длина) | 2 | * Если значение ≥ 1536 (`0x0600`) — это **тип** протокола верхнего уровня (например, `0x0800` — IPv4, `0x86DD` — IPv6, `0x0806` — ARP).<br>* Если значение ≤ 1500 — это **длина** поля данных (Payload). |
| **Payload** (полезная нагрузка / данные) | 46–1500 | Данные от протоколов верхних уровней (IPv4, IPv6, ARP и др.). Если данные меньше 46 байт, добавляется поле **Pad**. |
| **Pad** (выравнивание) | 0–46 | Дополнительные байты (нули), если данные меньше 46 байт. Гарантирует минимальный размер кадра. |
| **FCS** (Frame Check Sequence, контрольная сумма) | 4 | Контрольная сумма CRC (Cyclic Redundancy Check). Используется для проверки целостности кадра. Если приёмник вычислит другую CRC, кадр отбрасывается. |

**Общий размер кадра:**
* минимальный: 64 байт (6 + 6 + 2 + 46 + 4);
* максимальный: 1518 байт (6 + 6 + 2 + 1500 + 4).
* с преамбулой и SFD: 1526 байт.

## Ключевые характеристики

* **MTU (Maximum Transmission Unit) = 1500 байт.** Это размер поля **Payload** — максимальная полезная нагрузка кадра без заголовков и FCS.
* **Минимальный размер кадра = 64 байт.** Гарантирует, что коллизии (столкновения кадров) будут обнаружены всеми устройствами в сегменте Ethernet. Если данных мало, добавляется **Pad**.
* **MAC‑адресация.** Кадры адресуются на канальном уровне с помощью 48‑битных MAC‑адресов. Коммутаторы используют эти адреса для пересылки кадров нужным портам.
* **Контроль ошибок.** FCS вычисляется отправителем и проверяется получателем. Повреждённые кадры отбрасываются.
* **Типы кадров.** В зависимости от значения поля **Type** кадр может нести данные разных протоколов (IPv4, IPv6, ARP, VLAN‑теги и др.).

## Варианты кадров Ethernet

1. **Ethernet II (DIX)** — самый распространённый. Использует поле **Type** для указания протокола.
2. **IEEE 802.3 / SNAP** — использует поле **Length**, а затем добавляет дополнительные заголовки (LLC, SNAP) для указания протокола. Встречается реже, в основном в legacy‑системах.
3. **Кадры с тегом VLAN (IEEE 802.1Q)** — содержат дополнительное 4‑байтное поле **Tag** после Source MAC, где указан номер VLAN. Увеличивают MTU на 4 байта (до 1504 байт).

## Как работает кадр в сети

1. **Отправка.** Устройство формирует кадр: заполняет MAC‑адреса, тип, данные, вычисляет FCS и добавляет преамбулу.
2. **Передача.** Кадр отправляется в сеть. Коммутатор читает **Destination MAC** и пересылает кадр только на нужный порт (если MAC‑адрес известен).
3. **Приём.** Получатель проверяет FCS. Если CRC совпадает, извлекает данные из **Payload** и передаёт их протоколу верхнего уровня (например, IP).
4. **Обработка.** Протокол верхнего уровня (IP) обрабатывает данные и, если нужно, формирует ответный кадр.

## Краткий итог

**Ethernet frame:**
* базовая единица данных в сетях Ethernet;
* имеет строгую структуру с заголовками, данными и контрольной суммой;
* MTU = 1500 байт (размер полезной нагрузки);
* использует MAC‑адресацию для доставки внутри сегмента сети;
* обеспечивает контроль ошибок через FCS;
* существует в нескольких вариантах (Ethernet II, 802.3, с VLAN‑тегами).
