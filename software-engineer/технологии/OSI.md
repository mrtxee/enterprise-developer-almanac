Отлично!  
**Модель OSI (Open Systems Interconnection)** — это **фундаментальная модель**, которая описывает, как данные передаются между компьютерами в сети. Она делит весь процесс на **7 уровней**, каждый из которых отвечает за свою часть.

> 🔑 Это не реальная технология, а **концептуальный каркас**, помогающий понять, **где и что происходит** при сетевом взаимодействии.

---

## ✅ Что такое модель OSI?

> **OSI Model** — это **7-уровневая модель** для структурирования сетевых протоколов и технологий.  
> Разработана **ISO (International Organization for Standardization)** в 1984 году.

Она помогает:
- Диагностировать проблемы: *"Где сломалось?"*
- Понимать, как работают интернет, Wi-Fi, HTTP, TCP/IP
- Объяснять новичкам, как устроена сеть

---

## ✅ 7 уровней модели OSI (от нижнего к верхнему)

| Уровень | Название               | Отвечает за                                        | Примеры                                                  |
| ------- | ---------------------- | -------------------------------------------------- | -------------------------------------------------------- |
| **7**   | **Application Layer**  | Взаимодействие пользователя с сетью                | HTTP, FTP, SMTP, DNS, REST API                           |
| **6**   | **Presentation Layer** | Формат данных: шифрование, компрессия, кодирование | SSL/[[TLS]], JPEG, MPEG, JSON/XML                        |
| **5**   | **Session Layer**      | Управление сеансом связи (начало/конец)            | NetBIOS, PPTP, RPC                                       |
| **4**   | **Transport Layer**    | Надёжная доставка, контроль потока, ошибок         | [[IP TCP UDP\|TCP]], UDP<br>* **socket** поверх TCP/UDP* |
| **3**   | **Network Layer**      | Маршрутизация (по IP-адресам)                      | [[IP TCP UDP\|IP]], ICMP, routers, firewalls             |
| **2**   | **Data Link Layer**    | Передача по одному "прыжку" (link), MAC-адресация  | Ethernet, Wi-Fi (802.11), switches                       |
| **1**   | **Physical Layer**     | Физическая передача битов                          | Кабели, Wi-Fi сигнал, оптика                             |

---

## 🧠 Как запомнить порядок уровней?

Используйте мнемонику:

> **"All People Seem To Need Data Processing"**

- **A**ll → **Application** (7)
- **P**eople → **Presentation** (6)
- **S**eem → **Session** (5)
- **T**o → **Transport** (4)
- **N**eed → **Network** (3)
- **D**ata → **Data Link** (2)
- **P**rocessing → **Physical** (1)

> ⬇️ Считаем сверху вниз: от человека к проводу.

## ✅ Подробнее по уровням

🔹 **Уровень 7: Прикладной (Application)**
- Работает с пользователем
- Протоколы: `HTTP`, `FTP`, `SMTP`, `DNS`, `REST`, `gRPC`
- ❗ Не путайте с "приложением" — это **не программа**, а **интерфейс между программой и сетью**

---

🔹 **Уровень 6: Представления (Presentation)**
- Преобразует данные в нужный формат
- Шифрование (`SSL/TLS`)
- Компрессия (`gzip`)
- Кодировка (`UTF-8`, `ASCII`)
- Конвертация форматов (`JSON ↔ XML`)

---

🔹 **Уровень 5: Сеансовый (Session)**
- Управляет **сессией**: установка, поддержание, закрытие соединения
- Диалог "клиент ↔ сервер"
- Например: `session start`, `data transfer`, `session end`

---

🔹 **Уровень 4: Транспортный (Transport)**
- Гарантирует **надёжную доставку**
- **TCP** — надёжный, с подтверждением
- **UDP** — быстрый, без подтверждения
- Разделение на порты (`80`, `443`, `8080`)
- Контроль потока и ошибок

---

🔹 **Уровень 3: Сетевой (Network)**
- **IP-адресация** и **маршрутизация**
- Определяет **путь пакета** через интернет
- Используется **роутерами**
- Протоколы: `IP`, `ICMP`, `ARP`, `IPv4`, `IPv6`

---

🔹 **Уровень 2: Канал передачи данных (Data Link)**
- Передача между **соседними узлами**
- Использует **MAC-адреса**
- Обнаружение ошибок (CRC)
- Протоколы: `Ethernet`, `Wi-Fi`, `PPP`, `VLAN`

---

🔹 **Уровень 1: Физический (Physical)**
- Передача **битов** по физической среде
- Кабели, радиоволны, оптоволокно
- Напряжение, частота, скорость
- Пример: `Cat6`, `Fiber`, `Wi-Fi 6`

---

## 🔄 Как работает передача данных через OSI?

🔍 По уровням OSI:

| Layer               | Что происходит                  | Запомни как...                                    | Пример                                               |
| ------------------- | ------------------------------- | ------------------------------------------------- | ---------------------------------------------------- |
| **7. Application**  | HTTP-запрос к API               | **Приложение** — то, что видит пользователь       | Gmail (браузер) использует `HTTPS`                   |
| **6. Presentation** | Шифрование через TLS            | **Шифрование и формат** — как данные представлены | Данные шифруются через `TLS`, конвертируются в байты |
| **5. Session**      | Сеанс установлен                | **Сеанс** — диалог начался                        | Устанавливается сеанс с сервером Google              |
| **4. Transport**    | TCP-соединение                  | **Транспорт** — надёжная доставка                 | TCP разбивает данные, гарантирует доставку           |
| **3. Network**      | IP: `192.0.2.1` → `203.0.113.1` | **Сеть** — маршрутизация по миру                  | IP-протокол направляет пакеты через роутеры          |
| **2. Data Link**    | MAC-адресация в локальной сети  | **Канал** — соседние устройства                   | Каждый хоп (роутер → роутер) использует Ethernet     |
| **1. Physical**     | Сигнал по кабелю или Wi-Fi      | **Физика** — кабели, свет, радиоволны             | Биты передаются по кабелю или радиосигналу           |
💡 **Запомните:**  
> **7 — человек**  
> **1 — железо**  
> Между ними — 5 уровней абстракции.
