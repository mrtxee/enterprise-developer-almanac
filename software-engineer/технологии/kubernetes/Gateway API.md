## Gateway API ([[software-engineer/технологии/kubernetes/Kubernetes]] Gateway API)

**Что это?** Стандарт (Kubernetes ресурс) для описания сетевого трафика в кластере.

**Аналогия:** **Дорожные знаки и разметка** в городе, которые указывают как транспорт должен перемещаться между районами.

### Характеристики:

- **Уровень:** Инфраструктура/Стандарт
    
- **Назначение:** Описание маршрутизации в Kubernetes
    
- **Фокус:** Сетевая инфраструктура, L4/L7 балансировка
    
- **Примеры:** GKE Gateway, Istio, NGINX Ingress Controller
