### Amazon EC2: что это

**Amazon EC2** (Elastic Compute Cloud) — сервис облачных вычислений в AWS, предоставляющий **виртуальные серверы** (инстансы) по модели IaaS (Infrastructure as a Service). Вы получаете полный контроль над ОС и ПО, платя только за использованные ресурсы.

### Ключевые возможности

- **Масштабирование «на лету»**: увеличивайте/уменьшайте мощность инстансов или их количество в зависимости от нагрузки.
- **Разнообразие конфигураций**: десятки типов инстансов под разные задачи (CPU, GPU, память, хранилище).
- **Гибкая оплата**: почасовая, спотовая (сниженная цена за прерываемые инстансы), зарезервированная (скидка за долгосрочное использование).
- **Интеграция с AWS**: прямой доступ к S3, RDS, VPC, IAM, CloudWatch и др.
- **Безопасность**: сетевые ACL, группы безопасности, шифрование дисков, интеграция с AWS KMS.
- **Автоматизация**: запуск через API, CLI, Terraform, CloudFormation.

### Основные компоненты

1. **Инстанс (Instance)** — виртуальный сервер с выбранной ОС (Linux, Windows, macOS) и конфигурацией.
2. **AMI (Amazon Machine Image)** — шаблон для создания инстанса (ОС + предустановленное ПО + настройки).
3. **Типы инстансов** — категории с разным соотношением CPU/RAM/GPU/хранилища:
 - *General Purpose* (T, M): баланс CPU и памяти (веб‑серверы, небольшие БД).
 - *Compute Optimized* (C): мощный CPU (HPC, пакетные вычисления).
 - *Memory Optimized* (R, X): большой объём RAM (кэши, in‑memory БД).
 - *Accelerated Computing* (P, G, F): GPU/FPGA (ML, рендеринг, криптография).
 - *Storage Optimized* (I, D): быстрые локальные диски (NoSQL, лог‑аналитика).
4. **Эластичные IP‑адреса** — статические публичные IP для инстансов.
5. **Группы безопасности** — виртуальные файрволы для контроля трафика.
6. **EBS (Elastic Block Store)** — сетевые блочные диски для хранения данных (аналоги HDD/SSD).
7. **VPC (Virtual Private Cloud)** — изолированная сетевая среда для инстансов.

### Как работает (кратко)


1. Вы выбираете **AMI** (образ ОС).
2. Подбираете **тип инстанса** (например, `t3.medium`).
3. Настраиваете **сеть** (VPC, подсети, группы безопасности).
4. Указываете **хранилище** (EBS‑диски, их размер и тип).
5. Задаёте **ключи SSH** для доступа.
6. Запускаете инстанс — через минуты он доступен по IP.
7. Управляете им через консоль AWS, CLI или API (старт/стоп/перезагрузка/изменение типа).


### Сценарии использования


- **Веб‑приложения**: хостинг сайтов, API, микросервисов.
- **Базы данных**: самостоятельные БД (MySQL, PostgreSQL) или вспомогательные ноды.
- **Аналитика и Big Data**: обработка данных (Spark, Hadoop), ETL‑пайплайны.
- **Machine Learning**: обучение моделей на GPU‑инстансах (P3, G4).
- **Тестирование и разработка**: временные среды для CI/CD.
- **Резервное копирование и DR**: аварийные инстансы в других регионах.
- **Игровые серверы**: высокопроизводительные инстансы для мультиплеера.


### Модели ценообразования


1. **On‑Demand** — почасовая оплата без обязательств (максимум гибкости).
2. **Reserved Instances** — скидка до 75 % за резервирование на 1–3 года.
3. **Spot Instances** — цена ниже On‑Demand до 90 %, но AWS может прервать инстанс при нехватке ресурсов.
4. **Dedicated Hosts** — физические серверы под ваш контроль (для лицензий с привязкой к CPU).


### Преимущества


- **Гибкость**: выбор ОС, ПО, конфигурации.
- **Масштабируемость**: от 1 до тысяч инстансов за минуты.
- **Глобальная инфраструктура**: регионы и зоны доступности по всему миру.
- **Интеграция**: работа с другими сервисами AWS (S3, RDS, Lambda).
- **Безопасность**: VPC, шифрование, IAM‑политики.
- **API‑управление**: автоматизация через CLI, SDK, Terraform.


### Ограничения


- **Сложность настройки** — требуется знание сетей, ОС, безопасности.
- **Затраты при неоптимальном выборе** — легко переплатить за неподходящий тип инстанса.
- **Привязка к AWS** — миграция на другой облачный провайдер может быть сложной.
- **Прерываемые инстансы (Spot)** — риск потери данных при прерывании.


### Пример запуска инстанса (CLI)

```bash
# Запуск t3.medium с AMI Amazon Linux 2
aws ec2 run-instances \
--image-id ami-0abcdef1234567890 \
--instance-type t3.medium \
--key-name my-key-pair \
--security-group-ids sg-0123456789abcdef0 \
--subnet-id subnet-0123456789abcdef0
```


### Итог


EC2 — это:
- **Виртуальные серверы в облаке** с полным контролем над ОС и ПО.
- **Широкий выбор конфигураций** под любые задачи (от CPU до GPU).
- **Гибкие модели оплаты** (On‑Demand, Reserved, Spot).
- **Глубокая интеграция** с экосистемой AWS.
- **Инструмент для масштабирования** — от тестового сервера до глобальной инфраструктуры.
