Разберу пошагово, как почистить место в корневом разделе (`/`) в Arch Linux с GNOME. Перед любыми действиями **сделайте бэкап важных данных**.


# root-cleanup
## Шаг 1. Анализ занятого места

Сначала выясните, какие папки занимают больше всего места:

* **Через `ncdu`** (удобный интерактивный инструмент):
  ```bash
  sudo pacman -S ncdu
  sudo ncdu /
  ```
  Используйте стрелки для навигации, `d` — удалить файл/папку, `q` — выход.

* **Через стандартную команду `du`**:
  ```bash
  sudo du -sh /* 2>/dev/null | sort -h
  ```
  Эта команда покажет размер всех папок в корне, отсортированный по возрастанию.

## Шаг 2. Очистка кэша пакетов

**Pacman** (основной менеджер пакетов):

* Очистить кэш устаревших пакетов (оставит последние версии):
  ```bash
  sudo pacman -Sc
  ```
* Полностью очистить кэш (включая последние версии — используйте осторожно):
  ```bash
  sudo pacman -Scc
  ```

**AUR‑хелперы** (если используете `yay`, `paru` и т. д.):
```bash
yay -Scc    # для yay
paru -Scc   # для paru
```

## Шаг 3. Удаление неиспользуемых пакетов

1. Найдите «сироты» (orphaned packages — зависимости, оставшиеся после удаления программ):
  ```bash
  pacman -Qdt
  ```
2. Если вывод не пуст, удалите их:
  ```bash
  sudo pacman -Rns $(pacman -Qdtq)
  ```
   **Внимание:** перед массовым удалением проверьте каждый пакет через `pacman -Qi <имя_пакета>`, чтобы случайно не удалить что‑то нужное.

## Шаг 4. Очистка временных файлов

* Удалите содержимое `/tmp` (временные файлы, обычно удаляются при перезагрузке):
  ```bash
  sudo rm -rf /tmp/*
  ```
* Проверьте `/var/tmp` (долгоживущие временные файлы):
  ```bash
  sudo du -sh /var/tmp
  sudo rm -rf /var/tmp/*  # если много места занято
  ```

## Шаг 5. Очистка логов

Большие логи могут занимать много места:
* Посмотрите, какие логи самые объёмные:
  ```bash
  sudo du -sh /var/log/* | sort -h
  ```
* Очистите старые логи (осторожно, не удаляйте активные):
  ```bash
  sudo journalctl --vacuum-size=100M  # оставить только последние 100 МБ логов
  sudo find /var/log -name "*.log" -type f -delete  # удалить все .log (не рекомендуется без проверки)
  ```

## Шаг 6. Проверка больших файлов

Найдите файлы больше 100 МБ в корне:
```bash
sudo find / -xdev -type f -size +100M -exec ls -lh {} \; 2>/dev/null
```
Просмотрите результат и удалите ненужные (например, старые ISO‑образы, дампы).

## Шаг 7. Дополнительные инструменты

* **BleachBit** — графический «уборщик»:
  ```bash
  sudo pacman -S bleachbit
  bleachbit
  ```
  Позволяет безопасно очистить кэш браузеров, временные файлы и т. д.

* **fdupes** — поиск дубликатов файлов:
  ```bash
  sudo pacman -S fdupes
  fdupes -r /home /etc ...  # укажите нужные папки
  ```

---

## Важные предупреждения

* **Не удаляйте вручную файлы в `/usr`, `/bin`, `/lib`, `/etc` без понимания их назначения** — это может сломать систему.
* Перед `pacman -Scc` убедитесь, что у вас есть доступ к интернету — восстановить удалённые пакеты без сети сложно.
* Если используете `BleachBit`, не выбирайте опции, затрагивающие системные разделы или важные конфигурации.
* После очистки кэша пакетов (`pacman -Sc`) проверьте, что система загружается и все программы работают.

## Профилактика

Чтобы проблема не повторялась:
* Раз в 1–2 месяца запускайте `pacman -Sc`.
* Периодически проверяйте `/tmp` и `/var/tmp`.
* Используйте `ncdu` для мониторинга перед установкой крупных программ.

Если хотите, могу подробнее разобрать какой‑то конкретный шаг или помочь с анализом вашей ситуации — укажите, какие папки/файлы занимают больше всего места по результатам `ncdu`.

# home-cleanup
Чтобы найти и удалить большие и ненужные файлы в вашей домашней директории, можно использовать как интерактивный способ с программой `ncdu`, так и быстрый анализ в терминале с помощью стандартных команд `du` и `find`.

### 🔍 Быстрый анализ через терминал

Вот несколько простых команд, которые помогут вам быстро найти, какие файлы и папки занимают больше всего места.

*   **Топ-15 самых "тяжёлых" директорий:**
    Эта команда просканирует ваш домашний каталог (`~`) и покажет 15 самых больших папок.
    ```bash
    du -h ~/ --max-depth=1 | sort -hr | head -n 15
    ```
    *Здесь `du -h` выводит размер в удобном для человека формате, `--max-depth=1` ограничивает глубину, а `sort -hr` и `head` сортируют и показывают результат.*

*   **Топ-20 самых больших файлов:**
    Эта команда найдет все файлы (`-type f`) в вашем домашнем каталоге и покажет 20 самых крупных.
    ```bash
    find ~/ -type f -exec du -Sh {} + | sort -rh | head -n 20
    ```
    *(Объяснение: `find` перебирает файлы, `du -Sh` выводит их размер в удобном формате, а `sort -rh | head` сортирует и выбирает топ результатов.)*

Этих двух команд обычно достаточно, чтобы быстро определить "виновника" переполненного диска.

### 💾 Интерактивная очистка с `ncdu`

`ncdu` (NCurses Disk Usage) — мощная консольная утилита для интерактивного исследования и удаления файлов. Вы можете перемещаться по папкам и удалять ненужное, не запоминая сложные команды.

1.  **Установка:**
    Если `ncdu` еще не установлена, выполните:
    ```bash
    sudo pacman -S ncdu
    ```
    

2.  **Запуск и работа:**
    Запустите сканирование вашей домашней папки:
    ```bash
    ncdu ~/
    ```
    *Подсказка: если в вашей домашней папке много файлов, процесс может занять некоторое время. Чтобы не сканировать временные файлы, можно добавить параметр `--exclude .cache`.*

3.  **Навигация и удаление:**
    После завершения сканирования вы увидите список всех папок и файлов, отсортированных по размеру. Для управления используйте клавиши:
    *   **Стрелки (`↑`/`↓`)** — перемещение по списку.
    *   **`Enter`** — войти в выбранную папку.
    *   **`]` (закрывающая квадратная скобка)** — выйти на уровень выше.
    *   **`d`** — удалить выбранный файл или папку (программа запросит подтверждение).
    *   **`q`** — выйти из программы.

### 🧹 Стратегии очистки домашней папки

Когда вы найдёте, чем занято место, можно приступать к чистке. Вот на что стоит обратить внимание в первую очередь:

*   **Очистка кэша** (`~/.cache/`): Многие приложения хранят здесь временные данные. Обычно удаление содержимого этой папки безопасно, но делать это лучше выборочно. Вы можете просмотреть её содержимое с помощью `du -sh ~/.cache/*`. Удалить старые и неиспользуемые файлы кэша можно командой:
    ```bash
    find ~/.cache -depth -type f -atime +100 -delete
    ```
    Эта команда удалит файлы, к которым не было обращений более 100 дней.

*   **Очистка корзины**: Не забывайте периодически очищать корзину вашего рабочего стола (обычно это папка `~/.local/share/Trash`).

*   **Удаление дубликатов**: Вы можете найти и удалить дублирующиеся файлы с помощью утилиты `rmlint`. Установите её (`sudo pacman -S rmlint`) и запустите из терминала в вашей домашней папке. Программа найдет все возможные дубликаты и предложит, что с ними сделать.

*   **Управление пакетами (Cache и Orphans)**: Хотя ваш вопрос конкретно о `/home`, не лишним будет напомнить, что место могут занимать и системные файлы.
    *   Очистить кэш `pacman`: `sudo paccache -r` (оставляет 3 последние версии пакетов).
    *   Удалить "осиротевшие" пакеты (не нужные ни одной программе): `sudo pacman -Rns $(pacman -Qtdq)`.

*   **Другие папки для проверки**: Иногда большие объёмы данных могут храниться и в других скрытых папках, например, `~/.local/` (особенно если вы используете `flatpak`), `~/.config/` (конфиги) или `~/.mozilla/` / `~/.cache/chromium/` (кэш и профили браузеров).

Надеюсь, эти советы помогут вам навести порядок на диске. Если появятся вопросы по конкретным файлам или папкам, смело задавайте
