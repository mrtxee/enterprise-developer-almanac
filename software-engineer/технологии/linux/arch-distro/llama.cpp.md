После сборки `llama.cpp` у вас есть всё необходимое для запуска больших языковых моделей локально. Сборка прошла успешно, теперь осталось получить саму модель и запустить её. Я подготовил инструкцию, как это сделать с помощью `llama-cli` или `llama-server`.

### 🚀 Запуск модели через `llama-cli` (интерактивный режим)

Этот режим позволяет общаться с моделью прямо в терминале.

1.  **Скачайте модель.** Модели в `llama.cpp` имеют формат `.gguf`. Для первого знакомства я советую взять небольшую модель, например, `Qwen2.5-3B-Instruct`. Она весит около 2 ГБ и отлично работает на многих системах. Сохраните её в отдельную папку, например, `models`:
    ```bash
    mkdir -p models
    cd models
    wget https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/main/qwen2.5-3b-instruct-q4_k_m.gguf
    cd ..
    ```

2.  **Запустите `llama-cli`.** После загрузки модели выполните команду:
    ```bash
    ./build/bin/llama-cli -m models/qwen2.5-3b-instruct-q4_k_m.gguf
    ```
    *   `-m` — указывает путь к файлу модели.
    *   По умолчанию будет запущен интерактивный режим, и вы сможете начать диалог. Чтобы завершить разговор, введите, например, `Ctrl+C`.

### 🎛️ Ключевые параметры для тонкой настройки

Вы можете управлять производительностью и поведением модели с помощью следующих флагов.

| Флаг | Описание | Пример |
| :--- | :--- | :--- |
| **`-t <N>`** | Количество потоков для CPU. Установите число, равное количеству ядер вашего процессора. | `-t 8` |
| **`-ngl <N>`** | Количество слоёв модели, которые будут выгружены на **GPU** (Vulkan). Это значительно ускоряет обработку. Вы можете установить `-ngl 20` или `-ngl 99`, чтобы загрузить как можно больше. | `-ngl 20` |
| **`-c <N>`** | Размер контекста. Определяет, насколько "длинной" будет память модели. | `-c 2048` |
| **`-n <N>`** | Максимальное количество токенов, которое сгенерирует модель за раз. | `-n 256` |
| **`--color`** | Включает цветной вывод в терминале, что удобно для чтения. | `--color` |
| **`-e`** | Обрабатывает управляющие последовательности в промпте (например, `\n` для новой строки). | `-e` |

### ⚙️ Пример запуска с оптимизацией под вашу систему

```bash
./build/bin/llama-cli -m models/qwen2.5-3b-instruct-q4_k_m.gguf -t 8 -ngl 20 -c 2048 --color
```

> **Важное примечание:** Если при запуске вы видите в выводе сообщение `llama_vulkan: Found 1 Vulkan devices:`, значит, Vulkan-ускорение активно и всё работает корректно. Если этой строки нет, проверьте, что при сборке вы использовали флаг `-DGGML_VULKAN=ON`.

### 🌐 Запуск HTTP-сервера (`llama-server`)

Если вы хотите использовать модель через веб-интерфейс или из другого приложения, запустите сервер:

```bash
./build/bin/llama-server -m models/qwen2.5-3b-instruct-q4_k_m.gguf
```

После этого сервер будет доступен по адресу `http://127.0.0.1:8080`, и вы сможете отправлять к нему запросы, совместимые с API OpenAI.

### ⚠️ Возможные ошибки и их решение

*   **`error: invalid argument: -i`**: В новых версиях `llama.cpp` интерактивный режим включён по умолчанию, поэтому флаг `-i` больше не нужен.
*   **`error: unknown command: ./main`**: Это устаревшая команда. Вместо неё используйте `./build/bin/llama-cli`.
*   **Ошибка при сборке `Could NOT find Vulkan`**: Убедитесь, что вы установили пакет `vulkan-devel` перед сборкой.
