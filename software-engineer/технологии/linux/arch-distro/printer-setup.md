Да, Endeavour OS **может** автоматически находить USB-принтеры, но **не "из коробки"**. В отличие от Ubuntu или Fedora, где все необходимые службы уже предустановлены, Endeavour OS (как и чистый Arch) требует минимальной настройки. После выполнения нескольких простых шагов принтер будет определяться мгновенно при подключении.

### 🧩 Что нужно сделать для автоматического обнаружения?

1. **Установите CUPS** — систему печати.
   ```bash
   sudo pacman -S cups
   ```

2. **Запустите и включите службу CUPS**.
   ```bash
   sudo systemctl enable --now cups
   ```

3. **Установите драйвер для вашего принтера**. Для большинства USB-принтеров подойдёт универсальный драйвер `gutenprint` или `hplip` (для HP). Если у вас Brother — установите `brlaser` или драйвер из AUR. Но даже без драйвера CUPS может определить принтер как "Generic".

4. **Добавьте пользователя в группу `lp`**, чтобы иметь доступ к принтеру без пароля.
   ```bash
   sudo usermod -aG lp $USER
   ```
   Выйдите из системы и зайдите заново.

5. **Убедитесь, что модуль ядра `usblp` загружен**. Обычно он загружается автоматически при подключении принтера. Проверить можно командой:
   ```bash
   lsmod | grep usblp
   ```
   Если модуль не загружен, подключите принтер и перезагрузите систему, либо загрузите вручную: `sudo modprobe usblp`.

После этого при подключении USB-принтера вы увидите уведомление (если у вас есть DE, поддерживающее уведомления) и сможете добавить его через настройки принтеров или через веб-интерфейс CUPS (`http://localhost:631`).

### 🧪 Проверка автоматического обнаружения

- Подключите принтер по USB.
- Откройте терминал и выполните:
  ```bash
  dmesg | tail -20
  ```
  Вы должны увидеть сообщения ядра о том, что устройство опознано (например, `usb 1-2: new full-speed USB device...`).
- Затем откройте `http://localhost:631` → Administration → Find New Printers. Если CUPS видит устройство, оно появится в списке.

### ⚠️ Важные нюансы

- **Автоматическая установка драйвера** не произойдёт — вам нужно будет выбрать модель вручную при добавлении принтера (CUPS предложит список совместимых). Для многих принтеров подойдёт драйвер `Generic PostScript` или `Gutenprint`.
- **Если принтер не определяется** — возможно, модуль `usblp` заблокирован. В некоторых сборках ядра его отключают. Тогда добавьте параметр ядра: в файле `/etc/modprobe.d/blacklist.conf` убедитесь, что `usblp` не в чёрном списке. Или загрузите его вручную.

### 🖨️ Итог

Endeavour OS **умеет** автоматически обнаруживать USB-принтеры, но только после того, как вы установите и запустите CUPS. Само обнаружение работает через механизм `udev` и не требует дополнительных драйверов для самого факта обнаружения. Однако для полноценной печати вам всё равно понадобится подходящий драйвер. Следуя инструкции выше, вы сможете добиться того же уровня автоматизации, что и в Ubuntu.
