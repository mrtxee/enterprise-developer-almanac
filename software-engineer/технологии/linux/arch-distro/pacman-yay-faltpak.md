Это три инструмента разного уровня, которые решают разные задачи на Arch Linux. Ниже подробный разбор и готовая шпаргалка по командам.

---

## 📊 Краткое сравнение

| Критерий | `pacman` | `yay` | `flatpak` |
|----------|----------|-------|-----------|
| **Тип** | Нативный пакетный менеджер Arch | AUR-хелпер (обёртка над `pacman`) | Дистрибутиво-независимая песочница |
| **Что устанавливает** | Официальные пакеты Arch (`.pkg.tar.zst`) | Официальные пакеты + **AUR** (PKGBUILD → сборка/бинарник) | Изолированные приложения (`*.flatpak`, рантаймы) |
| **Уровень интеграции** | Полная (системные пути, библиотеки, драйверы) | Полная (как `pacman`) | Песочница (ограниченный доступ к `~`, `/run/media`, D-Bus) |
| **Зависимости** | Системные, разделяемые между всеми пакетами | Системные + AUR-специфичные | Встроенные или общие рантаймы (`org.freedesktop.Platform`, `org.gnome.Platform` и т.д.) |
| **Безопасность** | Официальные репозитории → подпись GPG | Сообщество → проверка PKGBUILD, но без гарантий | Изоляция + явные разрешения (`--filesystem`, `--socket`) |
| **Для чего нужен** | Ядро системы, драйверы, библиотеки, официальные приложения | Программы, которых нет в официальных репозиториях (проприетарные, свежие, нишевые) | GUI-приложения, кросс-дистрибутивная установка, безопасный запуск |

---

## 📖 Подробно о каждом

### 🔹 `pacman`
Официальный менеджер пакетов Arch Linux. Работает быстро, строго разрешает зависимости, гарантирует целостность через GPG-подписи. Это **фундамент системы**.

### 🔹 `yay`
Неофициальный, но де-факто стандартный **AUR-хелпер**. Написан на Go, использует синтаксис `pacman`, автоматически:
- Ищет в официальных репозиториях и AUR
- Загружает `PKGBUILD`, собирает пакет или скачивает prebuilt
- Разрешает зависимости, в том числе AUR-зависимости
- Делегирует установку/удаление `pacman`

### 🔹 `flatpak`
Система упаковки приложений в **изолированные контейнеры**. Не зависит от дистрибутива, не ломает системные библиотеки, обновляется независимо от ОС. Идеален для десктопных программ (браузеры, мессенджеры, IDE, графика).

## 🛠 Шпаргалка по командам

| Задача                           | `pacman`                                                                      | `yay`                                                    | `flatpak`                                                                                       |
| -------------------------------- | ----------------------------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 🔍 **Поиск пакета**              | `pacman -Ss <имя>`                                                            | `yay -Ss <имя>`                                          | `flatpak search <имя>`                                                                          |
| 🔍 **Поиск среди установленных** | `pacman -Qs <имя>`                                                            | `yay -Qs <имя>`                                          | `flatpak list --app \| grep "<имя>"`                                                            |
| 📦 **Установить**                | `sudo pacman -S <имя>`                                                        | `yay -S <имя>`                                           | `flatpak install flathub <app-id>`                                                              |
| 🗑️ **Удалить**                  | `sudo pacman -Rns <имя>`                                                      | `yay -Rns <имя>`                                         | `flatpak uninstall <app-id>`                                                                    |
| 🧹 **Удалить сироты**            | `sudo pacman -Rns $(pacman -Qdtq)`                                            | `sudo pacman -Rns $(pacman -Qdtq)` *(делегирует pacman)* | `flatpak uninstall --unused`                                                                    |
| 💾 **Очистить кэш**              | `paccache -r` *(оставляет 3 версии)*<br>`sudo pacman -Scc` *(полная очистка)* | `yay -Sc`<br>`yay -Yc` *(очистка build-файлов AUR)*      | Нет традиционного кэша.<br>Для чистки: `flatpak uninstall --unused` + `rm -rf ~/.cache/flatpak` |

> 💡 `pacman -Rns` означает: `R`emove, `n`o save config files, `s`kip dependencies that are not orphans.  
> 💡 Для `paccache` нужен пакет: `sudo pacman -S pacman-contrib`

## 🧩 Как правильно комбинировать

| Ситуация | Что использовать | Почему |
|----------|------------------|--------|
| Обновление системы, драйверы, ядро, библиотеки | `sudo pacman -Syu` | Гарантирует целостность Arch |
| Установка `discord`, `spotify`, `visual-studio-code-bin`, `yay` | `yay -S <имя>` | Пакетов нет в официальных репозиториях, но нужны системные зависимости |
| Установка `Telegram`, `Firefox`, `GIMP`, `VLC`, `Steam` | `flatpak install flathub ...` | Изоляция, автоматические обновления, не конфликтует с системными версиями |
| Очистка места на диске | `paccache -r` → `flatpak uninstall --unused` → `yay -Yc` | Каждый инструмент чистит только свой слой |

## ⚠️ Важные нюансы

1. **Не ставьте один и тот же пакет одновременно через `pacman`/`yay` и `flatpak`**  
   Например, `pacman -S firefox` и `flatpak install flathub org.mozilla.firefox` создадут две независимые установки. Это допустимо, но занимает лишнее место и может путать ассоциации файлов.

2. **AUR ≠ репозиторий**  
   `yay` скачивает `PKGBUILD` от пользователей. Всегда просматривайте содержимое перед сборкой:  
   ```bash
   yay -G <имя> && cd <имя> && less PKGBUILD
   ```

3. **Flatpak и права доступа**  
   По умолчанию Flatpak-приложения не видят `~/.ssh`, `~/.gnupg`, внешние диски. Разрешения управляются через:
   ```bash
   flatpak override --user --filesystem=home <app-id>
   flatpak override --user --socket=wayland --socket=x11 <app-id>
   ```

4. **Кэш pacman занимает гигабайты**  
   Arch не удаляет старые пакеты автоматически. Настройте регулярную очистку:
   ```bash
   sudo systemctl enable paccache.timer  # автоматически чистит кэш еженедельно
   ```

## ✅ Итоговая рекомендация для Arch + GNOME
- `pacman` → всё, что касается системы, ядра, драйверов, официальных пакетов
- `yay` → только то, чего нет в официальных репозиториях (проверив `PKGBUILD`)
- `flatpak` → десктопные приложения, особенно проприетарные или требующие свежих версий без риска сломать систему

Если нужно настроить автоматическую очистку, интеграцию Flatpak с GNOME Software или безопасный поиск в AUR, напишите — дам готовые скрипты и конфиги. 🛠️

## 🔹 pacman

### 🌐 Удалённый поиск (официальные репозитории)
```bash
# Поиск по имени и описанию
pacman -Ss firefox

# Поиск только по имени пакета
pacman -Ss '^firefox$'

# Поиск в конкретном репозитории
pacman -Sl extra | grep firefox

# Поиск пакета, которому принадлежит файл
pacman -F /usr/bin/firefox

# Обновить базу файлов перед поиском
sudo pacman -Fy
```

### 💻 Локальный поиск (установленные пакеты)
```bash
# Поиск среди установленных
pacman -Qs firefox

# Показать все установленные пакеты
pacman -Q

# Показать только имена установленных пакетов
pacman -Qq

# Показать версии установленных пакетов
pacman -Q | grep firefox

# Показать явно установленные пакеты (не зависимости)
pacman -Qe

# Показать сироты (пакеты, которые никому не нужны)
pacman -Qdt
```

## 🔹 yay

### 🌐 Удалённый поиск (официальные репозитории + AUR)
```bash
# Поиск везде (официальные репо + AUR)
yay -Ss firefox

# Поиск только в AUR
yay -Ss firefox | grep "aur/"

# Поиск только в официальных репозиториях
yay -Ss firefox | grep -v "aur/"

# Поиск с фильтрацией по версии
yay -Ss firefox

# Поиск пакетов, доступных для обновления
yay -Qu
```

> 💡 **Распознавание источника**: в выводе `yay -Ss`:
> - `extra/firefox 120.0-1` → официальный репозиторий
> - `aur/firefox-beta-bin 121.0b1-1` → AUR

### 💻 Локальный поиск (установленные пакеты)
```bash
# Поиск среди установленных (как pacman -Qs)
yay -Qs firefox

# Показать все установленные пакеты
yay -Q

# Показать AUR-пакеты среди установленных
yay -Qm

# Показать официальные пакеты среди установленных
yay -Qn

# Показать сироты
yay -Qdt

# Показать пакеты, которые можно обновить (включая AUR)
yay -Qu
```

## 🔹 flatpak

### 🌐 Удалённый поиск (Flathub и другие remote)
```bash
# Поиск по всем подключённым remote
flatpak search firefox

# Поиск в конкретном remote (например, flathub)
flatpak search --origin flathub firefox

# Список всех пакетов в remote
flatpak remote-ls flathub

# Поиск в remote с фильтрацией
flatpak remote-ls flathub | grep firefox

# Добавить flathub, если ещё не добавлен
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
```

### 💻 Локальный поиск (установленные приложения)
```bash
# Список всех установленных flatpak-приложений
flatpak list

# Только имена приложений
flatpak list --app

# Только runtime
flatpak list --runtime

# Поиск установленного приложения
flatpak list | grep firefox

# Показать информацию об установленном приложении
flatpak info org.mozilla.firefox

# Показать, какие приложения используют runtime
flatpak list --app --columns=name,application,runtime | grep firefox
```

# flatpak
Разберу, как очистить кэш, настройки и данные от удалённых Flatpak‑программ — с командами и альтернативными способами.

## Основные команды


1. **Удалить неиспользуемые зависимости и рантаймы**


Команда находит и удаляет компоненты, которые больше не нужны ни одному установленному Flatpak‑пакету:
```bash
flatpak uninstall --unused
```

2. **Очистить кэш загруженных пакетов**

Удаляет временные файлы и кэш загруженных приложений:
```bash
flatpak repair --delete-old
```
Или вручную:
```bash
sudo rm -rf /var/tmp/flatpak-cache-*
```
(если Flatpak использует системный кэш)

3. **Удалить конфигурационные данные и пользовательские данные**

Flatpak хранит данные пользователя в `~/.var/app/`. Чтобы удалить остатки удалённого приложения:
```bash
rm -rf ~/.var/app/<ID_пакета>
```
Где `<ID_пакета>` — например, `org.gimp.GIMP`.

**Как узнать ID пакета:**
```bash
flatpak list --app
```

4. **Проверить и очистить дополнительные директории**

* **Кэш:** `~/.cache/flatpak/`
* **Локальные данные:** `~/.local/share/flatpak/`

Команды для очистки:
```bash
rm -rf ~/.cache/flatpak/*
rm -rf ~/.local/share/flatpak/repo/tmp/*
```

---

## Полный пошаговый процесс очистки

1. Удалить неиспользуемые компоненты:
```bash
flatpak uninstall --unused
```
2. Очистить кэш:
```bash
flatpak repair --delete-old
```
3. Найти и удалить остатки данных по ID пакета:
```bash
flatpak list --app  # посмотреть список пакетов и их ID
rm -rf ~/.var/app/<ID_удалённого_пакета>  # удалить данные
```
4. Очистить дополнительные директории:
```bash
rm -rf ~/.cache/flatpak/* ~/.local/share/flatpak/repo/tmp/*
```
5. Проверить результат:
```bash
du -sh ~/.var/app/*  # проверить размер оставшихся данных
flatpak list  # убедиться, что ненужные пакеты удалены
```

## Альтернативный способ: использование Flatsweep

Flatsweep — графический инструмент для автоматической очистки остатков Flatpak.

**Установка:**
```bash
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install flathub io.github.giantpinkrobots.flatsweep
```

**Использование:**
1. Запустите Flatsweep:
```bash
flatpak run io.github.giantpinkrobots.flatsweep
```
2. Дождитесь завершения сканирования.
3. Нажмите кнопку **Clean** для удаления найденных остатков.

**Преимущества Flatsweep:**
* автоматически находит все остатки (данные, кэш, конфигурации);
* показывает объём освобождаемого места;
* не требует запоминания команд;
* минимизирует риск случайного удаления нужных данных.


---

## Важные предупреждения

* **Резервное копирование.** Перед удалением данных сделайте бэкап важных настроек или файлов.
* **Осторожность с `rm -rf`.** Команда необратимо удаляет файлы — убедитесь, что указываете правильный путь.
* **Не удаляйте активные данные.** Проверьте, что пакет действительно удалён, прежде чем очищать его данные.
* **Системные рантаймы.** Flatpak не удалит рантаймы, используемые другими приложениями, даже если вы очистили кэш.
* **Права доступа.** Пользовательские данные (`~/.var/app/`) удаляются без `sudo`, системные компоненты — с правами администратора.

---

## Проверка результата

После очистки проверьте:
* объём занятого места: `du -sh ~/.var/app/`
* список установленных пакетов: `flatpak list`
* состояние кэша: `ls ~/.cache/flatpak/` (должно быть пусто или почти пусто)
