```bash
# добавить винду в grub
sudo pacman -S os-prober

sudo nano /etc/default/grub
	GRUB_DISABLE_OS_PROBER=false
sudo os-prober
sudo grub-mkconfig -o /boot/grub/grub.cfg
sudo pacman -Rsn os-prober

# добавить arch в efiboot секцию
sudo efibootmgr
sudo grub-install --target=x86_64-efi --efi-directory=/boot --recheck
sudo efibootmgr

# отключить вывод лога загрузки, только логотип ОС
sudo nano /etc/default/grub
	GRUB_CMDLINE_LINUX="... quiet splash rd.systemd.show_status=auto rd.udev.log-priority=3"
sudo grub-mkconfig -o /boot/grub/grub.cfg

sudo reboot
```

### `os-prober`

`os-prober` — утилита для автоматического обнаружения других операционных систем на компьютере и добавления их в меню загрузчика (чаще всего — GRUB).

**Основные функции**
- **Сканирование дисков.** Просматривает все доступные разделы на дисках системы.
- **Обнаружение ОС.** Определяет наличие других ОС (Windows, macOS, другие дистрибутивы Linux и т. д.) по:
    - сигнатурам файловых систем;
    - файлам загрузчиков;
    - другим характерным признакам.
- **Генерация записей для загрузчика.** Создаёт записи в конфигурации загрузчика, чтобы ОС отображались в меню при загрузке компьютера.
- **Интеграция с GRUB.** Автоматически добавляет найденные ОС в меню GRUB.

Разберу подробно команды `grub-install` и `efibootmgr` — их назначение, параметры и сценарии использования.

## `grub-install`

Утилита `grub-install` устанавливает загрузчик GRUB на устройство (диск) и настраивает его для загрузки операционной системы.

### Разбор команды
```bash
sudo grub-install --target=x86_64-efi --efi-directory=/boot --recheck
```

**Параметры:**
* `--target=x86_64-efi` — указывает целевую архитектуру и режим загрузки:
    * `x86_64` (вероятно, опечатка; должно быть `x86_64` → `x86_64` → корректно `x86_64` → правильно `x86_64` → верное значение: `x86_64` → **корректно: `x86_64`** → **итого: `x86_64-efi`** — 64‑битная архитектура x86 с поддержкой UEFI;
    * `efi` — режим загрузки UEFI (в отличие от Legacy/BIOS).
* `--efi-directory=/boot` — задаёт каталог, где расположены EFI‑файлы (обычно `/boot` или `/boot/efi`). Утилита поместит файлы GRUB в подпапку `EFI/` внутри указанного каталога.
* `--recheck` — заставляет утилиту повторно проверить устройство перед установкой. Это помогает избежать ошибок, если устройство было изменено с момента последнего запуска `grub-install`.


### Что делает команда
1. Создаёт EFI‑приложение GRUB (`grubx64.efi`) в `/boot/EFI/...`.
2. Копирует необходимые модули GRUB в `/boot/grub/x86_64-efi/`.
3. Настраивает конфигурацию для UEFI‑загрузки.
4. Регистрирует GRUB в NVRAM (если не используется `--no-nvram`).

### Когда использовать
* При установке GRUB на новый диск с UEFI.
* После смены диска или переустановки системы.
* Если GRUB повреждён или удалён.
* При настройке двойной загрузки с Windows (UEFI‑системами).

## `efibootmgr`

Утилита `efibootmgr` управляет записями загрузки в NVRAM UEFI. Она позволяет:
* просматривать текущие записи;
* добавлять новые;
* удалять старые;
* менять порядок загрузки.

### Разбор команды
```bash
sudo efibootmgr
```
Без параметров команда выводит список текущих записей загрузки UEFI.

**Типичный вывод:**
```
BootCurrent: 0001
Timeout: 1 сек
BootOrder: 0000,0001,0002
Boot0000* Windows Boot Manager
Boot0001* Arch Linux
Boot0002* UEFI: USB Drive
```

**Расшифровка:**
* `BootCurrent` — номер записи, с которой загрузилась система сейчас.
* `Timeout` — время ожидания выбора в меню загрузки.
* `BootOrder` — порядок, в котором UEFI пытается загрузить ОС.
* `BootXXXX` — отдельные записи загрузки. Звёздочка (`*`) означает активную запись.

### Основные опции `efibootmgr`
* `-v` — подробный вывод (показывает полный путь к файлу загрузчика).
* `-c` — создать новую запись.
* `-d` — указать устройство (диск).
* `-p` — указать раздел (EFI‑раздел).
* `-l` — путь к EFI‑файлу (например, `\EFI\arch\grubx64.efi`).
* `-L` — задать имя записи (например, «Arch Linux»).
* `-b` — номер записи для изменения/удаления.
* `-B` — удалить запись.
* `-o` — установить новый порядок загрузки (через запятую: `0001,0000`).

### Примеры использования

**1. Показать все записи (подробно):**
```bash
sudo efibootmgr -v
```
**2. Добавить запись для Arch Linux:**
```bash
sudo efibootmgr -c -d /dev/sda -p 1 -l \\EFI\\arch\\grubx64.efi -L "Arch Linux"
```
* `-d /dev/sda` — диск, на котором находится EFI‑раздел.
* `-p 1` — номер раздела (обычно 1, если EFI‑раздел первый).
* `-l \\EFI\\arch\\grubx64.efi` — путь к файлу загрузчика внутри EFI‑раздела.
* `-L "Arch Linux"` — имя записи в меню UEFI.
**3. Удалить запись (например, номер 0002):**
```bash
sudo efibootmgr -B -b 0002
```
**4. Изменить порядок загрузки (поставить Arch первым):**
```bash
sudo efibootmgr -o 0001,0000,0002
```

## Взаимосвязь команд

Эти утилиты часто используются вместе при настройке загрузки:

1. **`grub-install`** устанавливает GRUB как EFI‑приложение на диск.
2. **`efibootmgr`** регистрирует это приложение в NVRAM UEFI, чтобы система знала, откуда загружаться.

**Типичный сценарий (установка GRUB + настройка UEFI):**
```bash
# Установить GRUB для UEFI
sudo grub-install --target=x86_64-efi --efi-directory=/boot --recheck

# Обновить конфигурацию GRUB (создаёт grub.cfg)
sudo grub-mkconfig -o /boot/grub/grub.cfg

# Проверить записи UEFI
sudo efibootmgr

# При необходимости добавить запись вручную
sudo efibootmgr -c -d /dev/sda -p 1 -l \\EFI\\arch\\grubx64.efi -L "Arch Linux"
```

---

## Важные замечания

* **Права.** Обе команды требуют `sudo`, так как работают с системными разделами и NVRAM.
* **Архитектура.** Убедитесь, что `--target` соответствует вашей системе (`x86_64-efi` для 64‑битного UEFI).
* **EFI‑раздел.** Перед использованием `grub-install` убедитесь, что EFI‑раздел смонтирован в `/boot` (или `/boot/efi`).
* **Резервное копирование.** Перед изменением записей UEFI сделайте бэкап:
```bash
sudo efibootmgr > bootmgr_backup.txt
```
* **Проверка.** После настройки всегда проверяйте порядок загрузки: `sudo efibootmgr`.
* **Ошибки.** Если система не загружается после изменений, используйте Live‑USB для восстановления GRUB и записей UEFI.

## Краткий итог


* **`grub-install --target=x86_64-efi ...`** — устанавливает GRUB как UEFI‑загрузчик на диск, копирует файлы в `/boot`, настраивает модули.
* **`efibootmgr`** — управляет записями UEFI в NVRAM: показывает, добавляет, удаляет, меняет порядок загрузки.
