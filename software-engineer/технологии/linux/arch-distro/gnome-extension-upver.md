Чтобы сделать расширение **Forge** совместимым с GNOME 50 в Arch Linux, нужно отредактировать файл метаданных расширения и вручную добавить версию 50 в список поддерживаемых. Вот пошаговая инструкция:

### 📂 Шаг 1: Найдите папку расширения

Расширения GNOME могут находиться в двух местах. Выполните поиск:

```bash
find ~/.local/share/gnome-shell/extensions/ /usr/share/gnome-shell/extensions/ -name "*forge*" -type d 2>/dev/null
```

Обычно Forge устанавливается в:
```
~/.local/share/gnome-shell/extensions/forge@jmmaranan.com
/home/a/.local/share/gnome-shell/extensions/
```

### ✏️ Шаг 2: Отредактируйте metadata.json

Откройте файл `metadata.json` в найденной папке:

```bash
nano ~/.local/share/gnome-shell/extensions/forge@jmmaranan.com/metadata.json
```

Найдите строку с `"shell-version"` (или похожую на `"shell-version"` в секции, описывающей совместимость). Она выглядит примерно так:

```json
"shell-version": ["45", "46", "47"]
```

**Добавьте "50" в этот массив**:
```json
"shell-version": ["45", "46", "47", "50"]
```

Если секция называется иначе (например, просто перечислены версии), убедитесь, что формат JSON корректен — каждая версия в кавычках и через запятую.

### ⚠️ Шаг 3: Проверьте версию GNOME Shell

Убедитесь, что у вас действительно GNOME Shell 50:

```bash
gnome-shell --version
```

Если версия 50, то после правок всё должно заработать.

### 🔄 Шаг 4: Перезапустите GNOME Shell

Нажмите `Alt+F2`, введите `r` и нажмите Enter (в X11) или перезайдите в сеанс (в Wayland).

### 🛠 Шаг 5: Включите расширение

Откройте **Extension Manager** или **GNOME Extensions**, найдите Forge и включите его. Ошибка о несовместимости должна исчезнуть.

### 📌 Важное замечание

Это принудительное включение, но сам код расширения может использовать API, которые изменились в GNOME 50. Если после включения расширение работает с ошибками или глюками — увы, придётся ждать официального обновления от разработчика. В этом случае проверьте [страницу расширения на GNOME Extensions](https://extensions.gnome.org/extension/4481/forge/) на наличие бета-версии или Issue по этой проблеме.
