Для доступа к облаку Mail.ru через WebDAV в Arch Linux с GNOME есть несколько удобных вариантов, которые по функциональности аналогичны Disk-O. Вот лучшие из них.

## 🖥️ Графические клиенты (аналог Disk-O)

### 1. **Встроенная интеграция GNOME (Онлайн-учетные записи + Nautilus)**

Самый нативный способ, без установки лишнего ПО.

**Настройка:**
1. Откройте **Параметры → Онлайн-учетные записи**.
2. Если там нет Mail.ru, добавьте учётную запись **WebDAV** (может потребоваться пакет `gnome-online-accounts`).
3. Укажите:
   - **Сервер:** `https://webdav.cloud.mail.ru`
   - **Логин:** ваш email Mail.ru (например, `user@mail.ru`)
   - **Пароль:** пароль от приложения (не от основного ящика!)

4. После добавления облако появится в боковой панели Nautilus как сетевой диск.

> **Как получить пароль приложения:** В настройках Mail.ru → Безопасность → Пароли для приложений. Обычный пароль от почты не подойдёт.

---

### 2. **CarotDAV** (полнофункциональный GUI-клиент)

Ближайший аналог Disk-O — поддерживает WebDAV, монтирование, синхронизацию и встроенный проводник.

**Установка из AUR:**
```bash
yay -S carotdav
```

**Особенности:**
- Двухпанельный интерфейс в стиле Total Commander.
- Поддержка монтирования WebDAV как локального диска.
- Кеширование для быстрой навигации.
- Открытие/редактирование файлов на лету без скачивания.

## 📂 Монтирование как локальный диск (лучшая интеграция с системой)

Этот метод не даёт отдельного интерфейса, но облако будет доступно как обычная папка во всех приложениях.

### **davfs2** (монтирование WebDAV в файловую систему)

```bash
sudo pacman -S davfs2
sudo mount -t davfs https://webdav.cloud.mail.ru /mnt/mailru -o username=your@mail.ru
```

Для автоматического монтирования добавьте в `/etc/fstab`:
```
https://webdav.cloud.mail.ru /mnt/mailru davfs user,noauto,uid=ваш_пользователь 0 0
```

Чтобы не вводить пароль каждый раз, сохраните учётные данные в `~/.davfs2/secrets`:
```
/mnt/mailru your@mail.ru пароль_приложения
```

## 🔄 Синхронизация (аналог Dropbox/OneDrive)

### **rclone** (консольный, но с GUI-надстройками)

```bash
sudo pacman -S rclone
rclone config  # выберите WebDAV, введите https://webdav.cloud.mail.ru
```

Для графического интерфейса:
```bash
yay -S rclone-browser  # GUI для rclone
```

Позволяет синхронизировать папки, как в Dropbox:
```bash
rclone sync ~/Documents/Mailru mailru:Documents --progress
```

| Клиент | GUI | Монтирование | Синхронизация | Сложность |
|:---|:---:|:---:|:---:|:---:|
| GNOME Online Accounts | ✅ | ❌ (сетевой диск) | ❌ | 🟢 Низкая |
| CarotDAV | ✅ | ✅ | ✅ | 🟡 Средняя |
| davfs2 (монтирование) | ❌ | ✅ | ❌ | 🟡 Средняя |
| rclone + GUI | ✅ | ✅ | ✅ | 🟡 Средняя |

**Рекомендация:** Начните со встроенных Онлайн-учетных записей GNOME — это самый простой путь. Если нужна полноценная синхронизация и локальное монтирование, установите CarotDAV или rclone.
