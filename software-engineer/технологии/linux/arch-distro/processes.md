Для управления запущенными приложениями в GNOME из консоли можно использовать комбинацию стандартных команд Linux и специализированных утилит.

## 📋 Просмотр запущенных приложений

### 1. Традиционный способ (список процессов)

```bash
ps aux
```
Это покажет **все** процессы, включая системные и фоновые. Если нужно отфильтровать только приложения пользователя:

```bash
ps ux
```

**Для GNOME-специфичных приложений** можно отфильтровать по имени:

```bash
ps aux | grep -E "gnome-|gio|gapplication"
```

### 2. Просмотр только оконных приложений (рекомендуемый способ)

```bash
wmctrl -l
```
- Показывает только те приложения, у которых есть окна (GUI-программы)
- Выводит: `ID окна`, `десктоп`, `PID процесса`, `название окна`

Для получения более детальной информации:

```bash
wmctrl -lp
```
Добавляет в вывод PID процесса, что позволяет связать окно с конкретным процессом.

### 3. Интерактивный монитор (лучше всего для ручного управления)

```bash
htop
```
- Показывает все процессы в реальном времени
- Можно управлять процессами (завершать, приоритезировать) с помощью клавиш `F9` (убить), `F7`/`F8` (изменить приоритет)

## 🎮 Управление приложениями из консоли

### Завершение приложений

**По имени процесса:**
```bash
pkill firefox
killall firefox
```

**По PID (после нахождения через `wmctrl -lp` или `ps aux`):**
```bash
kill 12345
kill -9 12345  # если обычный kill не помогает
```

**По ID окна (из wmctrl):**
```bash
wmctrl -ic 0x03a00003
```

### Запуск приложений в фоне

```bash
gedit &
disown  # отсоединяет от терминала
```

### Контроль над запущенными сервисами GNOME

```bash
# Просмотр пользовательских сервисов
systemctl --user list-units

# Перезапуск конкретного GNOME-компонента
killall gnome-shell  # перезапустит оболочку (осторожно!)
```

## 🛠️ Полный инструментарий GNOME из консоли

| Команда | Функция |
|---------|---------|
| `gnome-system-monitor` | Графический аналог (можно вызвать, но из консольной сессии не очень удобно) |
| `gsettings` | Управление настройками GNOME |
| `gapplication` | Управление D-Bus-активируемыми приложениями |
| `dbus-send` | Низкоуровневое управление через D-Bus |

## 🔍 Примеры сценариев

### Найти и завершить зависшее приложение
```bash
# Найти окно
wmctrl -lp | grep -i firefox
# Завершить по PID
kill -9 12345
# Или по ID окна
wmctrl -ic 0x03a00003
```

### Мониторинг потребления ресурсов приложениями
```bash
while true; do clear; ps ux --sort=-%cpu | head -10; sleep 2; done
```

### Узнать, какое приложение занимает порт
```bash
sudo netstat -tulpn | grep :8080
```

## 💡 Рекомендация

- **Для быстрого просмотра GUI-приложений:** используйте `wmctrl -l`
- **Для управления процессами (завершение, приоритеты):** используйте `htop` (нужно установить: `sudo pacman -S htop`)
- **Для автоматизации в скриптах:** используйте `wmctrl` + `ps` + `kill`

Если нужно управлять именно GNOME Shell расширениями и сервисами, лучше использовать `gnome-extensions-app` (из графического интерфейса) или `gnome-shell-extension-tool` (устаревшая, но работает).
