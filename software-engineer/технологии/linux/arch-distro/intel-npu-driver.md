После чистой установки Arch Linux, чтобы задействовать NPU вашего процессора Meteor Lake, необходимо установить несколько дополнительных компонентов. Сам по себе драйвер ядра и прошивка для NPU уже включены в стандартные пакеты ядра и `linux-firmware`, поэтому базовая поддержка может уже быть. Однако для того, чтобы приложения могли его обнаружить и использовать, потребуется **пользовательский драйвер и библиотеки** из пакета `intel-npu-driver`, а также настройка прав доступа.

### 🧩 Что нужно установить и настроить

Для работы NPU потребуется выполнить три основных шага: установка драйвера, настройка прав доступа и проверка.

1.  **Установите пакет `intel-npu-driver` из AUR**
    Этот пакет содержит необходимый пользовательский драйвер и компоненты для взаимодействия с NPU. Проще всего установить его с помощью AUR-хелпера (например, `yay` или `paru`), выполнив в терминале команду:
    ```bash
    yay -S intel-npu-driver
    ```

2.  **Настройте права доступа к устройству NPU**
    Устройство NPU доступно как `/dev/accel/accel0`. По умолчанию доступ к нему может быть только у `root`. Чтобы ваши приложения могли с ним работать, необходимо добавить себя в группу `render`.
    *   Выполните команду для добавления вашего пользователя в группу `render`:
        ```bash
        sudo usermod -aG render $USER
        ```
    *   После этого **выйдите из системы и зайдите снова** (или перезагрузитесь), чтобы изменения вступили в силу.

3.  **Проверьте, что всё работает**
    После перезагрузки выполните в терминале следующие команды. Их вывод подтвердит, что NPU обнаружен и готов к работе.

    *   **Проверка устройства**: Убедитесь, что устройство появилось в системе.
        ```bash
        ls -lah /dev/accel/accel0
        ```
        Вы должны увидеть примерно такой вывод: `crw-rw---- 1 root render 261, 0 ...`. Это подтвердит, что устройство существует и принадлежит группе `render`.
    *   **Проверка драйвера ядра**: Проверьте, загружен ли модуль ядра `intel_vpu`.
        ```bash
        lsmod | grep intel_vpu
        ```

### 🤔 Что дальше? Запуск LLM на NPU

После установки драйвера сам по себе NPU не ускорит любую LLM. Нужно использовать специальное программное обеспечение, которое умеет с ним работать.

*   **Библиотека IPEX-LLM**: Это официальный инструмент от Intel для ускорения LLM на их процессорах, включая NPU. Он интегрируется с популярными фреймворками, такими как `llama.cpp`, `Ollama` и `Hugging Face`.
*   **Бэкенд OpenVINO для Ollama**: Вы также можете настроить `Ollama` для работы через бэкенд `openvino`, который имеет поддержку NPU. Это может быть более простым способом запустить некоторые модели.

Для экспериментов вы можете начать с установки `ollama` и `openvino`, но имейте в виду, что поддержка NPU в экосистеме все еще активно развивается.

Надеюсь, эта инструкция поможет вам подготовить систему. Если в процессе возникнут вопросы, спрашивайте.
