В сообществе Arch Linux нет одного «официального» скрипта, который бы делал всё сразу, но есть множество проверенных пользовательских решений. Чаще всего люди используют системный таймер `systemd` для вызова обновлений и утилиту `paccache` для автоматической очистки кэша.

Вот два самых популярных подхода, которые я нашёл, и которые легко адаптировать под свои нужды.

---

### 🥇 Подход 1: Использование готового таймера `paccache`

Это самый простой способ автоматически чистить кэш пакетов, и он уже есть в вашей системе (в составе `pacman-contrib`).

*   **Что делает:** Автоматически удаляет старые версии пакетов из `/var/cache/pacman/pkg/`, оставляя только несколько последних (по умолчанию — 3). Это предотвращает бесконтрольный рост папки с кэшем.
*   **Как включить:**
    1.  Убедитесь, что установлен пакет `pacman-contrib`: `sudo pacman -S pacman-contrib`.
    2.  Включите таймер: `sudo systemctl enable --now paccache.timer`.
    3.  Проверьте статус: `sudo systemctl status paccache.timer`.
*   **Почему это хорошо:** Это стандартный инструмент, поддерживаемый разработчиками Arch. Он делает только очистку кэша, но не обновляет систему.

### 🛠️ Подход 2: Собственный скрипт с `systemd` таймером (рекомендованный сообществом)

Это более гибкий способ, который позволяет автоматизировать не только очистку, но и само обновление. В сообществе широко используют комбинацию `pacman -Syu` и `paccache` внутри одного таймера.

Вот пример скрипта и конфигурации, который можно найти на форумах Arch Linux.

**Скрипт (например, `/usr/local/bin/auto-update.sh`):**

```bash
#!/usr/bin/env bash

# Уведомление о начале (опционально)
notify-send "Arch Linux" "Начинается автоматическое обновление..."

# Обновление базы и пакетов
pacman -Syu --noconfirm

# Очистка кэша (оставить 2 последние версии)
paccache -rvk2

# Удаление orphan-пакетов (опционально)
pacman -Rns $(pacman -Qtdq) 2>/dev/null

notify-send "Arch Linux" "Обновление завершено!"
```

**Таймер systemd (например, `/etc/systemd/system/auto-update.timer`):**

```ini
[Unit]
Description=Еженедельное обновление Arch Linux

[Timer]
OnCalendar=weekly
Persistent=true

[Install]
WantedBy=multi-user.target
```

**Сервис systemd (например, `/etc/systemd/system/auto-update.service`):**

```ini
[Unit]
Description=Скрипт автоматического обновления Arch Linux

[Service]
Type=oneshot
ExecStart=/usr/local/bin/auto-update.sh
```

**Как установить:**

1.  Создайте файлы скрипта, таймера и сервиса с указанным содержимым.
2.  Сделайте скрипт исполняемым: `chmod +x /usr/local/bin/auto-update.sh`.
3.  Включите таймер: `sudo systemctl enable --now auto-update.timer`.

**Почему это популярно:** Этот подход полностью прозрачен, его легко кастомизировать (добавить отправку email, логирование в файл или уведомления) и он использует стандартные механизмы systemd, а не сторонние cron-скрипты.

### ⚙️ Другие часто используемые инструменты

Хотя вы просили скрипт, стоит упомянуть и специализированные утилиты, которые также активно обсуждаются в сообществе.

*   **`topgrade`:** Очень популярная программа, которая обновляет не только пакеты Arch, но и сторонние менеджеры (Flatpak, Snap, Pip, Rust, и т.д.). Она умеет запускаться по таймеру и выводить уведомления об успешном завершении. Устанавливается через AUR (`yay -S topgrade`).
*   **`yay` / `paru`:** Эти AUR-помощники имеют встроенные флаги для автоматического обновления, например `yay -Syu --noconfirm`. Их также можно использовать в пользовательских скриптах.

---

### 📌 Итог

Основной рецепт от сообщества Arch Linux — это **комбинация `paccache.timer` для очистки кэша и собственного скрипта с `systemd` таймером для выполнения полного цикла обслуживания**. Такой подход даёт полный контроль и использует только стандартные инструменты системы.

Если вы хотите добавить уведомления на рабочий стол или логирование, это легко сделать внутри скрипта, что делает его очень гибким.
