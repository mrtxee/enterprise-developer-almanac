Чтобы запустить установку игры через `Setup.exe` в Arch Linux, используйте **Wine** — слой совместимости для запуска Windows‑приложений. Разберу процесс пошагово.


## Шаг 1. Установка Wine и сопутствующих пакетов


Откройте терминал и выполните:
```bash
sudo pacman -S wine wine-mono wine_gecko winetricks
```

**Что устанавливают пакеты:**
* `wine` — основной пакет для запуска Windows‑программ;
* `wine-mono` — реализация .NET Framework;
* `wine_gecko` — движок для отображения веб‑страниц внутри приложений;
* `winetricks` — утилита для установки дополнительных библиотек (DirectX, Visual C++ и т. д.).


## Шаг 2. Базовая настройка Wine


Запустите конфигуратор Wine:
```bash
winecfg
```
При первом запуске Wine создаст префикс (`~/.wine`) и настроит базовую среду. В окне `winecfg` можно:
* выбрать версию Windows (рекомендуется **Windows 7** или **Windows 10**);
* настроить графику, звук и другие параметры.

## Шаг 3. Запуск установщика


1. Перейдите в каталог с файлом `Setup.exe`:
```bash
cd /путь/к/папке/с/установщиком
```
2. Запустите установщик:
```bash
wine Setup.exe
```

## Шаг 4. Установка дополнительных зависимостей (при необходимости)

Многие игры требуют библиотек DirectX, Visual C++, .NET. Используйте `winetricks`:
```bash
winetricks d3dx9 d3dcompiler_47 dxvk vcrun2019 dotnet48
```
**Расшифровка флагов:**
* `d3dx9`, `d3dcompiler_47` — библиотеки DirectX 9;
* `dxvk` — Vulkan‑бэкенд для DirectX 9–11 (повышает производительность);
* `vcrun2019` — Visual C++ 2019;
* `dotnet48` — .NET Framework 4.8.

## Шаг 5. Альтернативные способы запуска

**Вариант 1. Через файловый менеджер**
* щёлкните правой кнопкой мыши по `Setup.exe`;
* выберите **«Открыть с помощью…»** → **«Wine Windows Program Loader»**.

**Вариант 2. С указанием префикса** (если используете несколько окружений Wine):
```bash
WINEPREFIX=~/.custom-prefix wine Setup.exe
```
Это запустит установщик в указанном префиксе (папке), а не в стандартном `~/.wine`.

## Шаг 6. Запуск установленной игры

После установки игра может:
* автоматически создать ярлык в меню приложений;
* добавить запись в `~/.local/share/applications/` (запуск через меню);
* потребовать ручного запуска через Wine:
```bash
wine ~/.wine/drive_c/Program\ Files/Path/To/Game/game.exe
```

## Полезные советы и решения проблем

**1. Проверка архитектуры**
Если игра 32‑битная, создайте 32‑битный префикс:
```bash
WINEARCH=win32 WINEPREFIX=~/.wine32 winecfg
```
Затем запускайте установщик в этом префиксе.

**2. Настройка производительности**
* включите **CSMT** (Concurrent Synchronization in Multithreaded) в `winecfg` (вкладка *Staging*) для повышения FPS;
* используйте **DXVK** (см. шаг 4) для перевода DirectX в Vulkan.

**3. Отладка**
* запустите Wine с выводом логов:
```bash
WINEDEBUG=+all wine Setup.exe 2>&1 | tee wine.log
```
* проверьте **Wine AppDB** (https://appdb.winehq.org/) — там есть инструкции для конкретных игр.

**4. Проблемы с графикой**
* если игра мерцает или не запускается в полноэкранном режиме, включите **«Эмуляцию виртуального рабочего стола»** в `winecfg` → *Graphics*;
* попробуйте переключиться на **XWayland** (если используете Wayland).

**5. Отсутствие звука**
Убедитесь, что в `winecfg` на вкладке *Audio* выбран правильный звуковой драйвер (PulseAudio или ALSA).

## Краткий итог

| Действие | Команда/Способ |
|-------|--------------|
| Установка Wine | `sudo pacman -S wine wine-mono wine_gecko winetricks` |
| Настройка Wine | `winecfg` |
| Запуск установщика | `wine Setup.exe` |
| Установка зависимостей | `winetricks d3dx9 vcrun2019 dxvk` |
| Запуск игры | `wine ~/.wine/drive_c/.../game.exe` |

**Важно:**
* некоторые игры (особенно с античитом, например, *Valorant*, *Fortnite*) не работают в Wine;
* для современных AAA‑игр рассмотрите **Proton** (через Steam) — он оптимизирован для игр лучше, чем «чистый» Wine.
