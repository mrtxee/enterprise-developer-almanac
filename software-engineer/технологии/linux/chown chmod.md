Разберу кратко и чётко команды `chown` и `chmod` — их назначение, синтаксис и ключевые отличия.

## chown (change owner)

**Назначение:** изменяет **владельца** и/или **группу** файлов и каталогов.

**Базовый синтаксис:**
```bash
chown [опции] <владелец>[:<группа>] <файл/каталог>
```

**Примеры:**
* Изменить владельца: `sudo chown user file.txt`
* Изменить владельца и группу: `sudo chown user:group file.txt`
* Рекурсивно для каталога: `sudo chown -R user:group /path/to/dir`

**Ключевые опции:**
* `-R` (`--recursive`) — рекурсивное применение;
* `-v` (`--verbose`) — подробный вывод;
* `--reference=файл` — взять владельца/группу от указанного файла.

**Важные нюансы:**
* Обычно требуется `sudo` — обычный пользователь не может передавать владение другим.
* Можно использовать имена или числовые ID (UID/GID).
* Проверить результат можно командой `ls -l`.

## chmod (change mode)

**Назначение:** изменяет **права доступа** (permissions) к файлам и каталогам.

**Базовый синтаксис:**
```bash
chmod [опции] <права> <файл/каталог>
```

**Способы задания прав:**

1. **Символьный режим** (читаемый формат):
   * `u` — владелец (user);
   * `g` — группа (group);
   * `o` — остальные (others);
   * `a` — все (all);
   * `+` — добавить права;
   * `-` — убрать права;
   * `=` — установить точно.

   **Примеры:**
   * Добавить право выполнения владельцу: `chmod u+x script.sh`
   * Убрать право записи у группы и остальных: `chmod go-w document.txt`
   * Установить полные права для всех: `chmod a=rwx folder/`

2. **Числовой (октальный) режим** (быстрый формат):

   Каждая цифра — сумма прав для одной категории:
   * `4` = чтение (`r`);
   * `2` = запись (`w`);
   * `1` = выполнение (`x`).

   **Примеры:**
   * `644` — владелец: чтение+запись, группа и остальные: только чтение (`rw-r--r--`);
   * `755` — владелец: все права, группа и остальные: чтение+выполнение (`rwxr-xr-x`);
   * `700` — только владелец имеет все права (`rwx------`).

   **Использование:**
   ```bash
   chmod 644 file.txt
   chmod 755 script.sh
   ```

**Ключевые опции:**
* `-R` — рекурсивное применение к каталогу и его содержимому;
* `-v` — подробный вывод.

## Сравнение chown и chmod

| Параметр | chown | chmod |
|--------|-------|-------|
| **Что меняет** | Владельца и/или группу | Права доступа (чтение, запись, выполнение) |
| **Синтаксис** | `chown владелец:группа файл` | `chmod права файл` (символьный/числовой) |
| **Типичные задачи** | Передать файл другому пользователю, сменить группу каталога | Разрешить выполнение скрипта, запретить запись в файл |
| **Требует sudo** | Обычно да | Не всегда (можно менять свои файлы) |
| **Рекурсия** | Через `-R` | Через `-R` |

## Практический пример совместного использования

Допустим, нужно передать каталог `project` пользователю `dev` и дать ему полные права:

```bash
# Меняем владельца и группу
sudo chown -R dev:dev project/

# Устанавливаем права: владелец — всё, группа — чтение/выполнение, остальные — ничего
chmod 750 project/
```

**Краткий итог:**
* `chown` — кто **владеет** файлом (владелец и группа).
* `chmod` — что можно **делать** с файлом (права доступа: чтение, запись, выполнение).
