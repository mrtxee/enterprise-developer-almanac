Разберу подробно различия между **MBR** (Master Boot Record) и **GPT** (GUID Partition Table) — двумя основными схемами разбиения дисков.

## MBR (Master Boot Record)

**Что это:** старая схема разметки дисков, появившаяся в 1983 году вместе с IBM PC XT.

**Структура:** занимает первые 512 байт диска и состоит из:
* кода загрузчика (446 байт) — мини‑программы для запуска ОС;
* таблицы разделов (64 байт) — информации о разделах диска;
* магической сигнатуры (2 байта) — проверочного кода целостности.

**Ключевые характеристики:**
* **Максимальный размер диска:** 2 ТБ (из‑за 32‑битной адресации).
* **Количество разделов:** максимум 4 первичных раздела. Для большего числа нужно использовать расширенный раздел с логическими подразделами.
* **Загрузочная совместимость:** работает с BIOS и старыми ОС (Windows XP и ранее, старые версии Linux/macOS).
* **Резервное копирование:** нет встроенной копии таблицы разделов. Повреждение MBR может привести к потере доступа ко всему диску.
* **Восстановление данных:** благодаря простой структуре восстановление после сбоев обычно проще.


## GPT (GUID Partition Table)

**Что это:** современная схема разметки, разработанная в конце 1990‑х, официально представлена в 2000 году вместе с UEFI.

**Структура:**
* защитный MBR (первые 512 байт) — для совместимости со старыми системами;
* основная таблица разделов (в начале диска);
* резервная таблица разделов (в конце диска) — копия основной;
* записи о разделах с уникальными GUID (128‑битные идентификаторы).

**Ключевые характеристики:**
* **Максимальный размер диска:** до 9,4 зеттабайт (8 миллиардов ТБ) благодаря 64‑битной адресации.
* **Количество разделов:** до 128 основных разделов по умолчанию (можно увеличить).
* **Загрузочная совместимость:** требует UEFI (не работает с классическим BIOS). Поддерживается Windows 8+, современными Linux и macOS.
* **Резервное копирование:** наличие резервной копии таблицы разделов повышает отказоустойчивость.
* **Целостность данных:** использует контрольные суммы CRC32 для проверки целостности таблицы разделов.
* **Гибкость:** каждый раздел имеет уникальный GUID и атрибуты (например, флаг «загрузочный»).

## Сравнительная таблица


| Параметр | MBR | GPT |
|--------|------|------|
| Год появления | 1983 | 2000 |
| Максимальный размер диска | 2 ТБ | 9,4 ЗБ (практически неограниченно) |
| Макс. число разделов | 4 первичных или 3 первичных + 1 расширенный | До 128 основных (по умолчанию) |
| Совместимость с UEFI | Нет | Да |
| Совместимость с BIOS | Да | Нет (только через CSM) |
| Поддержка ОС | Windows 95/98/Me/XP/Vista/7, Linux, macOS (с ограничениями) | Windows 8/10/11, современные Linux, macOS |
| Резервная копия таблицы разделов | Нет | Есть (в конце диска) |
| Защита данных | Низкая (одна копия) | Высокая (резервная копия + CRC) |
| Уникальные идентификаторы разделов | Нет | Да (GUID) |
| Простота восстановления | Проще (структура проще) | Сложнее (но надёжнее за счёт бэкапа) |

## Когда что выбирать

**Выбирайте MBR, если:**
* используете старый компьютер с BIOS (до 2010 года);
* работаете с диском объёмом менее 2 ТБ;
* нужна совместимость с Windows XP или более ранними ОС;
* предпочитаете простоту и лёгкость восстановления данных;
* диск используется как хранилище (не загрузочный).


**Выбирайте GPT, если:**
* у вас современный компьютер с UEFI;
* используете диск объёмом более 2 ТБ;
* хотите создать более 4 разделов без расширенных разделов;
* важна отказоустойчивость (резервная таблица разделов);
* планируете установить Windows 11 (для загрузочного диска требуется GPT);
* используете SSD‑накопитель большой ёмкости;
* настраиваете dual boot с Linux или macOS.

## Как проверить текущую схему разметки

**В Windows:**
1. Нажмите `Win + R`, введите `diskmgmt.msc`.
2. В «Управлении дисками» кликните правой кнопкой по диску → «Свойства».
3. На вкладке «Тома» посмотрите «Стиль раздела»:
    * «Основная загрузочная запись (MBR)» — MBR;
    * «Таблица разделов GUID (GPT)» — GPT.

**В Linux:**
* Команда `lsblk -f` покажет тип раздела в колонке `FSTYPE`.
* Или используйте `parted`:
  ```bash
  sudo parted -l
  ```
  Ищите строки `Partition Table: msdos` (MBR) или `Partition Table: gpt` (GPT).

## Конвертация между MBR и GPT

**Важно:** перед конвертацией сделайте резервную копию данных.

**Способы:**
* **Windows:** `diskpart` (удаляет данные) или «Управление дисками» (удаляет все разделы).
* **Linux:** `gdisk` (может конвертировать без потери данных) или `GParted` (удаляет разделы).
* **Сторонние утилиты:** AOMEI Partition Assistant, 4DDiG Partition Manager (могут конвертировать без удаления данных).

## Краткий итог

* **MBR** — простой и совместимый вариант для старых систем и небольших дисков (< 2 ТБ).
* **GPT** — современный, надёжный и масштабируемый стандарт для UEFI‑систем и больших накопителей.
