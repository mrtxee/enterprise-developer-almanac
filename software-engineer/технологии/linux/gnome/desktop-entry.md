В каталоге `~/.local/share/applications/` могут находиться файлы разных типов — не только классические `.desktop` с секцией `[Desktop Entry]`. Разберу их подробно.


## Основные типы файлов

**1. `.desktop` — файлы ярлыков приложений**

Самый распространённый тип. Содержат секцию `[Desktop Entry]` и описывают:
* приложения (`Type=Application`);
* каталоги (`Type=Directory`);
* ссылки (`Type=Link`).

Пример: `firefox.desktop`, `my-game.desktop`.

**2. `.directory` — файлы описания каталогов**

Используются для структурирования меню приложений (например, создание папок «Игры», «Графика» и т. д.). Содержат секцию `[Desktop Entry]` с `Type=Directory`.

Пример файла `Games.directory`:
```ini
[Desktop Entry]
Name=Games
Type=Directory
Icon=games
```

**3. `.menu` — XML‑файлы для описания структуры меню**

Определяют иерархию и группировку пунктов в главном меню. Используют формат XML (не INI). Обычно находятся в `/etc/xdg/menus/`, но могут быть и в `~/.local/share/applications/`.

Пример фрагмента:
```xml
<!DOCTYPE Menu PUBLIC "-//freedesktop//DTD Menu 1.0//EN"
"http://www.freedesktop.org/standards/menu-spec/1.0/menu.dtd">
<Menu>
  <Name>Applications</Name>
  <Directory>my-custom-games.directory</Directory>
  <Include>
    <Category>Game</Category>
  </Include>
</Menu>
```

**4. `.desktop.mime` — файлы MIME‑типов**

Описывают ассоциации между MIME‑типами (типами файлов) и приложениями. Редко создаются вручную — обычно генерируются автоматически.

Пример: `text/plain.desktop.mime`.

**5. `.desktop.cache` — кэшированные файлы**

Автоматически генерируемые файлы кэша для ускорения работы меню. Создаются и обновляются командами:
* `update-desktop-database`;
* при запуске среды рабочего стола.

Пример: `mimeinfo.cache`.

## Прочие возможные файлы

**6. Обычные скрипты и бинарные файлы**

Иногда пользователи по ошибке или намеренно помещают в этот каталог:
* исполняемые скрипты (`.sh`);
* бинарные файлы (`.bin`, `.run`).

Это **не рекомендуется**: каталог предназначен для `.desktop`-файлов, а не для исполняемых файлов.

**7. Временные и служебные файлы**

Могут появляться в процессе работы системы или при ошибках:
* файлы с тильдой (`~`) на конце — резервные копии (например, `myapp.desktop~`);
* lock‑файлы или временные файлы от менеджеров пакетов или настроек.

**8. Файлы пользовательских категорий**

Пользователь может создать собственные категории в меню, используя:
* `.directory`-файлы (для отображения);
* `.menu`-файлы (для структуры).

## Краткий справочник по типам

| Тип файла | Назначение | Пример имени | Секция `[Desktop Entry]` |
|--------|----------|-----------|----------------------|
| `.desktop` | Ярлык приложения, ссылки или каталога | `firefox.desktop` | Да (обязательно) |
| `.directory` | Описание категории/папки в меню | `Games.directory` | Да (`Type=Directory`) |
| `.menu` | Структура главного меню (XML) | `my-custom.menu` | Нет (формат XML) |
| `.desktop.mime` | Ассоциации MIME‑типов | `text/plain.desktop.mime` | Может быть |
| `.desktop.cache` | Кэшированная информация для ускорения меню | `mimeinfo.cache` | Нет |
| Скрипты (`.sh`) | Исполняемые скрипты (не для этого каталога) | `start.sh` | Нет |
| Резервные копии (`~`) | Автосохранения редакторов | `myapp.desktop~` | Да, если оригинал был `.desktop` |

## Важные замечания

1. **Основное назначение каталога.** `~/.local/share/applications/` предназначен в первую очередь для `.desktop`-файлов — ярлыков приложений текущего пользователя.
2. **Приоритет.** Файлы в этом каталоге имеют приоритет над системными (`/usr/share/applications/`). Пользовательский `firefox.desktop` переопределит системный.
3. **Обновление кэша.** После добавления/изменения `.desktop`-файлов рекомендуется обновить кэш:
   ```bash
   update-desktop-database ~/.local/share/applications
   ```
4. **Перезапуск.** Иногда для отображения изменений требуется перезапуск среды рабочего стола (выйти и зайти в сессию заново или перезапустить GNOME Shell: `Alt+F2` → `r` → Enter).
5. **Чистота каталога.** Не стоит хранить в нём исполняемые файлы или временные данные — это может привести к путанице и ошибкам в отображении меню.
