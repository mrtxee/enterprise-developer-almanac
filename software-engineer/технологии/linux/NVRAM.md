**NVRAM (Non‑Volatile Random‑Access Memory)** — энергонезависимая память с произвольным доступом.


## Кратко: главное

* **Сохраняет данные** при отключении питания — в отличие от обычной RAM (оперативной памяти).
* **Быстро работает** — по скорости чтения/записи близка к RAM, а не к накопителям (HDD/SSD).
* **Используется для хранения** критически важных настроек и данных, которые должны пережить отключение питания.

## Как работает
Есть несколько вариантов реализации:
* **SRAM + батарейка** — статическая память с резервным питанием (например, для хранения настроек BIOS).
* **Гибрид RAM + энергонезависимой памяти** — например, связка RAM с EEPROM или флеш‑памятью.
* **Современные типы** (FRAM, MRAM, PCM и др.) — не требуют батареек, используют особые физические свойства материалов.


## Где применяется
* **BIOS/UEFI** — хранение настроек загрузки, даты/времени, конфигурации оборудования.
* **Серверы и СХД** — кэширование данных с защитой от сбоев питания (например, в RAID‑контроллерах).
* **Сетевое оборудование** — сохранение конфигураций маршрутизаторов, коммутаторов.
* **Микроконтроллеры и IoT‑устройства** — хранение калибровочных данных, журналов, состояний.
* **Принтеры и МФУ** — настройки сети, учёт печати, профили.
* **Игровые консоли** — сохранение прогресса и настроек.

## Примеры в реальной жизни
* Литиевая батарейка на материнской плате ПК подпитывает NVRAM с настройками BIOS.
* Сервер с батарейным кэшем сохраняет данные в NVRAM при аварийном отключении питания, чтобы потом дописать их на диски.
* Умный термостат сохраняет расписание и настройки даже при пропадании питания.

---

## Краткий итог: отличия от других типов памяти

| Тип памяти | Сохраняет данные без питания? | Скорость | Типичное применение |
|----------|-------------------------------|---------|-------------------|
| **NVRAM** | Да | Высокая (как у RAM) | Настройки, кэши, журналы |
| **RAM (DRAM/SRAM)** | Нет | Очень высокая | Основная оперативная память |
| **Флеш (NAND)** | Да | Средняя | SSD, USB‑флешки, BIOS‑чипы |
| **EEPROM** | Да | Низкая | Микроконтроллеры, небольшие настройки |

**Проще говоря:** NVRAM — это «быстрая память, которая помнит даже после выключения».
