Разберу подробно различия между BIOS и UEFI — двумя основными типами прошивок для запуска компьютера.


## BIOS (Basic Input/Output System)


**Что это:** базовая система ввода‑вывода, встроенная в материнскую плату (разработана в 1980‑х годах).


**Ключевые особенности:**
* **Интерфейс:** текстовый экран, управление только с клавиатуры.
* **Режим работы:** 16‑битный реальный режим процессора.
* **Таблица разделов:** MBR (Master Boot Record) — загрузочная запись размером 512 байт в начале диска.
* **Ограничения MBR:**
    * максимальный размер диска — 2,2 ТБ;
    * максимум 4 первичных раздела (или 3 первичных + 1 расширенный).
* **Процесс загрузки:** последовательная инициализация оборудования (медленнее).
* **Безопасность:** нет встроенных механизмов защиты.
* **Хранение настроек:** CMOS‑память (энергозависимая, с батарейкой).
* **Объём настроек:** ограниченный.

**Процесс загрузки через BIOS:**
1. Запуск POST (Power‑On Self Test) — проверка оборудования.
2. Поиск загрузочного устройства по порядку, заданному в настройках.
3. Чтение MBR, выполнение кода загрузчика.
4. Передача управления загрузчику ОС (например, GRUB или `bootmgr`).

## UEFI (Unified Extensible Firmware Interface)

**Что это:** современная замена BIOS (первые спецификации — 2005 год).

**Ключевые особенности:**
* **Интерфейс:** графический, с поддержкой мыши, сенсорного ввода, анимации.
* **Режим работы:** 32‑ или 64‑битный защищённый режим.
* **Таблица разделов:** GPT (GUID Partition Table).
* **Преимущества GPT:**
    * поддержка дисков объёмом до 9,4 зеттабайт (практически неограниченно);
    * до 128 разделов по умолчанию (можно увеличить);
    * дублирование таблицы разделов (в начале и в конце диска) для надёжности.
* **Процесс загрузки:** параллельная инициализация оборудования (быстрее).
* **Безопасность:** поддержка Secure Boot — проверка цифровых подписей загрузчиков.
* **Хранение настроек:** NVRAM (энергонезависимая память).
* **Расширяемость:** поддержка плагинов, утилит и приложений (например, файловых менеджеров или браузеров).
* **Сетевые возможности:** встроенный сетевой стек (IPv4/IPv6), поддержка сетевой загрузки через HTTP.

**Процесс загрузки через UEFI:**
1. Инициализация оборудования в параллельном режиме.
2. Проверка Secure Boot (если включён).
3. Поиск ESP (EFI System Partition) — раздела FAT32 с загрузчиками.
4. Запуск загрузчика из ESP (например, `shimx64.efi` для Linux или `winload.efi` для Windows).
5. Передача управления ОС.

## Сравнительная таблица

| Критерий | BIOS | UEFI |
|----------|-------|------|
| Год появления | 1981 | 2005 |
| Интерфейс | Текстовый, управление клавиатурой | Графический, поддержка мыши/тача |
| Метод загрузки | MBR | GPT |
| Макс. размер диска | 2,2 ТБ | До 9,4 ЗБ |
| Макс. число разделов | 4 (первичных) | 128+ |
| Скорость загрузки | Медленнее (последовательная инициализация) | Быстрее (параллельная инициализация, Fast Boot) |
| Безопасность | Нет защиты | Secure Boot (проверка подписей) |
| Архитектура | 16‑битный режим | 32/64‑битный режим |
| Хранение настроек | CMOS (ограниченный объём) | NVRAM (большой объём) |
| Расширяемость | Ограниченная | Поддержка плагинов и утилит |
| Сетевые функции | Нет | Встроенный стек (IPv4/IPv6) |
| Поддержка ОС | Старые версии Windows, Linux | Все современные ОС (включая Windows 11) |

## Когда что использовать?

**Выбирайте UEFI, если:**
* используете диск >2 ТБ;
* хотите быструю загрузку;
* нужна защита Secure Boot (особенно для Windows 10/11);
* планируете мультизагрузку (Linux + Windows);
* хотите графический интерфейс настройки с мышью;
* требуется поддержка современных функций (сетевая загрузка, диагностика).

**BIOS может быть актуален, если:**
* работаете со старым оборудованием (до 2010 года);
* используете старые ОС, не поддерживающие UEFI;
* нужны максимальная простота и надёжность без лишних функций;
* в промышленных или встраиваемых системах, где стабильность важнее функционала.

## Совместимость: Legacy Mode и CSM

Многие современные материнские платы поддерживают **режим совместимости** (Compatibility Support Module, CSM), который:
* позволяет UEFI‑системе эмулировать работу BIOS;
* даёт возможность загружать старые ОС через MBR;
* полезен при апгрейде старого оборудования.

**Важно:** Windows 11 требует UEFI и Secure Boot — установка на BIOS/MBR невозможна.

## Как определить, что используется?

**В Windows:**
1. Нажмите `Win + R`, введите `msinfo32`.
2. В строке «Режим BIOS» будет указано «UEFI» или «Наследованный» (Legacy/BIOS).

**В Linux:**
* Проверьте наличие каталога `/sys/firmware/efi`. Если он есть — система загружена в режиме UEFI.
* Или выполните команду: `ls /sys/firmware/efi`


**Визуально:**
* графический интерфейс с мышью при входе в настройки — скорее всего, UEFI;
* синий экран с белыми буквами и управлением только клавиатурой — BIOS.
