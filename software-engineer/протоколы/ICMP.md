### ICMP (Internet Control Message Protocol)


**Уровень:** сетевой (модель OSI, уровень 3).  
**Назначение:** передача управляющих сообщений и диагностика сети (не для передачи пользовательских данных).

#### Основные функции
- **Уведомления об ошибках** (например, «узел недоступен», «сеть недоступна»).  
- **Диагностика** (команды `ping`, `traceroute`).  
- **Проверка доступности узлов** (эхо‑запросы и ответы).  
- **Передача информации о маршрутизации** (например, перенаправление на лучший маршрут).

#### Как работает
- **Эхо‑запрос (Echo Request)**: отправитель (например, `ping`) посылает пакет с типом `8` (ICMP).  
- **Эхо‑ответ (Echo Reply)**: получатель отвечает пакетом с типом `0`.  
- **Сообщение об ошибке** (например, тип `3` — «Destination Unreachable»).

#### Примеры использования
- `ping example.com` — проверяет доступность узла.  
- `traceroute example.com` — показывает маршрут и задержки до цели.  
- Маршрутизаторы используют ICMP для уведомления о проблемах (например, TTL expired).

#### Важные типы сообщений
- `0` — эхо‑ответ (Echo Reply);  
- `3` — недостижимость цели (Destination Unreachable);  
- `8` — эхо‑запрос (Echo Request);  
- `11` — время жизни пакета истекло (Time Exceeded).

### Ключевые отличия ICMP и ARP


| Критерий | ICMP | ARP |
|--------|------|-----|
| **Уровень OSI** | Сетевой (3) | Канальный (2) |
| **Назначение** | Управление и диагностика сети | Сопоставление IP ↔ MAC в LAN |
| **Тип сообщений** | Управляющие (ошибки, эхо) | Запросы/ответы о MAC‑адресах |
| **Область действия** | Между сетями (через маршрутизаторы) | Внутри одной LAN |
| **Примеры** | `ping`, `traceroute` | Разрешение MAC‑адреса по IP |

### Итог

- **ICMP** — «язык» сетевых уведомлений и диагностики. Позволяет:  
  - проверять доступность узлов (`ping`);  
  - отслеживать маршрут (`traceroute`);  
  - получать сообщения об ошибках.  

- **ARP** — «переводчик» между IP и MAC‑адресами в локальной сети. Позволяет:  
  - находить MAC‑адрес устройства по его IP;  
  - доставлять Ethernet‑кадры внутри LAN.
