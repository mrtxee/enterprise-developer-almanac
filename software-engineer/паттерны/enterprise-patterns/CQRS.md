**Command Query Responsibility Segregation (CQRS)** — это паттерн проектирования микросервисов, который разделяет операцию чтения и записи данных в системе на два отдельных интерфейса.
* *– Принцип разделения ответственности за выполнение командных запросов*

Типовой пример реализации паттерна CQRS – разделением операций чтения и записи через разные модели данных и интерфейсы.
- **Команды (Commands) используются для изменения состояния системы.**
- **Запросы (Queries) используются для получения данных из системы.**

__Пример__: служба СДЭК. Есть много запросов на отслеживание посылки, которые могут создать проблемы службам курьеров и управления, которые должно вносить изменения данных.
