# Anycast

**Anycast** — это метод сетевой маршрутизации, при котором **один и тот же IP-адрес** одновременно используется на множестве серверов в разных точках мира.

**Как работает:**
- Пользователь подключается к IP-адресу (например, `8.8.8.8`)
- Интернет-маршрутизаторы автоматически направляют его к **ближайшему** (в сетевом смысле) серверу с этим адресом

**Главные преимущества:**
- **Низкая задержка** — пользователь всегда идёт к ближайшему узлу
- **Отказоустойчивость** — при падении одного сервера трафик мгновенно перенаправляется на другой (без изменения DNS, без TTL)

**Где используется:** DNS-корневые серверы, CDN (Cloudflare, AWS CloudFront), балансировщики глобального трафика.

# Anycast vs BGP

**Ключевое отличие:** **Anycast** — это *схема адресации* (что делаем), **BGP** — это *протокол* (как делаем).

| Характеристика | Anycast                                              | BGP                                                       |
| -------------- | ---------------------------------------------------- | --------------------------------------------------------- |
| **Суть**       | Один IP на многих серверах                           | Протокол обмена маршрутами между сетями                   |
| **Уровень**    | Логическая схема / модель                            | Технический протокол (L4, межсетевой)                     |
| **Задача**     | Направить клиента к ближайшему узлу                  | Объявить соседним маршрутизаторам: "IP X находится здесь" |
| **Реализация** | Достигается **через** [[BGP]] (или другие протоколы) | Инструмент для реализации Anycast                         |

**Как связаны:**
- **BGP** — инструмент. Вы настраиваете его на каждом сервере, чтобы объявить миру: "IP `1.2.3.4` доступен у меня".
- **Anycast** — результат. Маршрутизаторы, получив одинаковые объявления от многих серверов, выбирают ближайший.

**Итог:** Anycast — это "что", BGP — один из способов "как это сделать в интернете".
