## Axon Framework

**Axon Framework** — платформа для реализации **CQRS** и **Event Sourcing** на Java/Spring.

| Компонент | Назначение |
|-----------|------------|
| **Command Gateway / Bus** | Прием и маршрутизация команд (изменение состояния) |
| **Event Gateway / Bus** | Публикация событий (реакция на изменения) |
| **Event Store** | Хранилище всех событий (источник истины) |
| **Aggregate** | Инкапсулирует бизнес-логику, генерирует события |
| **Query Handler** | Обрабатывает запросы чтения (отдельная модель) |
| **Saga** | Управляет долгоживущими распределенными транзакциями |

**Ключевые особенности**

- Разделение команд и запросов (CQRS)
- Восстановление состояния через воспроизведение событий
- Интеграция с Spring Boot, JPA, [[mongo-db|MongoDB]], Kafka
- Поддержка распределенных приложений (Axon Server)
