**Locust** — это инструмент для нагрузочного тестирования на Python, позволяющий моделировать поведение пользователей и проверять производительность веб‑приложений, API, сервисов и других систем под высокой нагрузкой.

## Как работает Locust

1. **Сценарии на Python.** Вы пишете код, описывающий действия «пользователей» (например, запросы к API, переходы по страницам).
2. **Масштабирование.** Locust запускает множество виртуальных пользователей (по умолчанию — в отдельных зелёных потоках *gevent*), имитируя реальную нагрузку.
3. **Веб‑интерфейс.** В реальном времени показывает метрики: RPS (запросов в секунду), время отклика, ошибки, число активных пользователей и др.
4. **Отчёты.** Можно экспортировать данные или использовать API для интеграции с CI/CD.

## Ключевые компоненты

- **`User`** — базовый класс для описания поведения виртуального пользователя.
- **`task`** — метод, определяющий действие пользователя (например, HTTP‑запрос).
- **`between()`** — задает интервал между выполнениями задач.
- **`HttpUser`** — наследник `User` с встроенным HTTP‑клиентом для веб‑тестов.
- **Веб‑панель** (`http://localhost:8089`) — интерфейс для запуска и мониторинга тестов.

## Установка

```bash
pip install locust
```

## Простой пример

Создаём файл `locustfile.py`:

```python
from locust import HttpUser, task, between

class MyUser(HttpUser):
    wait_time = between(1, 3)  # пауза между задачами: 1–3 сек

    @task
    def index_page(self):
        self.client.get("/")  # запрос к главной странице

    @task(3)  # эта задача выполняется в 3 раза чаще
    def view_item(self):
        self.client.get("/item?id=123")
```

## Запуск теста

1. В терминале выполните:
   ```bash
   locust -f locustfile.py
   ```
2. Откройте в браузере `http://localhost:8089`.
3. Укажите:
   - **Number of total users** — общее число виртуальных пользователей.
   - **Spawn rate** — скорость их запуска (пользователей в секунду).
   - **Host** — базовый URL тестируемого сервиса (например, `https://example.com`).
4. Нажмите **Start swarming** — тест начнётся.

## Основные метрики в интерфейсе

- **Requests per second (RPS)** — количество запросов в секунду.
- **Average response time** — среднее время отклика (мс).
- **Failures** — число ошибок.
- **Users** — активные виртуальные пользователи.
- **Charts** — графики нагрузки и времени отклика.

## Расширенные возможности

- **Настройка пользователей.** Можно создавать несколько классов `User` с разным поведением.
- **События и хуки.** Например, `on_start` и `on_stop` для действий при запуске/остановке пользователя.
- **Распределённый режим.** Запуск на нескольких машинах для сверхвысокой нагрузки (используйте ключи `-M` и `-s`).
- **API для автоматизации.** Можно запускать тесты через HTTP‑API или скрипты.
- **Экспорт данных.** Результаты доступны в CSV, JSON или через веб‑интерфейс.

## Когда использовать Locust

- Тестирование API (REST, GraphQL).
- Нагрузка на веб‑сайты и веб‑приложения.
- Проверка масштабируемости сервисов.
- Интеграция в CI/CD (например, запуск тестов при деплое).

## Плюсы Locust

- **Простота.** Код на Python, легко читать и менять.
- **Масштабируемость.** Тысячи пользователей на одном сервере.
- **Интерактивный интерфейс.** Наглядный мониторинг в реальном времени.
- **Гибкость.** Можно тестировать не только HTTP, но и другие протоколы (через кастомные клиенты).

## Минусы

- Требует базовых знаний Python.
- Для очень сложных сценариев может понадобиться доработка кода.

## Полезные команды

- `locust -f locustfile.py --headless -u 100 -r 10` — запуск без интерфейса: 100 пользователей, скорость 10/сек.
- `locust --help` — список всех опций.

**Итог:** Locust — мощный и гибкий инструмент для нагрузочного тестирования, особенно удобный для команд, работающих с Python. Он позволяет быстро создавать реалистичные сценарии и получать наглядные результаты.
