### Tableau — что это


**Tableau** — программное обеспечение для интерактивной бизнес‑аналитики (BI) и визуализации данных. Позволяет собирать, анализировать и наглядно представлять информацию из разнородных источников.


**Разработчик:** Tableau Software, Inc. (с 2019 года — в составе корпорации Salesforce).


### Ключевые возможности

- **Сбор данных** из множества источников:
  - реляционные БД (MySQL, PostgreSQL, Oracle, SQL Server);
  - облачные хранилища и сервисы (AWS Redshift, Google BigQuery, Salesforce, Microsoft Azure);
  - файлы (Excel, CSV, JSON, PDF).
- **Обработка и анализ** данных:
  - фильтрация и группировка;
  - сводные таблицы;
  - простые вычисления;
  - поиск трендов.
- **Визуализация** в виде:
  - графиков и диаграмм (в т. ч. пузырьковых);
  - географических карт;
  - деревьев событий;
  - интерактивных дашбордов.
- **Совместная работа:**
  - публикация отчётов в облаке;
  - совместный просмотр и редактирование;
  - настройка прав доступа.
- **Доступ из любой точки** через браузер или десктопное приложение.


### Основные продукты экосистемы Tableau


1. **Tableau Desktop** — инструмент для анализа и визуализации.  
   - версии: персональная (без совместного доступа) и профессиональная.
2. **Tableau Server** — платформа для публикации и совместного использования отчётов внутри организации.
3. **Tableau Online** — облачное решение (данные хранятся в облаке Salesforce).
4. **Tableau Public** — бесплатная версия с ограничениями:
   - работы сохраняются в публичном облаке;
   - нет экспорта в CSV и локального сохранения.
5. **Tableau Reader** — приложение для просмотра готовых визуализаций.
6. **Tableau Prep** — инструмент для подготовки данных (извлечение, очистка, трансформация).
7. **Tableau CRM** — интеграция с Salesforce CRM для анализа данных в рабочем процессе.
8. **Tableau Data Management** — модуль для поиска, подготовки и упорядочивания данных.
9. **Tableau Server Management** — сервис для развёртывания и управления серверными решениями.


### Преимущества

- **Интуитивный интерфейс** — не требует навыков программирования.
- **Высокая скорость** обработки больших массивов данных.
- **Гибкость** — настройка визуализаций под конкретные задачи.
- **Безопасность** — аутентификация, шифрование, ролевой доступ.
- **Мультиплатформенность** — работа в браузере, на Windows и macOS.
- **Интеграции** с популярными облачными и BI‑сервисами.


### Ограничения

- **Нет глубокой предобработки данных** — требуются сторонние инструменты (например, Python, R).
- **Ограниченная аналитика** — нет продвинутых ML‑моделей и прогнозного моделирования.
- **Производительность** может снижаться при работе с очень большими наборами данных.
- **Стоимость** — полная лицензия Tableau Desktop стоит ~7 000 руб./мес. на пользователя.
- **Для РФ** — новые версии и обновления недоступны с 2022 года.


### Для кого подходит

- **Аналитики данных** — для создания отчётов и дашбордов.
- **Руководители** — мониторинг KPI, выручки, прибыли.
- **Маркетологи** — анализ эффективности кампаний.
- **Финансисты** — отчётность и прогнозирование.
- **Менеджеры** — контроль работы подразделений.
- **Компании** любого масштаба — от малого бизнеса до корпораций.


### Пример использования

1. Подключение данных из Excel и PostgreSQL.
2. Создание графика продаж по регионам.
3. Добавление фильтров по периодам.
4. Публикация интерактивного дашборда в облаке.
5. Предоставление доступа команде через Tableau Server.


### Альтернативы

- **Microsoft Power BI** — сильнее в интеграции с Microsoft‑продуктами.
- **Dundas BI** — больше инструментов для предобработки.
- **Visary BI** — российский аналог для бизнес‑аналитики.
- **Sisense** — комплексная платформа с расширенной аналитикой.
