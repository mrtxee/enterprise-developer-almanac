# Облачные вычисления

**Cloud computing (облачные вычисления)** — это модель предоставления ИТ-услуг, при которой пользователи получают доступ к необходимым вычислительным ресурсам (серверам, хранилищам, сетям, программному обеспечению, аналитике) через Интернет по требованию.

**Суть технологии:**
* вместо покупки и обслуживания собственного оборудования компании арендуют ресурсы у поставщика облачных услуг;
* программное обеспечение и данные размещаются вне пользовательских компьютеров, доступ к ним осуществляется через сеть (аналогично получению электроэнергии из центральной электросети);
* пользователи платят за услуги по подписке или по мере использования ресурсов.

**Ключевые характеристики (по определению Национального института стандартов и технологий США — NIST):**
1. **Самообслуживание по требованию** — пользователи самостоятельно запрашивают и получают доступ к ресурсам без взаимодействия с персоналом поставщика.
2. **Широкий сетевой доступ** — ресурсы доступны через стандартные механизмы по сети.
3. **Объединение ресурсов** — провайдер объединяет вычислительные ресурсы для обслуживания множества клиентов с динамическим распределением.
4. **Быстрая эластичность** — возможность оперативно масштабировать ресурсы (увеличивать или уменьшать) в соответствии с потребностями.
5. **Измеряемый сервис** — использование ресурсов отслеживается и контролируется, что обеспечивает прозрачность для поставщика и потребителя.

**Основные модели облачных сервисов (Cloud computing):**
* **IaaS (Infrastructure as a Service)** — предоставление вычислительных ресурсов (серверы, хранилища, сети, виртуальные машины). Пользователь имеет максимальный контроль над инфраструктурой, но несёт ответственность за настройку и управление. Примеры: Amazon EC2, Google Compute Engine, «Яндекс Облако».
* **PaaS (Platform as a Service)** — готовая среда для разработки и запуска приложений (инструменты, библиотеки, серверы, базы данных). Провайдер управляет инфраструктурой, пользователь фокусируется на коде. Примеры: Google App Engine, Heroku, Microsoft Azure App Service.
* **SaaS (Software as a Service)** — доступ к готовому ПО через Интернет (без установки на локальный компьютер). Провайдер полностью управляет инфраструктурой, платформой и приложением. Примеры: Gmail, Google Docs, Zoom, Microsoft Office 365 [```2```](https://journal.sweb.ru/article/chem-otlichaetsya-saas-ot-paas-i-iaas)[```5```](https://sky.pro/wiki/profession/oblachnye-vychisleniya-osnovnye-koncepcii/).

**Модели развёртывания облачных систем:**
* **Публичное облако (Public Cloud)** — инфраструктура управляется провайдером и используется множеством организаций (AWS, Microsoft Azure, Google Cloud Platform).
* **Частное облако (Private Cloud)** — инфраструктура для одной организации (локально или у третьей стороны с выделенными ресурсами).
* **Общественное облако (Community Cloud)** — совместно используется несколькими организациями с общими требованиями (например, в здравоохранении или финансах).
* **Гибридное облако (Hybrid Cloud)** — сочетание публичного и частного облаков для гибкости и оптимизации затрат.
* **Мульти-облако (Multi-Cloud)** — использование сервисов от разных провайдеров в одной архитектуре [```5```](https://sky.pro/wiki/profession/oblachnye-vychisleniya-osnovnye-koncepcii/).

**Примеры использования Cloud computing:**
* хранение и обработка данных (облачные хранилища);
* веб-хостинг и развёртывание приложений;
* резервное копирование и восстановление данных;
* разработка и тестирование ПО (виртуальные машины, контейнеры);
* аналитика данных и машинное обучение;
* онлайн-обучение и видеосвязь;
* хранение медицинских данных и электронных карт;
* государственные сервисы для хранения и обработки данных граждан [```1```](https://otus.ru/journal/vvedenie-v-cloud-computing-kak-rabotat-s-oblachnymi-servisami/).

**Преимущества Cloud computing:**
* снижение затрат на инфраструктуру;
* лёгкое масштабирование ресурсов;
* быстрая развёртка приложений и сервисов;
* доступность ресурсов из любой точки мира;
* повышенная отказоустойчивость и безопасность (за счёт распределения данных);
* возможность сосредоточиться на бизнесе, а не на ИТ-инфраструктуре [```1```](https://otus.ru/journal/vvedenie-v-cloud-computing-kak-rabotat-s-oblachnymi-servisami/).
