## Шифрование и защита данных

Ниже — объяснение ключевых терминов: **шифрование**, **гомоморфное шифрование**, **токенизация**, **дифференциальная приватность** и **контексты безопасности**.

---

## Шифрование (Encryption)

> **Шифрование** — это процесс преобразования **открытых данных** в **нечитаемый вид**, который можно расшифровать только с помощью **ключа**.

**Цель**

- Защитить данные при хранении (`at rest`) и передаче (`in transit`);
- обеспечить **конфиденциальность**.

**Примеры**

```plaintext
"пароль123" → "x89kLmNpQrStUvWz"
```

**Типы**

| Тип | Описание |
|------|----------|
| **Симметричное** | Один ключ для шифрования и расшифровки<br>→ AES-256 |
| **Асимметричное** | Пара: public key (шифрует), private key (расшифровывает)<br>→ RSA, ECC |

**Где используется**

- HTTPS (TLS);
- хранение паролей;
- данные клиентов в БД;
- файлы в облаке.

> 💬 *«Шифрование — это как замок на двери. Только у кого есть ключ — может войти.»*

## Гомоморфное шифрование (Homomorphic Encryption)

> **Гомоморфное шифрование** — это **революционная форма шифрования**, при которой можно **выполнять операции над зашифрованными данными**, не расшифровывая их.

**Простыми словами:**

```plaintext
(2 + 3) × 4 = 20
```

Теперь представьте, что числа **зашифрованы**:

```plaintext
E(2) + E(3) → E(5)
E(5) × E(4) → E(20)
```

→ Результат остаётся зашифрованным

→ Получается `E(20)` → расшифровывается → `20`

→ А система **никогда не видела исходные данные**

### Зачем это важно

| Сценарий | Без гомоморфного шифрования | С гомоморфным |
|----------|-----------------------------|---------------|
| Больница отправляет данные в облако | ❌ Данные должны быть расшифрованы → риск утечки | ✅ Можно посчитать статистику без расшифровки |
| Финансовый анализ | ❌ Нужны открытые данные | ✅ Работа с E(data) |
| ML-обучение | ❌ Модель видит все данные | ✅ Обучение на зашифрованных данных |

### Ограничения

- очень медленное;
- большой размер данных;
- поддержка только определённых операций (например, сложение, умножение);
- пока **экспериментальная технология** (не массово используется).

### Реализации

- **Microsoft SEAL**;
- **IBM HELib**;
- **Google FHE (Fully Homomorphic Encryption)**.

> 💬 *«Гомоморфное шифрование — это когда ваш банк считает ваш баланс, но не знает, сколько у вас денег.»*

## Сравнение всех понятий

| Концепция | Основная цель | Когда использовать |
|-----------|---------------|--------------------|
| **Шифрование** | Скрыть данные от посторонних | При хранении/передаче чувствительных данных |
| **Гомоморфное шифрование** | Обрабатывать данные, не расшифровывая | Для анализа конфиденциальных данных (медицина, финансы) |
| **Токенизация** | Заменить чувствительные данные | Платежи, логи, тестовые среды |
| **Дифференциальная приватность** | Получать статистику, не нарушая приватность | BI, исследования, отчётность |
| **Контекст безопасности** | Принять решение о доступе | Zero Trust, Adaptive Auth, MFA |
