## Дифференциальная приватность: математический подход

> **Дифференциальная приватность** — это **математический подход**, при котором можно **получать статистику по группе**, но **невозможно определить данные конкретного человека**.

### 💡 Пример

Предположим, нужно узнать:

> *«Сколько пользователей болели COVID-19 за последний месяц?»*

Но **не нужно знать, кто именно болел**.

### 🔧 Принцип работы

- К данным добавляется **случайный шум**;
- индивидуальные записи становятся **неидентифицируемыми**;
- но **общая картина** остаётся точной.

```python
# Вместо реального ответа:
real_data = [1, 0, 1, 1, 0]  # 1=болел, 0=нет

# Добавляем шум:
noisy_data = [1, 0, 1, 1, 1]  # случайно один изменён

# Среднее ≈ то же, но нельзя сказать про одного пользователя
```

### ✅ Области применения

- Apple: сбор статистики без идентификации;
- Google Chrome: репорты ошибок;
- исследования: медицинские, социологические;
- BI: аналитика продаж без персональных данных.

### 🔑 Основной принцип

> *«Если удалить одного пользователя из набора — результат почти не изменится»*
> → Значит, его данные **не влияют на вывод** → он **приватен**
