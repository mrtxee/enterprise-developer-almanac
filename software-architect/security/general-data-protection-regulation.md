## GDPR: определение

**GDPR (General Data Protection Regulation)** — это **самый строгий и влиятельный закон о защите персональных данных в мире**, действующий с **25 мая 2018 года** в Европейском союзе.

> **GDPR** — это **регламент ЕС**, который:
> - защищает личные данные граждан;
> - даёт людям контроль над своей информацией;
> - требует от компаний прозрачности, безопасности и подотчётности.

> 🔑 Даже если компания не находится в ЕС, но работает с пользователями из ЕС → **GDPR распространяется на неё**.

---

## Кто должен соблюдать GDPR

| Компания | Нужно ли соблюдать GDPR? |
|----------|--------------------------|
| В ЕС | ✅ Да |
| За пределами ЕС, но есть пользователи из ЕС | ✅ Да (например, сайт на английском) |
| Только российские пользователи | ❌ Нет (но может потребоваться ФЗ-152) |

## Основные принципы GDPR

| Принцип | Объяснение |
|---------|------------|
| **1. Законность, справедливость, прозрачность** | Собираете данные — объясните почему |
| **2. Цель ограничена** | Можно только для заявленной цели |
| **3. Минимизация данных** | Собирайте только то, что нужно |
| **4. Актуальность** | Поддерживайте данные в актуальном состоянии |
| **5. Хранение ограничено по времени** | Не храните "на всякий случай" |
| **6. Целостность и конфиденциальность** | [[encryption|Шифрование]], безопасность, [[data-loss-prevention|DLP]] |
| **7. Подотчётность** | Обработчик должен доказать, что соблюдает правила |

## Права пользователей (Data Subject Rights)

| Право | Что значит |
|-------|-----------|
| **Право на доступ** | Пользователь может запросить: «Какие у вас есть обо мне данные?» |
| **Право на исправление** | «Исправьте мою фамилию» |
| **Право на забвение (Right to be Forgotten)** | Удалите все мои данные |
| **Право на ограничение обработки** | «Не используйте мои данные, пока я проверяю их точность» |
| **Право на переносимость данных** | «Отдайте мои данные JSON'ом, чтобы я мог передать другому сервису» |
| **Право возражать против профилирования** | «Я не хочу, чтобы меня анализировали» |

## Обязанности компаний

| Требование | Как выполнить |
|------------|---------------|
| **Consent (согласие)** | Явное согласие: галочка + текст |
| **Data Protection by Design & Default** | Безопасность с самого начала |
| **DPO (Data Protection Officer)** | Если много PII или чувствительные данные |
| **DPIA (Data Protection Impact Assessment)** | Оценка рисков при обработке PII |
| **Обработка через Data Processor Agreement (DPA)** | Все контракты с третьими лицами (AWS, Google, Mailchimp) |
| **Уведомление о нарушении** | Сообщить в течение 72 часов после инцидента |
| **Privacy Policy** | Должна быть понятной и доступной |

## Персональные данные (PII)

```text
• Имя, фамилия
• Email, номер телефона
• IP-адрес (да, это PII!)
• Cookie ID
• Локация
• Фото, видео с лицом
• Биометрия
• Финансовая информация
• Здоровье, политические взгляды, ориентация
```

> 💡 Даже **псевдоним** может быть PII, если его можно связать с человеком.

## Ответственность и штрафы

| Нарушение | Штраф |
|-----------|-------|
| Лёгкое (нет политики) | До 10 млн € или 2% мирового оборота |
| Серьёзное (утечка, нет consent) | До 20 млн € или 4% оборота |

**Примеры реальных штрафов**

- **Meta (Facebook)** — 1,2 млрд €;
- **Google** — 50 млн €;
- **British Airways** — 20 млн £ за утечку 500 тыс. пассажиров.

## Практические шаги по соблюдению GDPR

| Ситуация | Что делать |
|----------|------------|
| Сбор email'ов | Явное согласие + возможность отписаться |
| Регистрация на сайте | `Я согласен с политикой` — не просто галочка, а осознанный выбор |
| Использование Google Analytics | Настройте cookie consent, анонимизируйте IP |
| Интеграция с SaaS | Проверьте, соответствует ли он GDPR |
| Утечка данных | Уведомить регулятора за 72 часа |

## Лучшие практики соблюдения GDPR

| Действие | Объяснение |
|----------|------------|
| **Consent Management Platform (CMP)** | OneTrust, Cookiebot |
| **Anonymization / Pseudonymization** | Не храните напрямую |
| **Encryption at rest & transit** | TLS, AES |
| **Access Control** | Только тот, кому нужно, — видит |
| **Audit Logs** | Кто и когда просил свои данные |
| **Data Mapping** | Где хранятся PII? |
| **Vendor Risk Assessment** | AWS, Azure, Mailchimp — должны быть GDPR-compliant |

## GDPR vs 152-ФЗ

| **Характеристика** | **GDPR** | **152-ФЗ** |
|--------------------|----------|------------|
| **Сфера применения** | Применяется на глобальном уровне, если речь идёт о гражданах ЕС | Применяется к организациям, которые обрабатывают данные российских граждан |
| **Локализация данных** | Нет особых требований | Требуется хранение на российских серверах |
| **Права личности** | Широкие права, включая переносимость данных | Права менее полные |
| **Штрафы** | До 20 млн евро или 4% мирового оборота | Административные штрафы |
| **Регулирующий орган** | Европейский совет по защите данных | Роскомнадзор (Федеральная служба по надзору в сфере связи) |
