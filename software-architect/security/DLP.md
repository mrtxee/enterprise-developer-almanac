Отличный и очень важный вопрос!  
**DLP (Data Loss Prevention)** — это **ключевая система защиты данных**, которая помогает **предотвратить утечку, случайную отправку или кражу конфиденциальной информации**.

---

## ✅ Что такое DLP?

> **DLP (Data Loss Prevention)** — это технология и набор политик, которые **обнаруживают, контролируют и блокируют попытки передачи чувствительных данных вне безопасной среды**.

### 🔹 Простыми словами:
> DLP — это **"страж", который говорит:**  
> _«Вы пытаетесь отправить список клиентов в Excel-файле? Нет. Это запрещено.»_

---

## 🛡️ Основные цели DLP

| Цель | Объяснение |
|------|------------|
| **Предотвращение утечки** | Не дать вывести данные через email, USB, облако |
| **Соблюдение нормативов** | GDPR, PCI-DSS, HIPAA, ФЗ-152 требуют контроля за персональными данными |
| **Защита IP компании** | Алгоритмы, исходный код, формулы — не должны уйти |
| **Контроль на границах** | Email, интернет, файловые обменники, облачные хранилища |

---

## 🔍 Как работает DLP?

DLP использует **три подхода**:

### 1. **Обнаружение (Detection)**
- Сканирует:
  - Электронная почта
  - Файловые серверы
  - Облачные хранилища (Google Drive, Dropbox)
  - Трафик (в реальном времени)

- Ищет по шаблонам:
  - `^\d{4}-\d{6}-\d{5}$` → номер карты
  - `@company.com` → внутренние адреса
  - `secret`, `password`, `private key`

### 2. **Классификация данных**
- Помечает данные как:
  - Public
  - Internal
  - Confidential
  - Secret
- На основе:
  - Регулярных выражений
  - Machine Learning
  - Контекста (например, название файла: "зарплаты.xlsx")

### 3. **Реакция (Prevention / Action)**
Когда DLP находит проблему — он может:

| Действие | Пример |
|--------|--------|
| **Блокировать** | Запретить отправку email с приложением "client_data.zip" |
| **Предупредить** | «Вы действительно хотите отправить этот файл?» |
| **Зашифровать автоматически** | Отправил → DLP шифрует → только для получателя |
| **Перенаправить администратору** | Отдел безопасности проверяет |
| **Залогировать инцидент** | Для аудита и расследования |

## 🧩 Где размещается DLP?

| Место | Что контролирует |
|-------|------------------|
| **Endpoint DLP** | На компьютере: USB, печать, скриншоты |
| **Network DLP** | В трафике: email, web, FTP |
| **Cloud DLP** | SaaS: Google Workspace, Microsoft 365, AWS |
| **Storage DLP** | Файловые серверы, SharePoint, NAS |
| **Email DLP** | SMTP, Outlook, Gmail |

## ✅ Пример: DLP в действии

```plaintext
Сотрудник хочет отправить:
📧 Тема: "Данные клиентов"
📎 Вложение: clients.xlsx
→ Содержит: ФИО, email, телефоны

DLP анализирует:
✅ Файл = .xlsx
✅ Содержит >10 email'ов
✅ Поле "Телефон" — похоже на мобильные
✅ Название: "клиенты"

→ Срабатывает правило: "Не отправлять персональные данные"
→ Появляется окно:
   ❗ "Этот файл содержит конфиденциальные данные.
      Вы уверены, что хотите его отправить?"
```

## 🆚 DLP vs другие технологии

| Технология | Чем отличается от DLP |
|-----------|------------------------|
| **Антивирус** | Ищет вредоносное ПО, а не утечку данных |
| **Firewall** | Блокирует IP/порт, но не содержимое письма |
| **SIEM** | Агрегирует логи, но не блокирует действия |
| **EDR/XDR** | Защита от атак, а не от ошибки сотрудника |
| **DLP** | ✅ Ищет именно **чувствительные данные** |

> ✅ **DLP — это про контент, а не про сетевой уровень.**

## ✅ Какие данные ищет DLP?

| Тип данных | Примеры |
|-------------|---------|
| **PII (Personally Identifiable Information)** | ФИО, паспорт, ИНН, СНИЛС |
| **PCI (Payment Card Data)** | PAN, CVV, срок действия |
| **PHI (Protected Health Info)** | Диагноз, медицинские записи |
| **Corporate Secrets** | Исходный код, бизнес-планы |
| **Financial Data** | Зарплаты, бухгалтерия |
| **Credentials** | Пароли, API-ключи, SSH-ключи |
