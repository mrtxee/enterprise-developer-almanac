## Токенизация (Tokenization)

> **Токенизация** — это **замена чувствительных данных на безсмысленные токены**, которые можно безопасно использовать.

### 💡 Пример:
```plaintext
Настоящий номер карты: 4111-1111-1111-1111
Токен: tok_abc123xyz
```

- В системе хранится `tok_abc123xyz`, а не настоящий PAN
- Только **токен-сервис** может вернуть оригинал

### ✅ Преимущества:
- Уменьшает зону охвата [[PCI-DSS]]
- Не нужно шифровать каждый запрос
- Можно использовать токены в логах, тестах

### 🔄 Отличие от шифрования:

| | **Шифрование** | **Токенизация** |
|--|------------------|------------------|
| **Обратимость** | Да (если есть ключ) | Да (только через vault) |
| **Размер выхода** | Почти как оригинал | Фиксированный (например, 16 символов) |
| **Ключевая зависимость** | Ключ | Vault / Token Service |
| **Используется в** | TLS, БД | Платежи, SaaS, API |

> ✅ **PCI-DSS рекомендует токенизацию вместо шифрования** для защиты платежных данных
