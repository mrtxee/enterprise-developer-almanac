# требования

## уточнения
* DAU = 50 000 000 пользователей
* Среднее число просмотренных постов в ленте в день 1 пользователя: 
	* 5 просмотров ленты в день
	* 1 просмотр: 10 постов
* Среднее число доабвлений постов 1 пользователя: 1 пост / 5 дней
* 1 пост это :
	* изображение, растровое, 500 КБ
	* 100 символов, 400 Б
## ФТ
* загрузка поста
* чтение ленты
* сервис подписок
	* добавить подиску
	* удалить подиску
## НФТ
* Troughput
	* RPS
		* $RPS(R) = 50\ млн * 5 / 86400 = 2\ 900$
		* $RPS(W) = 50\ млн / 5 / 86400 = 115$
	* Traffic
		* $Traffic(R) = 2900*500КБ = 1,5\ ГБс$
		* $Traffic(W) = 115*500КБ = 58\ МБс$
* Capcity
	* $Capacity = 58\ МБс * 86400c*365 = 1,8\ EБ\ /\ год$

# api

```bash
# чтение ленты

{
	"image" : byte[],

}

Content-type: json
{
	"feedId": int
}
# сервис подписок, отписаться

Content-type: json
{
	"feedId": int
}

```
