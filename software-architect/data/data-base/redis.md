## Шардирование в Redis

Redis использует шардирование по умолчанию для распределения данных — специально ничего настраивать не придётся. Всё пространство ключей в кластерах Redis разделено на 16384 слота (называемых слотами хэша), и эти слоты назначены нескольким узлам Redis. Данный ключ сопоставляется одному из этих слотов.

Хэш-слот для ключа вычисляется как:

$$
HASH\_SLOT = CRC16(\text{ключ}) \bmod 16384
$$
