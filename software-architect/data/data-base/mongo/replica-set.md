## Replica Set: группа серверов MongoDB

**Replica Set** — группа [[mongo-db]]-серверов, поддерживающих один и тот же набор данных для отказоустойчивости и репликации.

**Состав:**

| Роль | Описание |
|---|---|
| **Primary** | Принимает все операции записи, ведёт oplog (журнал операций) |
| **Secondary** | Реплицирует данные с primary, может читать (опционально) |
| **Arbiter** | Участвует в выборах, не хранит данные |

**Особенности:**

- автоматическое восстановление при отказе primary;
- выборы нового primary через консенсус (majority);
- минимум 3 узла или 2 + arbiter для надёжного выбора;
- обеспечивает высокую доступность, не масштабирование записи.
