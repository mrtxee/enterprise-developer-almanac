## Greenplum

### Общая информация

**Greenplum** — это массово-параллельная реляционная система управления базами данных (СУБД), основанная на PostgreSQL. Система предназначена для хранения и обработки больших объёмов данных (до сотен терабайт).

### Архитектура системы

Greenplum использует **MPP-архитектуру** (Massive Parallel Processing), которая включает следующие компоненты:

- **Master host** — главный узел, управляющий клиентскими соединениями и анализирующий SQL-запросы.
- **Secondary master** — резервный мастер для отказоустойчивости.
- **Segment hosts** — серверы-сегменты для хранения и обработки данных.
- **Interconnect** — внутренняя сеть для связи между узлами.

### Ключевые особенности

- **Горизонтальное масштабирование** — возможность добавления новых узлов для увеличения производительности.
- **Столбцовое хранение** данных для эффективного сжатия.
- Полная поддержка **SQL-стандартов** и PostgreSQL.
- **Отказоустойчивость** через резервные компоненты.
- Соответствие принципам **ACID**.

### Технические ограничения

- Максимальное количество таблиц: более 4 млрд.
- Максимальный размер таблицы: до 128 ТБ на сегмент.
- Максимальное число строк: более 281 триллиона.
- Максимальный размер строки: 1 ГБ.
- Максимальное количество столбцов: 1600.

### Области применения

Greenplum оптимально подходит для:

- создания крупных **корпоративных хранилищ данных**;
- **предиктивной аналитики** в банках и ритейле;
- обработки **больших данных**;
- построения **аналитических моделей**;
- реализации **[[ELT]]-процессов**.

### Интеграция и совместимость

Система поддерживает:

- работу с **BI-системами**;
- интеграцию с **Hadoop**;
- взаимодействие с **Apache Spark** и **Kafka**;
- использование библиотеки **MADlib** для анализа данных.

### Современное состояние

В мае 2024 года компания Tanzu by Broadcom приняла решение о закрытии исходного кода проекта Greenplum Database. Все будущие версии будут выпускаться как часть **VMware Tanzu Data Suite** с закрытым исходным кодом.
