**PL/pgSQL** — это процедурный язык программирования для СУБД **PostgreSQL**, позволяющий писать функции, триггеры, процедуры и блоки кода прямо внутри базы данных .

## Самое главное

- **Расширяет SQL** управляющими конструкциями: `IF`, циклы (`LOOP`, `FOR`, `WHILE`), обработка исключений (`BEGIN … EXCEPTION … END`) .
- Позволяет объявлять **переменные**, **константы**, **курсоры**, работать с **записями** и **строками** .
- Код выполняется **на стороне сервера БД**, что удобно для сложной бизнес‑логики, пакетной обработки данных, триггеров .

## Базовая структура

Типичный блок PL/pgSQL выглядит так :

```sql
[DECLARE
  -- переменные
]
BEGIN
  -- SQL и управляющие конструкции
[EXCEPTION
  -- обработка ошибок
]
END;
```

Пример функции :

```sql
CREATE OR REPLACE FUNCTION add_numbers(a INT, b INT)
RETURNS INT AS $$
DECLARE
  result INT;
BEGIN
  result := a + b;
  RETURN result;
END;
$$ LANGUAGE plpgsql;
```

## Когда используют

- Сложная **бизнес‑логика**, которую удобнее держать в БД .
- **Триггеры** для автоматических действий при вставке/обновлении/удалении .
- Пакетная обработка данных, ETL‑подобные скрипты внутри PostgreSQL .
