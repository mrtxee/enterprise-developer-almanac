## MapReduce

**MapReduce** — это модель распределённых вычислений, разработанная компанией Google в 2004 году (авторы — Джеффри Дин и Санджай Гемават) для обработки очень больших объёмов данных (до нескольких петабайт) в компьютерных кластерах. Также MapReduce — это фреймворк для вычисления распределённых задач на узлах (node) кластера.

Является одной из ключевых технологий [[big-data|Big Data]]. Реализована в таких системах, как:

- Apache Hadoop;
- Apache CouchDB;
- [[mongo-db|MongoDB]];
- [[hive-ql|Hive]] framework;
- GridGain;
- DryadLINQ и других.

## Как работает MapReduce

Работа MapReduce состоит из **трёх основных этапов**:

1. **Map (предварительная обработка)**:
    - входные данные делятся на части;
    - каждый рабочий узел (worker node) обрабатывает свою часть данных с помощью функции Map;
    - результат сохраняется в формате «ключ-значение» во временном хранилище.
2. **Shuffle and Sort (перетасовка и сортировка)**:
    - рабочие узлы перераспределяют данные на основе ключей, созданных на этапе Map;
    - данные группируются так, чтобы все значения для одного ключа оказались на одном узле;
    - происходит сортировка ключей.
3. **Reduce (финальная обработка)**:
    - каждый рабочий узел обрабатывает группу данных с одинаковым ключом;
    - результаты «склеиваются» и передаются на главный узел (master node);
    - формируется итоговый результат.

## Для чего нужен MapReduce

**Основная цель** — упростить обработку Big Data, распределённой по нескольким компьютерам или узлам, за счёт:

- параллельной обработки данных;
- автоматизации распределения задач по узлам кластера;
- управления сбоями и коммуникации между узлами.

**Примеры применения**

- **Поисковые системы** (индексация веб-страниц: извлечение слов и сопоставление их с ID документов).
- **Обработка изображений и видео** (анализ больших наборов медиафайлов).
- **Анализ социальных сетей** (анализ графов взаимодействий, таргетирование рекламы).
- **Научные исследования** (обработка геномных данных, космических наблюдений).
- **Распределённый поиск и сортировка данных**.
- **Обработка логов сети** (подсчёт частоты обращений, анализ трафика).
- **[[machine-learning|Машинное обучение]] и статистический перевод**.
- **Построение инвертированных индексов, кластеризация документов**.

## Ключевые преимущества MapReduce

- **Масштабируемость** — легко добавлять/удалять узлы для управления ресурсами.
- **Надёжность** — автоматическое восстановление после сбоев (задача переназначается на другой узел).
- **Гибкость** — поддержка различных форматов и структур данных.
- **Локальность данных** — обработка происходит на тех же серверах, где данные хранятся (уменьшает сетевой трафик).
- **Простота для разработчиков** — нужно реализовать только функции Map и Reduce, остальное берёт на себя фреймворк.

## Ограничения MapReduce

- **Низкая производительность** для интерактивного анализа и сложных операций (из-за пакетной обработки).
- **Высокие задержки** при цикле «чтение-запись» с жёсткого диска.
- **Не подходит для потоковой обработки** в реальном времени (например, в IoT).
- **Сложность программирования** — требует особого подхода (мышление в терминах Map и Reduce).
- **Ограниченность для итеративных алгоритмов** (например, в машинном обучении).

**Вывод**

MapReduce — фундаментальная технология для распределённой обработки Big Data, оптимальная для пакетной обработки больших объёмов информации. Несмотря на ограничения, остаётся востребованной в сферах, где критична масштабируемость и надёжность, а требования к скорости обработки не являются первостепенными.
