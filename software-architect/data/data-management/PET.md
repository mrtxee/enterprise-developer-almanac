## Privacy-Enhancing Technologies

**Privacy-Enhancing Technologies (PETs)** — это **набор технологий и методов**, которые позволяют **использовать данные, не нарушая конфиденциальность**.

**Что такое PET**

> **PET** — это инструменты, которые **минимизируют риски утечки персональных данных**, позволяя при этом **анализировать, обрабатывать и использовать данные**.

**Простыми словами**

> «Как получить пользу от данных, не зная, кому они принадлежат?»

**Основные типы PET**

| Технология                                   | Описание                                           | Пример использования                              |
| -------------------------------------------- | -------------------------------------------------- | ------------------------------------------------- |
| **Анонимизация**                             | Удаление прямых идентификаторов                    | Замена email на `user_123`                        |
| **Псевдонимизация**                          | Замена идентификаторов на токены                   | `sha256(email)` вместо email                      |
| **Дифференциальная приватность**             | Добавление шума в данные                           | Аналитика с минимальной погрешностью              |
| **Гомоморфное шифрование**                   | Вычисления над зашифрованными данными              | ML-модель обучается на зашифрованных данных       |
| **Secure Multi-Party Computation (SMPC)**    | Совместные вычисления без раскрытия данных         | Банки совместно проверяют мошенничество           |
| **Zero-Knowledge Proofs (ZKP)**              | Доказательство без раскрытия данных                | Подтверждение возраста без указания даты рождения |
| **Federated Learning**                       | Обучение модели на устройствах без передачи данных | Клавиатура на телефоне учится локально            |
| **Trusted Execution Environments ([[TEE]])** | Изолированное выполнение кода                      | Intel SGX, ARM TrustZone                          |

**Где используются PET**

| Сфера | Пример |
|-------|--------|
| **Финансы** | Совместный анализ мошенничества между банками (SMPC) |
| **Здравоохранение** | Анализ медицинских данных без раскрытия пациентов (дифференциальная приватность) |
| **Реклама** | Таргетинг без передачи персональных данных (FLoC, Topics API) |
| **Госуслуги** | Подтверждение права на льготу без раскрытия дохода (ZKP) |
| **IoT** | Обработка данных на устройстве (Federated Learning) |

**Особенности**

| Плюс/минус | Объяснение |
|------------|------------|
| ✅ Соответствие GDPR/CCPA | Минимизация данных = меньше рисков |
| ✅ Доверие пользователей | Люди охотнее делятся данными |
| ✅ Новые бизнес-модели | Совместный анализ без обмена данными |
| ✅ Защита от утечек | Даже при утечке данные бесполезны |
| ❌ Сложность внедрения | Требуются специалисты по криптографии |
| ❌ Снижение производительности | Гомоморфное шифрование медленное |
| ❌ Потеря точности | Дифференциальная приватность добавляет шум |
| ❌ Юридическая неопределённость | Не все регуляторы принимают анонимизацию как «безопасную» |

**Пример: Дифференциальная приватность в Apple**

> Apple использует **дифференциальную приватность** для сбора данных об использовании:

- На устройстве добавляется шум к данным
- Отправляются только агрегированные результаты
- Apple **не знает**, какие именно данные у пользователя
- Позволяет улучшать продукт **без нарушения приватности**.

**Финальный вывод**

> **PET — это мост между данными и приватностью.**
> Они позволяют:
> - Использовать данные
> - Не нарушать права пользователей
> - Соответствовать законам

> *«Privacy is not the opposite of data. It's the foundation of trust.»*

> *«Data can be useful without being identifiable.»*
