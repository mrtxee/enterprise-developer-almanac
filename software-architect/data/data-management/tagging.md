## Инструменты для маркировки данных

| **Назначение**                                                         | **Инструменты**                                                                                                      |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Средства обнаружения и классификации данных                            | BigID; Informatica Data Catalog; Varonis Data Classification Engine                                                  |
| Решения для предотвращения потери данных ([[data-loss-prevention|DLP]])                         | Symantec DLP; McAfee DLP                                                                                             |
| Управление идентификацией и доступом ([[identity-access-management|IAM]])                             | Okta; Azure Active Directory; OneTrust (для интеграции меток в облачные хранилища)                                  |
| Управление информацией и событиями безопасности ([[SIEM|SIEM]])                 | Splunk; IBM QRadar                                                                                                   |
| Облачные метки и защита                                                | Microsoft Azure Information Protection; AWS Macie; Informatica (для интеграции меток в облачные хранилища)          |
| Комплексное управление данными и соответствием нормативным требованиям | BigID; Collibra; Informatica; OneTrust; DataGrail                                                                    |
