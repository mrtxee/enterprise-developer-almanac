**JDBC Catalog** — это **не аббревиатура**, а составной термин:

- **JDBC** — **Java Database Connectivity** (это и есть аббревиатура)
- **Catalog** — каталог (в значении «реестр метаданных»)

---

### 🔤 Расшифровка:
- **J**ava  
- **D**atabase  
- **C**onnectivity

---

### 💡 Что такое JDBC?
**JDBC** — это **стандартный API в Java** для подключения и взаимодействия с реляционными базами данных (PostgreSQL, MySQL, Oracle и др.).

Он позволяет:
- Выполнять SQL-запросы
- Получать результаты
- Управлять транзакциями

---

### 📦 А что такое "JDBC Catalog"?
В контексте систем аналитики (Spark, Trino, Flink и др.) **JDBC Catalog** означает:

> **Каталог метаданных, который хранит информацию о таблицах и схемах в обычной реляционной базе данных через JDBC.**

Например:
- Spark может использовать **PostgreSQL** как каталог метаданных.
- В PostgreSQL будут таблицы вроде `tables`, `columns`, `databases`.
- Сама **таблица данных** может лежать в S3 (Parquet), но её **описание** — в PostgreSQL.

Таким образом, **JDBC Catalog = использование любой RDBMS как хранилища метаданных через JDBC-интерфейс**.

---

### 🆚 Примеры других каталогов:
- **Hive Metastore** — специализированный каталог (обычно поверх MySQL/PostgreSQL)
- **AWS Glue Catalog** — облачный managed-каталог от AWS
- **Nessie** — Git-подобный каталог для lakehouse

А **JDBC Catalog** — это **универсальный способ** подключить **любую СУБД** как каталог.

---

✅ **Итог**:  
**JDBC = Java Database Connectivity**  
**JDBC Catalog = каталог метаданных, реализованный через JDBC-подключение к обычной БД**.
