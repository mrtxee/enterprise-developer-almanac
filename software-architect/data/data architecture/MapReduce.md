### Что такое MapReduce?

**MapReduce** — это модель распределённых вычислений, разработанная компанией Google в 2004 году (авторы — Джеффри Дин и Санджай Гемават) для обработки очень больших объёмов данных (до нескольких петабайт) в компьютерных кластерах [```2```](https://bigdataschool.ru/wiki/mapreduce/)[```3```](https://selectel.ru/blog/hadoop-chast-3-pig-obrabotka-dannyx/). Также MapReduce — это фреймворк для вычисления распределённых задач на узлах (node) кластера [```1```](https://www.decosystems.ru/mapreduce/).

Является одной из ключевых технологий Big Data. Реализована в таких системах, как:
* Apache Hadoop;
* Apache CouchDB;
* [[MongoDB]];
* Hive framework;
* GridGain;
* DryadLINQ и других [```2```](https://bigdataschool.ru/wiki/mapreduce/).

### Как работает MapReduce?

Работа MapReduce состоит из **трёх основных этапов**:

1. **Map (предварительная обработка)**:
   * входные данные делятся на части;
   * каждый рабочий узел (worker node) обрабатывает свою часть данных с помощью функции Map;
   * результат сохраняется в формате «ключ-значение» во временном хранилище [```2```](https://bigdataschool.ru/wiki/mapreduce/).

2. **Shuffle and Sort (перетасовка и сортировка)**:
   * рабочие узлы перераспределяют данные на основе ключей, созданных на этапе Map;
   * данные группируются так, чтобы все значения для одного ключа оказались на одном узле;
   * происходит сортировка ключей [```1```](https://www.decosystems.ru/mapreduce/)[```5```](https://www.geeksforgeeks.org/software-engineering/mapreduce-architecture/).

3. **Reduce (финальная обработка)**:
   * каждый рабочий узел обрабатывает группу данных с одинаковым ключом;
   * результаты «склеиваются» и передаются на главный узел (master node);
   * формируется итоговый результат [```2```](https://bigdataschool.ru/wiki/mapreduce/)[```5```](https://www.geeksforgeeks.org/software-engineering/mapreduce-architecture/).

### Для чего нужен MapReduce?

**Основная цель** — упростить обработку Big Data, распределённой по нескольким компьютерам или узлам, за счёт:
* параллельной обработки данных;
* автоматизации распределения задач по узлам кластера;
* управления сбоями и коммуникации между узлами [```1```](https://www.decosystems.ru/mapreduce/).

**Примеры применения:**
* **Поисковые системы** (индексация веб-страниц: извлечение слов и сопоставление их с ID документов) [```1```](https://www.decosystems.ru/mapreduce/).
* **Обработка изображений и видео** (анализ больших наборов медиафайлов) [```1```](https://www.decosystems.ru/mapreduce/).
* **Анализ социальных сетей** (анализ графов взаимодействий, таргетирование рекламы) [```1```](https://www.decosystems.ru/mapreduce/).
* **Научные исследования** (обработка геномных данных, космических наблюдений) [```1```](https://www.decosystems.ru/mapreduce/).
* **Распределённый поиск и сортировка данных** [```2```](https://bigdataschool.ru/wiki/mapreduce/).
* **Обработка логов сети** (подсчёт частоты обращений, анализ трафика) [```2```](https://bigdataschool.ru/wiki/mapreduce/).
* **Машинное обучение и статистический перевод** [```2```](https://bigdataschool.ru/wiki/mapreduce/).
* **Построение инвертированных индексов, кластеризация документов** [```2```](https://bigdataschool.ru/wiki/mapreduce/).

### Ключевые преимущества MapReduce

* **Масштабируемость** — легко добавлять/удалять узлы для управления ресурсами [```1```](https://www.decosystems.ru/mapreduce/).
* **Надёжность** — автоматическое восстановление после сбоев (задача переназначается на другой узел) [```1```](https://www.decosystems.ru/mapreduce/)[```4```](https://bigdataschool.ru/blog/about-mapreduce/).
* **Гибкость** — поддержка различных форматов и структур данных [```1```](https://www.decosystems.ru/mapreduce/).
* **Локальность данных** — обработка происходит на тех же серверах, где данные хранятся (уменьшает сетевой трафик) [```3```](https://selectel.ru/blog/hadoop-chast-3-pig-obrabotka-dannyx/).
* **Простота для разработчиков** — нужно реализовать только функции Map и Reduce, остальное берёт на себя фреймворк [```5```](https://www.geeksforgeeks.org/software-engineering/mapreduce-architecture/).

### Ограничения MapReduce

* **Низкая производительность** для интерактивного анализа и сложных операций (из-за пакетной обработки) [```1```](https://www.decosystems.ru/mapreduce/).
* **Высокие задержки** при цикле «чтение-запись» с жёсткого диска [```4```](https://bigdataschool.ru/blog/about-mapreduce/).
* **Не подходит для потоковой обработки** в реальном времени (например, в IoT) [```4```](https://bigdataschool.ru/blog/about-mapreduce/).
* **Сложность программирования** — требует особого подхода (мышление в терминах Map и Reduce) [```1```](https://www.decosystems.ru/mapreduce/).
* **Ограниченность для итеративных алгоритмов** (например, в машинном обучении) [```4```](https://bigdataschool.ru/blog/about-mapreduce/).

### Вывод

MapReduce — фундаментальная технология для распределённой обработки Big Data, оптимальная для пакетной обработки больших объёмов информации. Несмотря на ограничения, остаётся востребованной в сферах, где критична масштабируемость и надёжность, а требования к скорости обработки не являются первостепенными.
