# Шардирование в Redis

Redis использует шардирование по умолчанию для распределения данных, специально ничего настраивать не придётся. Всё пространство ключей в кластерах Redis разделено на 16384 слота (называемых слотами хэша), и эти слоты назначены нескольким узлам Redis. Данный ключ сопоставляется одному из этих слотов. Хэш-слот для ключа [**вычисляется**](https://redis.io/topics/cluster-spec#keys-distribution-model) как: **HASH_SLOT = CRC16 (ключ) mod 16384**, подробнее об этом можно прочитать [на сайте Redis](https://redis.io/topics/cluster-spec#keys-distribution-model).
