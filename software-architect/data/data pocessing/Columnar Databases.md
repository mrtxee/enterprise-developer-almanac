## ✅ 1. Столбцовые базы данных (Columnar Databases)

> **Столбцовая база данных** — это БД, в которой данные хранятся **по столбцам**, а не по строкам.

### 🔧 Как работает:
- Вместо `ROW: [id=1, name=Alice, age=30]` → хранится:
  - `id: [1, 2, 3]`
  - `name: ["Alice", "Bob", "Charlie"]`
  - `age: [30, 25, 35]`

### ✅ Преимущества:
| Плюс | Объяснение |
|------|------------|
| ✅ Высокая скорость чтения | При запросе только одного столбца — читается только он |
| ✅ Эффективное сжатие | Похожие значения в одном столбце → лучше сжимаются |
| ✅ Хорошо для аналитики | SELECT COUNT(*) FROM sales WHERE year=2023 — очень быстро |

### ❌ Минусы:
| Минус | Объяснение |
|-------|------------|
| ❌ Медленная запись | При вставке одной строки — нужно обновить все столбцы |
| ❌ Не подходит для OLTP | Операции вставки/обновления — медленные |

### 📌 Примеры:
- **ClickHouse**
- **Amazon Redshift**
- **Google BigQuery**
- **Snowflake**

## ✅ 2. Apache Spark

> **Apache Spark** — это **фреймворк для быстрой обработки больших данных**, который работает **в памяти** и поддерживает **разные типы вычислений**.

### 🔧 Что умеет:
- **Batch processing** — обработка пакетов
- **Streaming** — потоковая обработка (Spark Streaming)
- **MLlib** — машинное обучение
- **GraphX** — графовые вычисления
- **SQL** — через Spark SQL

### ✅ Преимущества:
| Плюс | Объяснение |
|------|------------|
| ✅ Высокая скорость | Работает в памяти (в отличие от Hadoop MapReduce) |
| ✅ Поддержка разных моделей | Batch, Streaming, ML, Graph |
| ✅ Легко использовать | API на Java, Scala, Python, R |
| ✅ Интеграция с Hadoop | Может читать из HDFS, S3 и др. |

### ❌ Минусы:
| Минус | Объяснение |
|-------|------------|
| ❌ Требует много памяти | Работа в памяти → высокое потребление RAM |
| ❌ Сложнее настраивать | Нужно управлять кластером, memory, partitions |

## ✅ 3. MapReduce

> **MapReduce** — это **модель параллельной обработки данных**, разработанная Google, реализованная в **Hadoop**.

### 🔧 Как работает:
1. **Map** — разбивает данные на части, применяет функцию к каждой
2. **Shuffle & Sort** — сортирует и группирует результаты
3. **Reduce** — объединяет результаты

```python
# Пример: подсчёт слов
Map: "hello world hello" → [("hello",1), ("world",1), ("hello",1)]
Reduce: [("hello",2), ("world",1)]
```

### ✅ Преимущества:
| Плюс | Объяснение |
|------|------------|
| ✅ Простота концепции | Легко понять и реализовать |
| ✅ Масштабируемость | Работает на тысячах узлов |
| ✅ Надёжность | Автоматическое восстановление при сбое |

### ❌ Минусы:
| Минус | Объяснение |
|-------|------------|
| ❌ Медленный | Запись на диск после каждого шага |
| ❌ Невозможность итераций | Каждый шаг — новый Job |
| ❌ Не подходит для интерактивной аналитики | Долгий запуск, нет реального времени |

## ✅ 4. Massive Parallel Processing (MPP)

> **MPP** — это **архитектура**, при которой **каждый узел обрабатывает часть данных независимо**, а затем результаты объединяются.

### 🔧 Как работает:
- Данные распределяются по узлам (например, по hash(id))
- Каждый узел выполняет свою часть вычислений
- Результаты собираются на координаторе

### ✅ Преимущества:
| Плюс | Объяснение |
|------|------------|
| ✅ Высокая производительность | Параллельная обработка |
| ✅ Масштабируемость | Можно добавлять узлы |
| ✅ Подходит для аналитики | ClickHouse, Redshift, Snowflake — используют MPP |

### ❌ Минусы:
| Минус | Объяснение |
|-------|------------|
| ❌ Сложность управления | Нужно управлять кластером |
| ❌ Высокие требования к сети | Много межузлового трафика |

## ✅ Сравнение: Все 4 технологии

| Технология | Тип | Скорость | Архитектура | Используется для |
|------------|-----|----------|-------------|------------------|
| **Столбцовые БД** | База данных | Очень высокая | MPP | Аналитика, BI |
| **Apache Spark** | Фреймворк | Высокая (в памяти) | MPP | Batch, Streaming, ML |
| **MapReduce** | Модель вычислений | Средняя | MPP | Большие пакеты, ETL |
| **MPP** | Архитектура | Очень высокая | Распределённая | Все вышеуказанные |

## ✅ Когда что использовать?

| Ваша цель | Рекомендация |
|----------|--------------|
| ✅ Быстрая аналитика (BI, отчёты) | ➤ **Столбцовая БД (ClickHouse, Redshift)** |
| ✅ Обработка больших пакетов | ➤ **MapReduce / Spark** |
| ✅ Реальное время, потоки | ➤ **Spark Streaming / Kafka + Flink** |
| ✅ Машинное обучение на больших данных | ➤ **Apache Spark (MLlib)** |
| ✅ Гибрид: пакеты + потоки + ML | ➤ **Apache Spark** |
