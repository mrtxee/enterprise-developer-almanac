## ✅ Что такое Data Lake?

**Data Lake** — это **централизованное хранилище**, которое:
- Принимает **любые данные** (структурированные, полуструктурированные, неструктурированные)
- Хранит их **в оригинальном формате** (JSON, CSV, Parquet, [[Avro|Avro]], видео, логи)
- Позволяет анализировать данные **позднее**, когда станет ясно, что с ними делать

---

✅ Зачем нужен Data Lake?

| Цель                          | Объяснение                                                            |
| ----------------------------- | --------------------------------------------------------------------- |
| ✅ Гибкость                    | Можно хранить любые данные без предварительного определения структуры |
| ✅ Дешевизна                   | Хранение на HDFS, S3, Azure Blob — дешевле, чем DW                    |
| ✅ Масштабируемость            | Может хранить PB данных                                               |
| ✅ Исследовательская аналитика | Для ML, Data Science, экспериментов                                   |
| ✅ Сохранение "сырых" данных   | Никакие преобразования не теряют информацию                           |

✅ Основные компоненты

| Компонент            | Роль                                         |
| -------------------- | -------------------------------------------- |
| **Источники данных** | [[OLTP]], [[software-engineer/технологии/kafka/Kafka]], файлы, IoT-устройства   |
| **Data Lake**        | S3, HDFS, Azure Blob — хранит "сырые" данные |
| **Data Processing**  | Spark, Flink, Airflow — обрабатывает данные  |
| **Data Warehouse**   | ClickHouse, Redshift — для аналитики         |
| **BI-инструменты**   | Power BI, Tableau — для отчётов              |

---

✅ Типичные технологии

| Компонент | Примеры |
|----------|---------|
| **Data Lake** | Amazon S3, Azure Data Lake Storage, Google Cloud Storage, HDFS |
| **Обработка** | Apache Spark, Apache Flink, Databricks, Airflow |
| **Аналитика** | Presto, Trino, Athena, Hive |
| **ML/DS** | Python, Pandas, PySpark, TensorFlow |

---

✅ Форматы данных в Data Lake

| Формат | Тип данных | Пример |
|--------|-----------|--------|
| **JSON** | Полуструктурированные | `{"user": "Alice", "action": "login"}` |
| **CSV** | Структурированные | `id,name,email` |
| **Parquet** | Структурированные (оптимизированный) | Для аналитики |
| **Avro** | Структурированные | Схема + данные |
| **Log files** | Неструктурированные | `2025-01-16 10:00:00 ERROR login failed` |
| **Images/Video** | Неструктурированные | `image.jpg`, `video.mp4` |

---

✅ Преимущества Data Lake

| Плюс | Объяснение |
|------|------------|
| ✅ Гибкость | Можно хранить всё, что угодно |
| ✅ Дешевизна | Хранение на объектных хранилищах (S3) дешевле |
| ✅ Масштабируемость | До PB/TB данных |
| ✅ Исследовательская аналитика | Подходит для ML, Data Science |
| ✅ Сохранение данных | Никаких потерь при загрузке |

---

✅ Недостатки

| Минус | Объяснение |
|-------|------------|
| ❌ Сложность | Требует специальных инструментов (Spark, Flink) |
| ❌ Отсутствие схемы | Без метаданных — сложно найти данные |
| ❌ Качество данных | Нет гарантий, что данные корректны |
| ❌ Безопасность | Требуется управление доступом (IAM, ACL) |
| ❌ Задержка | Анализ требует обработки перед запросом |

---

✅ Когда использовать Data Lake?

| Сценарий                                             | Рекомендация                   |
| ---------------------------------------------------- | ------------------------------ |
| ✅ Нужно хранить все данные (логи, события, фото)     | ➤ **Data Lake**                |
| ✅ Нужно делать ML/DS                                 | ➤ **Data Lake**                |
| ✅ Нужно исследовать данные без заранее заданной цели | ➤ **Data Lake**                |
| ✅ Нужны быстрые отчёты                               | ➤ **[[Data Warehouse]]**       |
| ✅ Нужно обновлять статус заказа                      | ➤ **[[OLTP]]**, а не Data Lake |

## ✅ Data Lake vs Data Warehouse

> 💬 _“A data lake is where you store everything. A data warehouse is where you use it.”_

| Критерий              | **Data Lake**                 | **[[Data Warehouse]]**                |
| --------------------- | ----------------------------- | ------------------------------------- |
| **Формат данных**     | Любые (сырые)                 | Структурированные (денормализованные) |
| **Цель**              | Хранение и исследование       | Аналитика и отчёты                    |
| **Скорость запросов** | Медленная (требует обработки) | Быстрая                               |
| **Стоимость**         | Низкая                        | Высокая                               |
| **Масштабируемость**  | Очень высокая                 | Высокая                               |
| **Примеры**           | S3, HDFS, ADLS                | ClickHouse, Redshift, BigQuery        |
→ ✅ **Data Lake — это "склад сырья".**  
→ ✅ **[[Data Warehouse]] — это "завод готовой продукции".**
