**Parquet** — это **формат хранения данных**, оптимизированный для **аналитики и больших объёмов данных**.

---

## ✅ Что такое Parquet?

**Parquet** — это **открытый, колоночный (columnar) формат**, который:
- Хранит данные **по столбцам**, а не по строкам
- Поддерживает **сжатие**
- Оптимизирован для **быстрых SQL-запросов**

💬 Простыми словами:
> Это как **хранить таблицу в Excel, но только по столбцам** — так быстрее читать конкретные поля.

---

## ✅ Почему Parquet лучше, чем CSV или JSON?

| Формат | Структура | Сжатие | Скорость чтения | Используется для |
|--------|-----------|--------|----------------|------------------|
| **CSV** | По строкам | Нет | Медленно | Маленькие файлы |
| **JSON** | По строкам | Нет | Очень медленно | API, логи |
| **Parquet** | По столбцам | Да (Snappy, Gzip) | Очень быстро | Аналитика, DW |

---

## ✅ Как работает Parquet?

### 📁 Структура файла:

```text
[Header]
[Column 1: user_id]   ← сжатые значения
[Column 2: name]      ← сжатые значения
[Column 3: amount]    ← сжатые значения
[Footer]
```

→ При запросе `SELECT user_id, amount FROM table` — читаются только два столбца → **экономия времени и памяти**.

## ✅ Пример: Parquet vs CSV

#### 📊 Таблица:

| id  | name    | amount |
| --- | ------- | ------ |
| 1   | Alice   | 100    |
| 2   | Bob     | 200    |
| 3   | Charlie | 300    |

#### 📄 CSV:
```csv
id,name,amount
1,Alice,100
2,Bob,200
3,Charlie,300
```

→ Чтение `SELECT name, amount` → нужно прочитать все строки → медленно.

#### 📄 Parquet:
```parquet
[Column: name] → "Alice", "Bob", "Charlie"
[Column: amount] → 100, 200, 300
```

→ Чтение `SELECT name, amount` → читаются только два столбца → **очень быстро**.
