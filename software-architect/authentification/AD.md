# Active Directory

**Active Directory (AD)** — это технология компании Microsoft, представляющая собой **службу каталогов** для централизованного управления пользователями, компьютерами, сетевыми устройствами и другими ресурсами в корпоративной сети.
- **[[LDAP]] — это протокол** доступа к иерархическим каталогам, содержащим информацию о пользователях, группах, устройствах и других ресурсах
- **Active Directory — это реализация каталога**, которая **использует LDAP**

---

✅ Краткое определение

| Технология           | Что это?                                                          |
| -------------------- | ----------------------------------------------------------------- |
| **LDAP**             | **Протокол** для доступа к иерархическим каталогам (RFC 4511)     |
| **Active Directory** | **Служба каталогов от Microsoft**, построенная **на основе LDAP** |

> 💡 **LDAP — это язык. AD — это книга, написанная на этом языке.**

---

✅ Сравнение: Active Directory vs LDAP

| Критерий                 | **Active Directory (AD)**                        | **LDAP (OpenLDAP и др.)**                            |
| ------------------------ | ------------------------------------------------ | ---------------------------------------------------- |
| **Тип**                  | Продукт Microsoft (Windows Server)               | Открытый протокол + реализации (OpenLDAP, Apache DS) |
| **Основа**               | Использует LDAP как один из протоколов           | Является самим протоколом                            |
| **Аутентификация**       | [[Kerberos]] (основной), NTLM, [[LDAP]]          | Обычно простой bind (логин/пароль) или SASL          |
| **Операционная система** | Только Windows Server                            | Любая (Linux, Unix, Windows)                         |
| **Лицензирование**       | Платный (часть Windows Server)                   | Бесплатный (OpenLDAP)                                |
| **Интеграция**           | Глубокая интеграция с Windows, Group Policy, DNS | Универсальный, но требует настройки                  |
| **Управление**           | GUI (Active Directory Users and Computers)       | CLI / Web UI (phpLDAPadmin и др.)                    |
| **Масштабируемость**     | Отлично (для корпоративных сетей)                | Хорошо (при правильной настройке)                    |
| **Безопасность**         | [[Kerberos]], [[TLS\|TLS]], Group Policy         | TLS, SASL, ACL                                       |
| **Область применения**   | Корпоративные Windows-сети                       | Гетерогенные среды, Linux, open-source проекты       |

---

✅ Архитектурные различия

### 🔹 Active Directory
- Это **полноценная служба каталогов**
- Включает:
  - **LDAP** — для чтения/записи
  - **[[Kerberos]]** — для аутентификации
  - **DNS** — для обнаружения контроллеров домена
  - **Group Policy** — для управления политиками (GPO)
  - **Replication** — между контроллерами домена

### 🔹 LDAP (например, OpenLDAP)
- Это **каталог + протокол**
- Не включает:
  - Политики безопасности
  - Централизованное управление паролями
  - Встроенный механизм репликации (есть, но сложнее)

## ✅ Когда что использовать?

| Сценарий | Рекомендация |
|----------|--------------|
| ✅ Корпоративная сеть на Windows | ➤ **Active Directory** |
| ✅ Гетерогенная среда (Linux + Windows) | ➤ **AD + LDAP-шлюз** или **FreeIPA** |
| ✅ Open-source проект, Linux-only | ➤ **OpenLDAP** |
| ✅ Нужна интеграция с Windows-приложениями | ➤ **Active Directory** |
| ✅ Нужна гибкость и контроль над каталогом | ➤ **OpenLDAP** |
| ✅ Требуется Group Policy | ➤ **Active Directory** |
| ✅ Ограниченный бюджет | ➤ **OpenLDAP** |

## ✅ Совместимость

> ✅ **Active Directory поддерживает LDAP**  
> → Вы можете подключаться к AD через любой LDAP-клиент!

#### 💡 Пример:
```bash
ldapsearch -H ldap://dc.example.com \
           -D "user@example.com" \
           -W \
           -b "dc=example,dc=com" \
           "(sAMAccountName=alice)"
```

→ Это запрос к **Active Directory** через **LDAP-протокол**.
