## LangChain: фреймворк для создания приложений на основе LLM


**LangChain** — это открытый фреймворк (Python/JS), упрощающий разработку приложений с большими языковыми моделями (LLM). Его ключевая идея: *связывать LLM с внешними источниками данных и инструментами*, чтобы преодолеть ограничения «изолированных» моделей.

### Зачем нужен LangChain

LLM «застывают» на данных обучения и не имеют:
* доступа к актуальным внешним данным;
* возможности выполнять действия (отправить email, вызвать API);
* долгосрочной памяти о взаимодействии с пользователем.


LangChain решает эти проблемы через **интеграцию** LLM с реальным миром.


### Ключевые компоненты

1. **LLM & Chat Models**  
   Поддержка десятков провайдеров (OpenAI, Anthropic, Google, локальные модели и др.).

2. **Prompts**  
   Шаблоны подсказок с механизмами:
   * форматирования ввода;
   * добавления контекста;
   * динамической подстановки переменных.

3. **Chains**  
   Последовательности вызовов LLM + инструменты. Примеры:
   * **LLMChain** — один вызов модели;
   * **SequentialChain** — цепочка шагов;
   * **RouterChain** — выбор ветки по условию.

4. **Memory**  
   Хранение истории диалога:
   * буфер последних N сообщений;
   * суммаризация истории;
   * векторная память (поиск по сходству).

5. **Indexes**  
   Индексация документов для поиска:
   * разбиение на чанки;
   * создание векторных embeddings;
   * поиск релевантных фрагментов.

6. **Agents**  
   «Агенты» с доступом к инструментам:
   * могут решать многошаговые задачи;
   * самостоятельно выбирают нужные инструменты;
   * итеративно уточняют решение.

7. **Tools**  
   Внешние интеграции:
   * поисковые системы;
   * базы данных;
   * API (погода, финансы, CRM);
   * калькуляторы, парсеры и др.

### Как это работает: пример RAG‑приложения

1. Пользователь задаёт вопрос: *«Какова текущая цена BTC?»*  
2. **Retriever** ищет актуальные данные о BTC в индексированных источниках.  
3. Найденные фрагменты + вопрос передаются в **Prompt Template**.  
4. LLM генерирует ответ на основе свежих данных.  
5. История сохраняется в **Memory** для следующих запросов.

### Типичные сценарии использования

- **Чат‑боты с доступом к документации** (поиск ответов в базе знаний).  
- **Аналитические ассистенты** (суммаризация отчётов + выводы).  
- **Автоматизация рабочих процессов** (создание задач в Jira по текстовому описанию).  
- **Поисковые системы с генерацией ответов** (как Perplexity).  
- **Персональные помощники** (планирование, напоминания, интеграция с календарями).

### Преимущества LangChain

- **Унификация интерфейсов** — один API для разных LLM и инструментов.  
- **Модульность** — можно комбинировать компоненты как кубики.  
- **Готовая инфраструктура** — не нужно писать с нуля поиск, память, цепочки вызовов.  
- **Активное сообщество** — множество готовых шаблонов и интеграций.  
- **Поддержка streaming** — поточная генерация ответа.

### Ограничения


- **Сложность настройки** — требует понимания архитектуры.  
- **Зависимость от LLM** — качество зависит от базовой модели.  
- **Задержки** — вызовы внешних инструментов увеличивают время ответа.  
- **Стоимость** — много вызовов LLM могут быть дорогими.

### Пример кода (упрощённый)

```python
from langchain import OpenAI, PromptTemplate, LLMChain


# Инициализация модели
llm = OpenAI(temperature=0.7)

# Шаблон подсказки
prompt = PromptTemplate(
    input_variables=["question"],
    template="Ответь на вопрос: {question}"
)

# Цепочка: prompt → LLM
chain = LLMChain(llm=llm, prompt=prompt)

# Запуск
response = chain.run("Что такое LangChain?")
print(response)
```

### Вывод

LangChain — это «склеивающий» фреймворк, превращающий LLM в **интеллектуальных агентов**, способных:
- искать информацию;
- запоминать контекст;
- выполнять действия;
- решать сложные многошаговые задачи.

Он особенно ценен для корпоративных решений, где критически важны актуальность данных и интеграция с существующими системами.
