## Виды токенизаторов

**Токенизаторы** — это **фундамент [[nl-processing|NLP]]**, особенно при работе с трансформерами.

Выбор правильного токенизатора влияет на:

- качество модели;
- размер векторов;
- поддержку языков;
- производительность.

---

## Сравнение токенизаторов

| Характеристика | **Byte-Pair Encoding (BPE)** | **SentencePiece** | **WordPiece (BERT)** | **Tiktoken (OpenAI)** | **Hugging Face Tokenizers** |
|----------------|------------------------------|------------------|----------------------|------------------------|----------------------------|
| **Разработчик** | Original: Philip Gage<br>Популяризирован GPT, RoBERTa | Google | Google (для BERT) | OpenAI | Hugging Face |
| **Подход** | Объединяет байты/символы по частоте | Subword → разбивает на части | Subword → как BPE, но greedy | BPE + специальные правила | Библиотека для всех токенизаторов |
| **Языки** | Универсальный (хорошо для любых) | Отлично для азиатских, без пробелов | Лучше для английского | Английский, частично другие | Зависит от модели |
| **Пробелы** | Не важны (работает с байтами) | Обрабатывает пробелы как символы | Добавляет префиксы `##` | Использует `<\|endoftext\|>` | Гибко |
| **Особенности** | Много токенов<br>Хорошо для редких слов | Независим от языка<br>Работает с китайским, японским | Для BERT<br>Greedy алгоритм | Очень быстрый<br>Оптимизирован под GPT | Unified API<br>Поддержка всех типов |
| **Скорость** | Средняя | Высокая | Средняя | ⚡ Очень высокая | Зависит от backend'а |
| **Используется в** | GPT, RoBERTa, Llama | T5, ALBERT, XLNet | BERT, DistilBERT | GPT-3, GPT-4 | Любая Hugging Face-модель |
| **Кодирование** | UTF-8 → byte-level | UTF-8 → subword | Unicode → subword | Byte-level BPE | Поддерживает все |
| **Преимущества** | Хорошо режет слова | Работает без предобработки | Совместим с BERT | Самый быстрый | Универсальная интеграция |

## Подробнее по каждому

### Byte-Pair Encoding (BPE)

> 🌐 Разработан в 1994, популяризирован в [[nl-processing|NLP]] в 2016+.

**Когда использовать**

- В собственной модели;
- если нужно гибкое разделение;
- для мультиязычных систем.

**Особенности**

- ✅ хорошее разделение на подслова;
- ✅ подходит для собственных моделей;
- ✅ универсален для мультиязычных систем;
- ❌ может создать много токенов;
- ❌ требует обучения.

**Пример**

```text
"unhappiness" → "un", "happi", "ness"
```

→ Обучается на корпусе.

### SentencePiece

> 🔤 Независим от пробелов → работает даже с японским.

**Особенности**

- ✅ не требует предварительной токенизации;
- ✅ работает напрямую со строкой UTF-8;
- ✅ подходит для языков без пробелов;
- ✅ единый подход ко всем языкам;
- ✅ простота внедрения.

**Используется в**

- T5
- ALBERT
- XLNet

### WordPiece (BERT)

> 🔠 Как BPE, но с жадным поиском.

**Особенности**

- ✅ при токенизации: `"playing"` → `"play", "##ing"`;
- ✅ используется в моделях [[nl-processing|BERT]]-семейства;
- ✅ хорошее покрытие словаря;
- ✅ эффективная обработка неизвестных слов;
- ❌ слабее на языках вне английского;
- ❌ медленнее, чем Tiktoken.

### Tiktoken (OpenAI)

> ⚡ Самый быстрый токенизатор в мире.

**Особенности**

- ✅ byte-level BPE;
- ✅ написан на C++ → скорость ×10;
- ✅ используется в GPT-3, GPT-4;
- ✅ сверхвысокая скорость;
- ✅ несколько режимов: `cl100k_base`, `p50k`, `r50k`;
- ✅ интеграция с OpenAI API;
- ❌ только для моделей OpenAI;
- ❌ не подходит для кастомных обучений.

**Пример**

```python
import tiktoken
enc = tiktoken.get_encoding("cl100k_base")
enc.encode("Hello world") → [15496, 9047]
```

### Hugging Face Tokenizers

> 🧰 Универсальная библиотека.

**Что делает**

- Поддерживает: BPE, WordPiece, SentencePiece;
- на C++ → очень быстро;
- API на Python/Rust.

**Используйте, если**

- Используется **любая модель из [[hugging-face|Hugging Face]]**;
- нужен одинаковый код для всех токенизаторов;
- дообучается собственная модель.

**Пример**

```python
from transformers import AutoTokenizer
tokenizer = AutoTokenizer.from_pretrained("bert-base-multilingual-cased")
tokens = tokenizer.tokenize("Привет, мир!")
```

## Рекомендации по выбору

| Задача | Рекомендация |
|------------|---------------|
| Используются GPT-3/4 | ➤ **Tiktoken** |
| Дообучение BERT | ➤ **WordPiece** |
| Мультиязычная модель (включая китайский) | ➤ **SentencePiece** |
| Собственная модель (Llama-style) | ➤ **BPE** |
| Работа с HF Transformers | ➤ **transformers.Tokenizer** |
| Максимальная скорость | ➤ **Tiktoken** или **HF Rust tokenizers** |
| Поддержка всех языков | ➤ **SentencePiece** |
| Исследовательские задачи | ➤ **HF + BPE/SentencePiece** |

**Финальный вывод**

| Токенизатор | Лучше всего подходит для |
|------------|--------------------------|
| **BPE** | GPT, RoBERTa, Llama |
| **SentencePiece** | T5, XLM-R, мультиязычные модели |
| **WordPiece** | BERT, DistilBERT |
| **Tiktoken** | GPT-3, GPT-4, gpt-3.5-turbo |
| **Hugging Face** | Любые модели, fine-tuning, RAG |

> 💬 _"The tokenizer is the gatekeeper of meaning."_

> 🔤 **Правильный токенизатор = меньше токенов = дешевле и быстрее.**
