### Векторное представление слов и фраз (Word Embedding)

**Word Embedding** — это метод представления слов и фраз в виде векторов (числовых массивов) в многомерном пространстве, где семантически близкие понятия имеют близкие векторные представления.

#### Суть подхода

Вместо того чтобы работать с текстом напрямую, алгоритмы машинного обучения:
* преобразуют каждое слово в вектор фиксированной длины (обычно 50–300 чисел);
* располагают векторы в пространстве так, чтобы семантически похожие слова находились рядом;
* используют эти векторы как входные данные для моделей NLP.

#### Ключевые свойства

1. **Семантическая близость**  
   Слова со схожим значением имеют близкие векторы (например, *«кошка»* и *«кот»* будут расположены рядом).

2. **Линейные отношения**  
   Векторные разности отражают семантические отношения:  
   $$
   \text{вектор(«король»)} - \text{вектор(«мужчина»)} \approx \text{вектор(«королева»)} - \text{вектор(«женщина»)}
   $$

3. **Многомерность**  
   Каждое измерение вектора может отражать определённый аспект значения (тематику, эмоциональную окраску, грамматические свойства).

#### Как создаются векторные представления

Основные алгоритмы обучения:

1. **Word2Vec** (Google, 2013)  
   Два варианта:
   * **CBOW** (Continuous Bag‑of‑Words): предсказывает слово по контексту;
   * **Skip‑gram**: предсказывает контекст по слову.

2. **GloVe** (Global Vectors, Stanford, 2014)  
   Строит векторы на основе глобальной статистики совместной встречаемости слов в корпусе.

3. **FastText** (Facebook, 2016)  
   Учитывает подслова (n‑граммы), что улучшает работу с редко встречающимися и морфологически сложными словами.

#### Процесс обучения

1. Берётся большой текстовый корпус (миллионы слов).
2. Для каждого слова формируется контекстное окно (например, ±5 слов).
3. Модель учится предсказывать:
   * либо целевое слово по контекстным (Skip‑gram);
   * либо контекстные слова по целевому (CBOW).
4. В результате обучения каждый токен получает вектор, отражающий его «окружение» в корпусе.

#### Применение векторных представлений

1. **Поиск синонимов**  
   Нахождение слов с близкими векторами.

2. **Классификация текста**  
   Использование векторов как признаков для моделей.

3. **Машинный перевод**  
   Сопоставление слов в разных языках через общие векторные пространства.

4. **Рекомендательные системы**  
   Представление товаров/контента в векторном пространстве.

5. **Извлечение информации**  
   Поиск сущностей и отношений на основе семантической близости.

#### Преимущества

* **Компактность**: вектор фиксированной длины вместо разреженных one‑hot‑кодов.
* **Семантика**: улавливает смысловые связи между словами.
* **Обобщение**: работает с неизвестными словами через подсловные единицы (в FastText).
* **Переносимость**: векторы можно использовать в разных задачах NLP.

#### Ограничения

* **Зависимость от корпуса**: качество векторов зависит от объёма и тематики обучающих данных.
* **Многозначность**: одно слово может иметь несколько значений, но получает один вектор.
* **Контекстная ограниченность**: классические модели не учитывают контекст предложения (решается в современных трансформерах вроде BERT).

#### Пример векторных представлений

Допустим, для слова *«кошка»* вектор может выглядеть так (упрощённо):  
$$
[0{,}25,\ -0{,}12,\ 0{,}87,\ \ldots,\ 0{,}41]
$$  
где каждое число отражает определённый семантический признак (например, «животное», «домашнее», «маленькое» и т. д.).

#### Современные альтернативы

Классические Word Embedding (Word2Vec, GloVe) постепенно уступают место **контекстуальным** моделям:
* **BERT**: генерирует разные векторы для одного слова в зависимости от контекста;
* **Sentence‑BERT**: создаёт векторы для целых предложений;
* **Universal Sentence Encoder**: универсальные векторные представления фраз.

Тем не менее классические Word Embedding остаются актуальными для задач, где:
* нужен быстрый инференс;
* достаточно общего семантического сходства;
* ограничены вычислительные ресурсы.

Векторные базы данных (например, FAISS, Qdrant или Weaviate) хранят сами эмбеддинги и используют графы (или кластерные индексы), которые за микросекунды возвращают десятку наиболее похожих векторов.
