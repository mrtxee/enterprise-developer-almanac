## ✅ 1. Sparse Representations (Разрежённые представления)

> Это **ранние методы**, где каждый документ → разрежённый вектор:  
> Подавляющее большинство значений = `0`

---

### 🔹 Методы:

#### 🟦 **Bag-of-Words (BoW)**
- Текст → мешок слов
- Игнорирует порядок, учитывает частоту

```text
"кошка сидит на ковре"
→ [кошка:1, сидит:1, на:1, ковре:1]
```

✅ Просто  
❌ Не учитывает семантику

---

#### 🟨 **One-Hot Encoding**
- Каждое слово = вектор длиной `N` (все нули + одна единица)

```text
Словарь: [cat, dog, run]  
"cat" → [1, 0, 0]  
"dog" → [0, 1, 0]
```

✅ Базовое понимание  
❌ Очень длинные векторы → неэффективно

---

#### 🟥 **TF-IDF (Term Frequency – Inverse Document Frequency)**

> Улучшенная версия BoW:
- `TF` — насколько часто слово в документе
- `IDF` — насколько редко слово в корпусе

```python
from sklearn.feature_extraction.text import TfidfVectorizer
tfidf = TfidfVectorizer()
X = tfidf.fit_transform(["кошка на ковре", "собака на улице"])
```

✅ Хорош для:
- Поиска
- Классификации
- Сравнения документов

❌ Не понимает:
- Синонимы (`автомобиль` ≠ `машина`)
- Контекст
- Порядок слов

---

### 🔹 BM25 — оценка релевантности

> **BM25 (Best Match 25)** — это **алгоритм ранжирования**, используемый в Elasticsearch, Lucene, Splunk

#### Формула (упрощённо):
```text
Score(D,Q) = Σ [IDF(q) * TF(q,D)]
```
Где:
- `q` — слово запроса
- `D` — документ
- `k1`, `b` — параметры (обычно `k1=1.2`, `b=0.75`)

#### Преимущества:
- Лучше, чем TF-IDF
- Учитывает длину документа
- Работает без обучения

✅ Используется в:
- Elasticsearch
- Solr
- DuckDB
- OpenSearch

## ✅ 2. Dense Representations (Плотные представления)

> Современные методы, где текст → **плотный вектор фиксированной длины**, например: `[0.89, -0.34, 0.67, ...]`  
> Длина: 384, 768, 1024

> 💡 Один вектор = смысл всего предложения

---

### 🔧 Нейросетевые модели

| Модель | Описание |
|--------|----------|
| **Word2Vec** | Первые эмбеддинги слов<br>CBOW, Skip-Gram |
| **GloVe** | Global Vectors for Word Representation<br>статистика + матричное разложение |
| **Sentence Transformers** | `all-MiniLM-L6-v2`, `paraphrase-multilingual`<br>Умеет сравнивать целые предложения |
| **E5 (Embeddings from Enhanced Encoder)** | От Microsoft — поддерживает много языков |
| **GTE (General Text Embeddings)** | Alibaba Cloud — open source |
| **text-embedding-3-small/large** | От OpenAI — state-of-the-art |

---

### 🔍 Как работают?

```text
"кошка сидит на ковре" → [0.89, -0.34, 0.67, ..., 0.12]
"кот лежит на ковре" → [0.87, -0.33, 0.65, ..., 0.13]

cosine_similarity(v1, v2) ≈ 0.98 → почти одинаковый смысл
```

> ✅ Теперь можно сравнивать **похожесть текстов**

---

## 🔎 Индексация плотных векторов

> Векторы нельзя хранить в обычной БД → нужен **ANN (Approximate Nearest Neighbors)**

| Алгоритм | Описание |
|---------|----------|
| **HNSW (Hierarchical Navigable Small World)** | Быстро, память-ёмкий<br>Используется в: Pinecone, Weaviate |
| **IVF-PQ (Inverted File Index + Product Quantization)** | Компактнее, медленнее<br>Хорош для больших систем |
| **DiskANN** | Хранит векторы на диске<br>Огромные объёмы → быстро |
| **FAISS (Facebook AI)** | Библиотека для ANN<br>Поддерживает HNSW, IVF, PCA |

---

## 🆚 Sparse vs Dense

| Критерий | **Sparse (BoW, TF-IDF)** | **Dense (Word2Vec, Sentence-BERT)** |
|----------|--------------------------|-------------------------------|
| **Длина вектора** | Большая (тысячи/миллионы) | Фиксированная (384, 768) |
| **Семантика** | ❌ Только ключевые слова | ✅ Понимает смысл |
| **Контекст** | ❌ Нет | ✅ Да |
| **Производительность** | Высокая при малых данных | Требует GPU/CPU |
| **Масштабирование** | До миллиона документов | До миллиардов (с ANN) |
| **Поиск по смыслу** | ❌ Только по словам | ✅ Да — “автомобиль” ≈ “машина” |
| **Инструменты** | Elasticsearch (TF-IDF), Scikit-learn | Pinecone, Weaviate, Chroma |

---

## ✅ Когда что использовать?

| Задача | Рекомендация |
|--------|---------------|
| ✅ Поиск по точному совпадению | ➤ **Sparse (TF-IDF, BM25)** |
| ✅ Поиск по смыслу | ➤ **Dense + RAG** |
| ✅ MVP, мало данных | ➤ **TF-IDF + BM25** |
| ✅ LLM, чат-боты | ➤ **Dense (E5, GTE, text-embedding-3)** |
| ✅ Мультиязычность | ➤ **sentence-transformers/multilingual** |
| ✅ Ограниченная память | ➤ **IVF-PQ, PQ** |
| ✅ Быстрый поиск | ➤ **HNSW** |

## ✅ Финальный вывод

| Тип | Подходит для |
|------|--------------|
| **Sparse** | Простой поиск, фильтрация |
| **Dense** | Понимание смысла, RAG, рекомендации |

> 💬 _“Sparse says: ‘It has the word.’_  
> _Dense knows: ‘It means the same.’”_
