## Hugging Face Tokenizers

**Tokenizers** — это высокопроизводительная библиотека от Hugging Face для преобразования текста в числовые последовательности (токены), которые понимают языковые модели.

### Зачем нужен токенизатор

Нейросети работают с числами, а не с текстом. Токенизатор:

- разбивает текст на смысловые единицы (токены);
- сопоставляет каждому токену числовой ID из словаря модели;
- формирует входные последовательности для модели.

### Как работает токенизатор

1. **Нормализация** — приведение текста к единому виду:
    - унификация пробелов и пунктуации;
    - приведение к нижнему регистру (опционально);
    - удаление/замена спецсимволов.
2. **Преразбиение (pre-tokenization)** — разделение текста на части по базовым правилам (например, по пробелам и пунктуации).
3. **Токенизация** — преобразование частей в токены по алгоритму (BPE, WordPiece и др.).
4. **Преобразование в ID** — замена токенов на числовые идентификаторы из словаря модели.
5. **Постобработка** — добавление специальных токенов.
