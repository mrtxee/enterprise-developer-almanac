## ML

Машинное обучение (Machine Learning, ML) — это технология, при которой алгоритмы учатся находить закономерности в данных и делать прогнозы с помощью математики, статистики и теории вероятностей, без ручного задания правил.

[[CRISP-DM|CRISP-DM]] — стандарт разработки и внедрения ML-модели.

[[machine-learning-model|Machine learning models]] — модели машинного обучения.

- Выбор аппаратной платформы для ML: [[cpu-gpu|CPU/GPU]]
- [[nl-processing|NLP]] — обработка естественного языка
  - [[dialog-management|NLU]] — Natural Language Understanding
  - [[dialog-management|DM]] — Dialog Management
    - Политики: Rule-based, Data-driven (Retrieval-based, Generating)
    - Slot Filling
  - [[dialog-management|NLG]] — Natural Language Generation
  - [[word-embedding|Word embedding]] — векторное представление слова
  - [[rag|RAG]] — Retrieval Augmented Generation pattern
    - Токены
    - Векторы
    - Чанки
    - Метаданные
    - SentenceTransformer
  - [[fine-tuning|Fine-tuning]] — однократное дообучение готовой большой языковой модели
  - Алгоритмы кодирования текста
    - **Sparse** — разрежённые представления текста
      - Методы кодирования векторов: [[nl-encoding|Bag-of-words]], one-hot, TF-IDF
      - BM25 — оценка релевантности вектора запросу
    - **Dense** — плотные представления текста
      - Нейросетевые модели: word2vec, GloVe, [[embedding-models|Sentence Transformers]], E5, GTE, text-embedding-3
      - Индексация векторов: ANN (HNSW, IVF-PQ, [[vector-index|DiskANN]])
    - **Гибрид** — dense-поиск + sparse-ранжирование
      - Инвертированный индекс (BM25)
      - Векторный индекс (HNSW в Qdrant / Elastic)
      - Слой слияния: Reciprocal Rank Fusion (RRF) или Linear Combo
    - **Меры близости**
      - Евклидова дистанция (L2)
      - Косинусное сходство
      - Скалярное произведение
      - Манхэттенское расстояние (L1)

  - [[airflow|Airflow]] — для автоматизации обучения
  - [[ml-flow|MLflow]] — для экспериментов и версионирования
  - [[Prometheus|Prometheus]] и [[grafana|Grafana]] — для метрик, [[ELK|ELK]]-стек — для более глубокого анализа логов
  - [[rasa|Rasa]] — среда машинного обучения
  - [[tokenizators|Tokenizators]]
    - Byte-Pair Encoding (BPE) — основа GPT-семейства
    - SentencePiece (Google) — универсальный токенизатор, поддерживает unigram-модели и BPE
    - WordPiece (BERT) — исторически популярный токенизатор, но реже встречается в новых [[LLM|LLM]]
    - Tiktoken (OpenAI) — оптимизирован под GPT-модели, быстро работает на C
    - HuggingFace/tokenizers — гибкий токенизатор, с помощью которого легко тренировать свой
  - [[vector-store|Vector store]] — хранилища эмбеддингов
    - **FAISS** — минималистичный и очень быстрый движок для C++ или Python
    - **Pinecone** — полностью управляемый облачный сервис-хранилище векторных данных (SaaS)
    - **Qdrant** — полнофункциональный векторный сервер с масштабируемыми REST- и gRPC-API
    - **ChromaDB** — легко встраиваемое решение с богатой экосистемой в Python
  - Контроль галлюцинаций
    - [[rag-assessment|RAG assessment]]

  - Безопасность работы LLM
    - Safety-классификаторы: OpenAI Moderation API, Google Perspective API, Hugging Face open-source, AWS Comprehend / Bedrock Guardrail, Azure Content Safety

## Вопросы и ответы

### Нейросеть vs модель

В чём разница между «нейросетью» и «моделью».

Коротко: **нейросеть** — это *архитектура* (принцип устройства), а **модель** — это *конкретный обученный экземпляр* нейросети.

Разберём подробнее:

**Нейросеть (нейронная сеть)** — это:

- общий принцип построения алгоритма по образцу работы биологических нейронов;
- «чертёж» или шаблон: сколько слоёв, как они связаны, какие функции активации используются;
- математическая структура, способная обучаться на данных, но пока не обученная и не готовая к применению.

**Модель нейросети** — это:

- уже обученная нейросеть с зафиксированными параметрами (весами);
- инструмент, который может решать конкретную задачу: генерировать текст, распознавать образы, переводить и т. п.;
- «построенный дом» по ранее описанному «чертежу» (архитектуре).

**Пример аналогии**

- Архитектура = план дома (сколько комнат, где стены, как проложены трубы).
- Модель = построенный дом с отделкой, мебелью и подключёнными коммуникациями.

**Что такое архитектура нейросети**

**Архитектура** — это структурная организация нейросети:

- количество слоёв (входного, скрытых, выходного);
- тип связей между нейронами (полносвязные, свёрточные, рекуррентные и др.);
- функции активации в нейронах;
- механизмы передачи данных между слоями;
- дополнительные блоки (например, механизмы внимания в трансформерах).

**Основные типы архитектур**

1. **Полносвязные (многослойные персептроны, MLP)**
   - каждый нейрон связан со всеми нейронами следующего слоя;
   - подходят для простых задач классификации и регрессии.
2. **Свёрточные нейросети (CNN, Convolutional Neural Networks)**
   - специализируются на обработке изображений;
   - используют свёрточные слои для выделения признаков (краёв, текстур и т. п.).
3. **Рекуррентные нейросети (RNN, Recurrent Neural Networks)**
   - работают с последовательными данными (текст, аудио, временные ряды);
   - имеют «память» о предыдущих шагах обработки.
4. **Трансформеры (Transformers)**
   - используют механизм внимания (attention) для анализа взаимосвязей между элементами последовательности;
   - лидируют в задачах обработки текста (перевод, суммаризация, диалог);
   - примеры: GPT, BERT, T5.
5. **Гибридные архитектуры**
   - комбинируют элементы разных типов (например, CNN + Transformer);
   - применяются в мультимодальных задачах (текст + изображение).

**Как это работает на практике**

1. **Выбор архитектуры**
   - определяется задачей: для изображений — CNN, для текста — Transformer и т. п.
2. **Обучение модели**
   - на больших наборах данных настраиваются веса связей между нейронами;
   - модель «учится» находить закономерности в данных.
3. **Использование модели**
   - обученная модель применяется для решения конкретных задач (генерация, классификация, прогноз).

**Итог**

- **Нейросеть** = общий принцип устройства (архитектура).
- **Модель** = конкретная обученная реализация этой архитектуры.
- **Архитектура** = структура нейросети, определяющая её возможности и область применения.

### Разрежённые и плотные подходы к поиску информации

Оба подхода решают задачу **retrieval** (поиска релевантных документов/фрагментов по запросу), но используют принципиально разные представления данных.

#### Разрежённый поиск (Sparse Retrieval)

**Основа**: текстовые данные представляются как **разрежённые векторы** — векторы высокой размерности, где большинство значений равны нулю, а ненулевые отражают частоту слов.

**Как работает**

- Анализирует, насколько часто слова из запроса встречаются в документах.
- Использует статистические меры (например, [[nl-processing|TF-IDF]]) для оценки значимости слов.
- Строит инвертированный индекс: для каждого слова — список документов, где оно встречается.

**Пример метода**: TF-IDF

- *Term Frequency (TF)*: частота слова в документе.
- *Inverse Document Frequency (IDF)*: «редкость» слова во всей коллекции документов.
- Итог: слова, частые в конкретном документе и редкие в коллекции, получают высокий вес.

**Особенности**

- ✅ Быстрый поиск (за счёт инвертированного индекса)
- ✅ Не требует обучения моделей
- ✅ Интерпретируем: понятно, почему документ попал в выдачу (по совпадению ключевых слов)
- ✅ Низкие требования к ресурсам
- ❌ Не понимает семантику: не найдёт документ, где нет точных слов из запроса, даже если смысл совпадает
- ❌ Работает только с текстом
- ❌ Чувствителен к синонимам, морфологии, опечаткам

**Где применяется**: классические поисковые системы (например, ранняя версия Google), корпоративный поиск по документам.

#### Плотный поиск (Dense Retrieval)

**Основа**: текстовые данные преобразуются в **плотные векторы** (эмбеддинги) низкой размерности, где каждое значение несёт семантическую информацию.

**Как работает**

- Нейросеть (например, [[nl-processing|BERT]]) кодирует запрос и документы в векторы.
- Векторы располагаются в общем семантическом пространстве: близкие по смыслу тексты имеют близкие векторы.
- Поиск сводится к нахождению ближайших соседей (ANN, Approximate Nearest Neighbors) к вектору запроса.

**Примеры моделей**: BERT, Sentence-BERT, ColBERT.

**Особенности**

- ✅ Понимает смысл: находит документы, семантически близкие к запросу, даже без точных совпадений слов
- ✅ Поддерживает мультимодальность: можно искать по тексту, изображениям, аудио
- ✅ Устойчив к синонимам, перефразировкам, ошибкам
- ✅ Позволяет сложные сценарии (например, поиск по намерению)
- ❌ Требует больших вычислительных ресурсов (обучение и инференс)
- ❌ Нужен предобученный или дообученный энкодер
- ❌ Менее интерпретируем: непонятно, почему конкретный документ попал в выдачу
- ❌ Медленнее, чем разрежённый поиск (из-за вычислений над векторами)

**Где применяется**: современные поисковые системы, рекомендательные сервисы, чат-боты, семантический поиск в больших базах знаний.

**Ключевые отличия**

| Критерий | Разрежённый поиск | Плотный поиск |
| ------ | --------------------------------- | --------------------------------------------- |
| **Представление данных** | Разрежённые векторы (много нулей) | Плотные векторы (мало измерений, все значимы) |
| **Основа** | Частотность слов | Семантическое значение |
| **Индексация** | Инвертированный индекс | [[vector-index|Векторный индекс]] (ANN) |
| **Скорость** | Очень быстрый | Медленнее (из-за векторных операций) |
| **Ресурсы** | Низкие | Высокие |
| **Семантика** | Нет | Да |
| **Мультимодальность** | Нет | Да |
| **Интерпретируемость** | Высокая | Низкая |
| **Типичные алгоритмы** | TF-IDF, BM25 | BERT + ANN (FAISS, HNSW) |

**Гибридные подходы**

На практике часто комбинируют оба метода:

1. **Первый этап (candidate retrieval)** — разрежённый поиск быстро отбирает кандидатов по ключевым словам.
2. **Второй этап (reranking)** — плотный поиск ранжирует кандидатов по семантической релевантности.

Это позволяет совместить скорость разрежённого поиска с точностью плотного.

**Пример**: поиск в Google или Яндекс может использовать гибридную схему для баланса скорости и качества.
