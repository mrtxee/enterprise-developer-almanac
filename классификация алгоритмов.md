# классификация алгоритмов

классификация всех типов алгоритмов в информатике

*   **По парадигме:** Полный перебор, Разделяй и властвуй, Динамическое программирование, Жадные, Backtracking.
*   **По типу задач:** Сортировка, Поиск, Графовые, Строковые, Численные, Криптографические.
*   **По сложности:** O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ).
*   **По детерминизму:** Детерминированные, Вероятностные (рандомизированные).
*   **По выполнению:** Последовательные, Параллельные, Распределенные.
*   **По реализации:** Рекурсивные, Итеративные.
*   **По обучению (AI):** С учителем, Без учителя, С подкреплением.

---

# класс парадигмы

*   **Полный перебор / Brute Force:** 
	* Проверка всех возможных вариантов решения.
*   **Разделяй и властвуй / Divide and Conquer:** 
	* Разбиение на независимые подзадачи, решение, слияние результатов.
*   **Динамическое программирование / Dynamic Programming:** 
	* Разбиение на перекрывающиеся подзадачи с запоминанием результатов.
*   **Жадные алгоритмы / Greedy Algorithms:** 
	* Локально оптимальный выбор на каждом шаге без отката.
*   **Поиск с возвратом / Backtracking:** 
	* Построение решения по шагам с откатом при неудаче.
# класс сложности

- **O(1):** Константное / Constant
- **O(log n):** Логарифмическое / Logarithmic
- **O(n):** Линейное / Linear
- **O(n log n):** Линеарифмическое / Linearithmic (Quasilinear)
- **O(n²):** Квадратичное / Quadratic
- **O(2ⁿ):** Экспоненциальное / Exponential

# класс детерминизма

*   **Детерминированные / Deterministic:** Одинаковый вход → 
	* всегда одинаковый результат и путь выполнения. Нет случайности.
*   **Вероятностные / Probabilistic (Randomized):** 
	* Используют случайность. Результат или время выполнения варьируются. Часто эффективнее. Типы: Лас-Вегас (всегда верно), Монте-Карло (возможна ошибка).
